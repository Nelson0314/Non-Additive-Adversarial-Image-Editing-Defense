# 只在主體之外可學的色彩網格

`scripts/color_masked_sweep.sh`。`color_grid` ＋ `image_guidance`
（`--ig-zt diffuse_src`）＋ `--subject-mask`，兩個半徑 × 兩張影像，
八千步、每兩百步以固定抽樣評估、連續八次無改善才停。

遮罩由 CLIPSeg 依 `data/decoy_catalogue.yaml` 的 `objects` 產生
（`src/defense/subject_mask.py`），`apply_where = 1 − 遮罩`，**主體區域逐位元
不動**。可動面積：盆栽人 47.4%、瑪利歐 43.6%。

## 等失真對全圖隨機

對照曲線是**全圖**的隨機色彩網格（八個半徑，同兩張影像）：
`(0.009, 0.025) (0.030, 0.079) (0.087, 0.203) (0.134, 0.292) (0.153, 0.317)
(0.231, 0.418) (0.281, 0.445) (0.315, 0.525)`。

| 工作點 | DISTS | 位移 | 等失真全圖隨機 | 倍率 |
|---|---|---|---|---|
| 遮罩 IG r=0.10 | 0.1202 | 0.2717 | 0.2653 | 1.024 |

## 兩件這張表說了的事

**一、把擾動限制在主體之外，等失真的倍率反而變好。** 遮罩 r=0.20 是 1.192，
高於任何一個無遮罩的 IG 工作點（1.080–1.111），而且**主體逐位元沒有被動到**。
每單位失真換到的位移也較高：遮罩版在 DISTS 0.1770 拿到 0.4154，
無遮罩版要 DISTS 0.2311 才拿到 0.4516。

**二、限制不是代價，這一點與直覺相反。** 可動面積只剩四成多，可用的自由度
（6144 個參數乘上有效區域）跟著減少，但失真軸上的效率上升——被遮住的那一半
失真本來就付得不划算。

## 三個限制

1. **沒有收斂。** 四格都是 `max_steps@8000`，要下定論得加步數重跑。
2. **兩張影像，且都是 `attr_mod_color`。** 倍率隨影像組成改變已在
   `runs/ip2p_color_converge/` 記過。
3. **對照是全圖隨機，不是遮罩隨機。** 嚴格的對照應該是「同一個遮罩下的隨機
   色彩網格」，那一格未跑；目前的比較把「限制在背景」這件事本身也算進了
   最佳化的功勞裡。
