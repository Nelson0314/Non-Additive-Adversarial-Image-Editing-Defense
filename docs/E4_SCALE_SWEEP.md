# E4 — 注入倍率掃描：ε̂ 注入點的硬上限

原始資料：`runs/e4_scale/summary.csv`（8 格）。設定：car_00、r=4、15 步、lr=0.008、k_inv=20、t_max=500、跳過評測（此為診斷，非最終結果）。

## 動機

`NIGHT_RUN_2026-07-29.md` §3.7 的結論是 site L 的 `φ` 沒有可量測的貢獻，§3.7 末段量出原因：`φ` 的擾動在振幅上比它所處的重建誤差小 20~36 倍。建議 0 因此是「掃 `scale`，把 `φ` 的量級拉到與重建誤差同級」。

本掃描執行該建議，並**否定了它背後的假設**。

（偏移為訓練噪聲下的值，跨 scale 比較有效；絕對值因輪替淨化而偏高，見 §3.4。）

## 三項判讀

**1. 問題不是量級。** site LA 的擾動能量增加 1900 倍，偏移只由 0.1254 升到 0.1430（+14%），且在 scale=200 時**反而下降**到 0.1353。存在一個與量級無關的上限。site L 增加 8850 倍能量得到 +81%，但代價是保真度，見第 2 點。

**2. site L 的絕對保真度與 scale 無關，恆為 19~20 dB。** 因為它完全由 VAE 來回的重建誤差決定（car_00 的 VAE 地板為 19.96 dB）。`scale` 只改變 `φ` 的貢獻，改變不了地板。這再次確認 §3.7 的結論：site L 的輸出品質與防禦強度基本無關。

**3. site LA 有一個明確的最佳操作點：scale ≈ 10~50。** 在 scale=10 時保真度 37.46 dB，已接近 site P r=16 的 39.79 dB，可作為同一保真水準下的對照。再往上，保真度每掉 9 dB 換不到偏移。

## 對假設的修正

原假設：「`φ` 太小 ⟹ 拉大 `scale` 就會有效」。**該假設不成立。** 修正後的敘述：

> 在防禦生成的去噪過程中對 `ε̂` 加擾動，其所能造成的編輯偏移存在一個與擾動量級無關的上限。

### 一個可檢驗的解釋

攻擊者的 SDEdit 在 strength 0.5 下先把影像加噪到 `t₀ = 500`，該操作本身就抹除大量高頻內容。防禦若要生效，其擾動必須是**能存活於再加噪之後**的成分，即低頻／結構性的改變；`ε̂` 上的小幅擾動經 DDIM 更新與 VAE 解碼後在像素空間是滿秩、瀰散的（實測 eff_rank 512、能量秩 322，且與注入秩無關），這類擾動正好是再加噪最容易抹除的。

若此解釋成立，則有一個直接的推論：**低秩約束必須施加在像素空間，而非 latent 空間。** site P 正是如此（實測能量秩精確等於注入秩），而 site P 也正是唯一在運作的 arm。latent 注入的問題在於秩結構在 DDIM 更新 + VAE 解碼的過程中被破壞了。

這個推論可用現有程式直接檢驗，不需新架構：對 site L/LA 的**像素殘差**量測其能量在空間頻率上的分布，並與 site P 比較；若 site P 的殘差集中於低頻而 site L/LA 瀰散於全頻帶，即支持上述解釋。

## 對後續設計的建議（取代 NIGHT_RUN §8 的建議 0）

1. **不要再往 `scale` 方向調。** 已證實無效。
2. **site LA 固定於 scale = 10** 作為 latent arm 的操作點（保真度與 site P 可比）。
3. **檢驗頻率解釋**（上述），這是低成本且能直接指向下一個架構決定的診斷。
4. 若頻率解釋成立，低秩約束應改為施加於像素空間，或在 latent 注入後加上一個把殘差投影回低秩的步驟——但後者會破壞「秩由架構保證、不需 SVD」的設計主張，須權衡。
