# 可學的補丁：主體逐位元不動，主體區位移仍達 0.57–0.60

`scripts/patch_direct_round.sh`、`src/defense/patch_param.py`。
兩張影像、六千步、每兩百步固定抽樣評估。**五格全部 `max_steps@6000` 未觸發
早停，讀數是下界。**

## 這一批推翻了什麼

`runs/patch_probe/README.md` 第三節寫著：影像引導殘差的 64% 落在主體的
latent token 上，凍結主體就凍結了那一段，故補丁族有 **0.41 的天花板**、
是結構性死路。

**那個推論無效。** 由「殘差壓不下去」推到「位移也上不去」不成立：
殘差確實只降到 0.60，但**位移照樣可以很大**，只要擾動是對抗性選出來的。
`patch_probe` 量到的 0.111–0.149 是**未最佳化內容**（白噪聲／中灰／照片）
的上界，不是這個方法的上界。

同樣是「主體逐位元不動」，把內容用 PGD 學出來之後：

| 格 | 支撐 | 面積 | 主體區位移（盆栽人／瑪利歐） | DISTS |
|---|---|---|---|---|
| `ig_comp_subj` | 補集 | 0.394／0.373 | **0.597 / 0.570** | 0.225／0.175 |
| `div_comp_subj` | 補集 | 同上 | **0.594 / 0.456** | 0.227／0.180 |
| `div_comp_uni` | 補集 | 同上 | 0.377 / 0.435 | 0.249／0.195 |
| `div_a10_mario` | 10% 方塊 | 0.100 | — / 0.310 | 0.075 |
| `div_a05_subj` | 5% 方塊 | 0.050 | 0.184 / 0.224 | 0.061／0.043 |
| `a05_rand`（同幾何隨機） | 5% 方塊 | 0.050 | 0.011 / 0.071 | — |
| **未最佳化白噪聲補集**（`patch_probe`） | 補集 | 0.394／0.373 | 0.149 / 0.111 | — |
| 相位族（**會動到主體**，參照） | — | — | 0.41 – 0.67 | 0.08–0.23 |

**最佳化的補集補丁落在相位族的區間內，而且主體逐位元不動。**

三件這張表說了的事：

1. **梯度買到 3–17 倍**：同一個幾何（5% 方塊、同位置）下，隨機 0.011／0.071
   對最佳化 0.184／0.224。
2. **面積是主要旋鈕**：5% → 10% → 補集 對應 0.22 → 0.31 → 0.57。
3. **主體加權有用**：同損失、同支撐，加權 0.594 對均勻 0.377（盆栽人）。

## `edit_divergence` 沒有比 `image_guidance` 好

本批新寫了一個**直接以防禦效果為目標**的損失
（`src/defense/edit_divergence_loss.py`）：

    L = − E_{t,ε} ‖ x̂₀(z_t ; c_I(x_def)) − x̂₀(z_t ; c_I(x)) ‖²

不指定要把影像條件推到哪裡，只要求模型建出來的東西離原圖的結果遠。
文字條件仍取空字串——**威脅模型的前提是攻擊指令未知**，用了攻擊 prompt
就是另一個威脅模型，數字不可與既有批次並列。

結果是**打平甚至略輸**既有的 `image_guidance`（0.597/0.570 對 0.594/0.456）。
如實記錄：這個損失沒有買到東西，後續取較簡單的 `image_guidance` 當基底。

## 兩個會靜默失效的坑（都已加守門）

1. **恆等起點是散度型損失的駐點。** `−‖f(x_def) − f(x)‖²` 在 `x_def = x` 處
   **值與梯度都恰為零**。第一次送出時五格全部 `loss -0.000000`、參數一步不動，
   而 trace 看起來只是「損失很小」。這是 FND-053 那一族的零梯度陷阱。
   修正：`--patch-init random`；且 `edit_divergence` ＋ patch 配 identity 起點時
   直接拋錯。`tests/test_patch_param.py` 有一條專門重現這個駐點。
2. **補集模式不給 `--radius` 會落進預算模式。** 補集的面積由遮罩決定、
   `radius` 完全不使用，但沒給它 `ip2p_run.py` 會去二分搜尋一個不起作用的
   參數。實測**用滿 GPU 兩小時而一步 PGD 的紀錄都沒有**，看起來像卡住而不是
   設定錯。修正：該組合缺 `--radius` 直接拋錯。

## 限制

1. **五格都跑滿六千步未早停**，讀數是下界。
2. **只有兩張影像。**
3. 補集支撐的 DISTS 是 0.175–0.249——整片背景換掉，這是**設計上就可見**的防禦。
   5% 方塊那一格只有 0.043–0.061。
4. 抗淨化另記於 `runs/ip2p_patch_purify/`；美化的取捨另記於
   `runs/ip2p_patch_pretty/`。
