## 2. 為什麼會走到這裡（三步）

**第一步：證明「匹配 LPIPS」不是匹配失真。** LPIPS 對模糊幾乎不收費，
最佳化會去買它。判別法是四臂等 LPIPS 探針（模糊／雜訊／變形-雙線性／
變形-雙三次）：雙三次比雙線性銳利 15 個百分點，故真的在量鈍化的指標必須
對雙三次收費**較低**。實測 GMSD、NLPD、HaarPSI、VIF、SSIM、DISTS、PSNR
全部反向——它們量的是幾何位移。使用者看比對頁後回報「位移不明顯、模糊
明顯較糟」，判別法成立。

順帶發現現行保真項的 `alpha_ssim=1.0` 不只對模糊盲目，而是**主動補貼
模糊**（SSIM 把雜訊判得比等 LPIPS 的模糊貴約 2 倍）。

**第二步：換掉約束，量出代價。** 新約束為 LPIPS ∩ 鈍化的交集，新指標
`local_acutance_dev`。E21 重跑後 site S 的 net 掉 **67.3%**，site P 只掉
8.3%。E15 記在非加性帳上的效果，三分之二是模糊。

**第三步：替代路徑也垮了。** site S 的鈍化幾乎全部來自雙線性重取樣
（純位移實驗 85.0% vs 真實 site S 85.2%），改 bicubic 回到 99.9%。這一度
看起來能救回來（τ=0.02 為 1.15×、τ=0.05 為 1.14×），但 E23 把步數由 25
提到 100、兩臂都真正被約束綁住之後，**τ=0.05 反轉為 0.85×**。

## 3. 哪些結論是硬的

**硬的（有資料、有測試、可重現）：**

| 結論 | 出處 |
|---|---|
| 用單一純量定義「匹配失真」，在失真種類不同的兩族之間不成立 | E20 §0、§5.3 |
| 位移主導 vs 鈍化追蹤的指標判別法，以及人眼確認 | E20 §5.3、§7 |
| `local_acutance_dev` 同時具備「對位移不敏感」與「不可抵銷」 | E20 §6，`tests/test_local_acutance.py` |
| SSIM 在保真項中補貼模糊 | E20 §3.3(1)、§8.2 |
| E15 的 1.15× 失效，且失效的量為 67.3% | E20 §8.3、E21 §2 |
| site S 的鈍化來源是雙線性重取樣 | E20 §5.2、E21 |
| cross-attention 的預設 divergence 模式梯度恆為零 | E20 §9 |
| 固定步數使不同格子被不同的東西綁住 | E21–E23 §4.1、§5.4 |

**不硬的：**

- **0.85× 本身**。100 步時兩臂**都還沒收斂**（末端 6/6 仍在上升），它是
  「100 步的比值」不是最終比值。
- **τ=0.02 的 1.15×**。E24 未產生資料即中止，該格既未證實也未推翻，
  **不應引用**。
- **`e23_Sbic_s100_tau0.10` 只完成 3/6 圖**，不可用於任何比較。

## 4. 重新思考時，這些是已知的死路

不要重走：

- **對抗性強健的感知度量**（E-LPIPS / R-LPIPS / LipSim）。解的是「微小擾動
  使度量數值劇變」，與本專案的「明顯模糊而度量不收費」是相反的失效，
  且其修法方向（讓度量更平滑）與需求相反。見 E20 §1.1。
- **NLPD、VIF、GMSD、HaarPSI 當保真約束**。四臂探針證明它們量的是位移，
  用它們會因為「site S 是變形」而懲罰它，是循環論證。見 E20 §5.3。
- **低秩**。使用者於 2026-07-30 明確排除。
- **site L / E / W（A 族）**。全部經 VAE 來回，重建地板即使壓到 0.0716
  仍高於加性運作點 0.063。見 E17–E19。
- **在 25 步的網格上比較兩個 site**。φ 量綱與 lr 都不同，「同樣跑 N 步」
  對兩者不是同一件事。

## 5. 若要繼續，三條路

**A. 接受否定結果，改寫論文重心。** 從「非加性更好」改成「匹配失真這件事
怎麼做才對，以及做對之後發生了什麼」。第 3 節「硬的」那八條足以支撐一篇
方法學論文，且「先前的正面結果來自度量盲區」本身可發表。

**B. 先修協議再重跑。** 把固定步數改成「約束啟動並穩定」的停止準則，
重跑 τ 網格，確認 0.85× 是不是最終值。成本不高（改停止準則 + 重跑數格），
但沒有 B 就無法確定地說 A。

**C. 換非加性的參數化。** 目前只試過位移場一種。在沒有理由相信別的參數化
會不同之前，這屬於「在會失敗的方向繼續深究」。

上一階段的建議是 **B 再 A**。使用者選擇重新思考方向，故三條路都未展開。
