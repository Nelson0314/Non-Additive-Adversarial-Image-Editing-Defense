# DCT-Shield 取捨曲線的延伸段

**這些數字尚未進入 `docs/RESULTS.md`**，等使用者裁定。

既有的 13 張曲線只到 `eps 1.4`（DISTS 0.0771），而本方法的兩個主線設定落在
DISTS 0.129–0.145。等失真的錨點因此只能外插，而協定（DEC-029）拒絕外插。
本目錄補上 `eps 1.8`／`2.2`，Y-only 補上 `eps 1.0`／`1.4`。

`--q-alg` 一律 0.95（論文 §5.4 的編輯任務設定），與既有曲線相同——兩支之間
唯一的差別因此是通道集合而不是品質因子（FND-058）。驅動是
`scripts/dct_band_extend.sh`。
