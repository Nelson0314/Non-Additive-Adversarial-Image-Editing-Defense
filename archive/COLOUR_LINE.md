# 一、問題與讀數

## 要解決什麼

現行的顏色方法在主表十二個條件裡位移排倒數，但**抗淨化是所有條件裡最好的**
（非幾何淨化保留率 1.016–1.021，其餘方法 0.31–0.86）。抗淨化來自它是**純顏色
全域映射**：同一個 RGB 三元組在整張圖得到同一個輸出，沒有空間資訊，JPEG 與模糊
洗不掉「把這種顏色換成那種顏色」這件事本身。

目標是在保住這個性質的前提下，把防禦效果拉到超過現行操作點。**沒有達成。**

## 讀數定義

主讀數是**位移** ＝ `LPIPS(編輯(原圖), 編輯(防禦圖))`。越大代表攻擊者拿到的結果
離他原本會拿到的越遠。

- 編輯管線（不可改）：InstructPix2Pix `timbrooks/instruct-pix2pix`，`s_t=7.5`、
  **`s_i=1.8`**（不是預設的 1.5）；inpainting `runwayml/stable-diffusion-inpainting`，
  遮罩 dilate 4、白＝重繪＝主體以外。兩者都是種子 20260812、50 步、512²。
- **求解端不得讀編輯指令**（威脅模型：防禦方看不到攻擊者的句子）。
  `scripts/immunise.py` 的 `assert_no_instructions` 會遞迴檢查設定檔並擋下來。
- 同時報**主體內**與**主體外**兩塊（遮罩為空間權重，全 1 時逐位元退回全圖 LPIPS），
  因為防禦端改掉的顏色會原封不動穿過編輯、被全圖 LPIPS 算成「位移被推開了」。

## 判定門檻

相對**批內**對照臂，**逐格相減後取中位**（不是兩邊各取中位再相減）：

- 配對差中位 **≥ 0.02** **且** 64 格裡改善 **≥ 42 格**，兩個都要滿足。
- identity／JPEG30／blur σ=2 **各自驗收**。
- 縮小規模時照實報數字，不換算門檻。

# 二、硬約束（使用者裁定）

1. **純顏色全域映射**：同一個 RGB 三元組在整張圖得到同一個輸出。沒有座標、
   沒有遮罩、沒有局部網路。
2. **人眼自然**，而且**由參數化的結構保證**，不是損失項也不是事後篩選。
3. **色偏只有兩種情形會難看**（使用者原話）：**出現高飽和色**，以及
   **和原膚色色差過大**。其他還好。
4. **抗淨化由載體性質保證**，不得進損失、不得進選解準則，只能事後量。
5. **防禦效果是主要目標**，不為了自然砍參數量。

## 已作廢，不是限制

- **擾動低頻不是目標**。它是這類方法的預設傾向，不是訓練目標也不是判準。
- **顏色類的淨化（灰階、灰世界、色階拉伸、CLAHE）不在本專案範圍內。**
  JPEG30 與 blur σ=2 要保留，那是驗收門檻。

## 五道被鑽過的自然度門檻

NIQE、平均 ΔE00、CVaR 尾端、臉框 ΔE00、NIMA——**全部被最佳化鑽過**。
NIMA 的失效最明顯：它把整張全綠的臉排在紅臉前面（`man_00` 原圖 5.372 →
全綠 **5.543**，比原圖還高），而它的整個動態範圍（5.12–5.40）比影像之間的差
（4.83–6.09）還小。CNNIQA 一樣平。CLIP 影像餘弦單調，但它量的是「離原圖多遠」，
是另一個振幅代理。**結論：自然度只能看圖。**

# 三、ΔE00 在求解中怎麼被限制

色差以 **augmented Lagrangian** 進入損失，不是解完再投影：

```
L = score + Σ_i [ λ_i·g_i + (ρ/2)·max(0, g_i)² ],   g_i = 量測_i / cap_i − 1
```

`ρ = 10.0`；`λ` 每 5 步更新 `λ_i ← max(0, λ_i + ρ·g_i)`。乘子會自己長到剛好讓
約束成立，不需要人調換算率；可行時懲罰為零，不會拿分數去換多餘的色差。

三個實作細節：

1. **兩份 CIEDE2000**。損失用可微的 `delta_e_torch`（公式照 Sharma et al. 2005
   的更正版，所有 `sqrt` 先 `clamp_min(eps)`，因為純灰 `C1=C2=0` 在人像上到處都是）；
   **量測與可行性一律走 skimage**。同一組 Lab 下兩者差 4.4e-15，端到端差約 0.003，
   來自專案的 `rgb_to_lab` 與 skimage 的 `rgb2lab` 最多差 0.005 個 Lab 單位。
2. **可行性在量化後的影像上檢查**：每 10 步做一次 `(x·255).round()/255` 的 PNG
   往返，因為交付的是 PNG。可行**且**固定抽樣的 `eval_score` 更好才存 checkpoint。
3. **交付最佳可行 checkpoint**。一次都沒可行過才退回 `fit_caps`（各段幅度同乘一個
   係數二分回上限），記在 `free_amplitude_shrink`，`free_feasible_step` 為 −1。

**為什麼要這樣**：舊做法是跑 150 步無約束再整體縮小，30 列裡 28 列貼住整圖上限、
**0 列**貼住臉部上限，因為整體縮放只能收縮、不能把預算從整圖搬到臉上。改成約束
進損失之後，同樣預算下穿透率從 1/25 變成 18/25。

**`deltae_cap` 管的是全圖逐像素平均**，所以「平均不超過 16」允許把預算集中在
某些區域或某個色相方向上。

**灰階在這裡是讀數不是淨化器**，作用在編輯輸出上，不是在編輯之前作用於防禦圖。

## 4. 兩條全域上界（`bounded_cast_curve`）

把硬約束三翻成兩條寫得進參數化的**全域常數上界**：輸出彩度對 RGB 立方體上
**每一個** `c` 滿足 `C*(T(c)) ≤ C_max`；落在膚色軌跡上的 `c` 滿足
`ΔE00(c, T(c)) ≤ d_max`（**有界，不是歸零**）。常數界沒有梯度，邊界上不會有跳變，
**結構上不可能產生斑塊**——先前 `skin_locus_curve` 用隨顏色變化的權重 `w(c)`，
斑塊大小是 `|∇w|·|F(c) − c|`。

參數化：三組 `(1,1,64)` 張量 `theta_l`／`theta_a`／`theta_b`，共 192 參數。控制點經
`tanh/√3` 映入單位球，再用非負、總和為 1 的 cubic B-spline 權重插值：

```
T(c) = Lab⁻¹( P₀(L(c)) + ρ(L(c))·z(L(c)) ),   ‖z‖₂ ≤ 1
```

`P₀` 是固定暖色色盤，`ρ` 是解析構造的安全半徑（由 Lab→RGB 導數界推導）。
**沒有輸出 clamp、沒有投影、沒有界限損失**，`project()` 是空操作。膚色帶是固定
暖色軌跡周圍 8 Lab 半徑的管帶，用 `ΔE00 ≤ (3/√2)‖ΔLab‖₂` 配置剩餘位移半徑。

兩條界互相牽制（彩度壓低，膚色被迫位移更多）：

| C_max | 12 | 16 | 20 | 24 | 28 | 32 | 40 | 48 | 64 |
|---|---|---|---|---|---|---|---|---|---|
| 最小可行 d_max | 55 | 47 | 40 | 32 | 24 | **17** | 17 | 17 | 17 |

`C_max` 到 32 以上 `d_min` 飽和在 17，所以 `(32,24)` 與 `(48,24)` 逐位元相同。

## 7. 兩個新載體（已撤回）

### `skin_locus_invariant`（160 參數）

膚色帶 Nagumo 不變集：寫平滑速度場、取時間一的流當映射，讓膚色帶映進帶自己。
張量 `theta_sigma (1,1,32)`／`theta_tau (1,2,32)`／`theta_gamma (1,1,64)`。
法向空間是二維（管帶固定 `L` 的截面是色度平面裡的圓盤），軌跡參數用 `L` 而非弧長。

**證出來的**：Nagumo 條件（帶邊界上法向速度為零，邊界上逐位元檢查）；**離散 RK4
也不變**——取 `window_outer = W − h·τ_amp`，`|u_n| ≥ W_o` 時四個 stage 全為零、`u`
逐位元不動，否則每個 stage 的取值點滿足 `|u| ≤ W`，增量是凸組合故 `|Δu| ≤ h·τ_amp`；
`L ∈ [0,100]`；帶內位移界；連續時間單射（Lipschitz 自治場）。
建構參數 `band_width=8`、`tau_amp=4`、`flow_steps=4` ⇒ `W_o = 7`、`W_i = 3.5`、`L_p = 5`。

**沒證出來的**：離散單射；色域；**帶外不出現新的高飽和**（`γ` 是速度不是輸出值，
給的是位移界不是輸出彩度的絕對上界）。

### `lab_axis_curve`（192 參數）

L／a／b 三軸各自索引的可分離曲線，三個 `(1,1,64)`。節點放在固定軌跡的色度值域上
（`a ∈ [−8.003, 23.024]`、`b ∈ [−8.0, 22.156]`、`L ∈ [0,100]`）。

**證出來的**：斜率落在 `(1/(1+r), 1+r)` = (1/6, 6) 對**任意有限 θ** 成立
（`s_i = K·w_i/Σw`，`w_i = 1+r·sigmoid(θ_i)`）；三軸各自嚴格單調、端點固定；
位移常數上界 `ratio·(hi−lo)`，`ratio = (1−s_min)(s_max−1)/(s_max−s_min) = 5/7`；
相對彩度界 `C*(out) ≤ C*(in) + √(D_a²+D_b²)`（實測常數 30.91）。

**做不出來的**：**絕對彩度常數上界與單射互相排斥**——值域有界的單調函式在區間外
必須是常數，那就不是單射。曲率界也拿不到（分段線性的 Hessian 無界）。
ΔE00 常數界在實務上是空的：`D_L=71.43`、`D_a=22.16`、`D_b=21.54` ⇒
`‖ΔLab‖ ≤ 77.83` ⇒ `ΔE00 ≤ 165.10`，遠大於 cap 16。

# 五、已經量到的結構事實

## 1. 振幅的來源是色度，人像上色度就是膚色

把 `−ΔE00` 當目標做梯度上升（多起點取最大，**回報的是下界估計，不是證明的天花板**），
量各族在 `man_00` 上到得了多大的振幅：

| 族 | 結構限制 | 天花板 |
|---|---|---|
| AdvCF（基準，三條曲線獨立） | 無 | **21.40** |
| 共用曲線＋有界偏移 `span 0.35` | 通道差 ≤ 0.35 盒寬 | 13.82 |
| 共用曲線＋輸出色階，`span 0` | 中間調不可能偏色 | 28.90（**解落在盒角，純綠**） |
| RGB 複合曲線 `span 0`，無色階 | 三通道同一條 | 12.89 |
| HSV 明度族 | 色相與飽和度**逐位元不變** | 8.42 |

`value_curve` 八張的天花板：8.41／13.32／21.40／9.83／22.39／14.07／8.61／14.34。
**八張裡有五張連基準的 16 都到不了。**

ΔE00 是**逐像素平均**，人像上膚色佔多數。**推論（已驗證）**：任何逐通道的自由度
都會被花在全域色偏上，因為色偏是把 ΔE00 做大最便宜的辦法——把逐通道的輸出色階
放開，天花板從 12.89 跳到 28.90，解直接落在盒角 `lift=[0,0.25,0]`、
`drop=[0.25,0,0.25]`，純綠。

## 3. 對比與亮度已經在可達範圍裡

現行載體兩端釘死 `F(0)=0`、`F(1)=1`、斜率界 [1/6, 6]：

- **對比**（S 形曲線）、**gamma／曝光式亮度**（抬中間調）都在族內，連「只調紅通道
  的對比」也在。求解器可以用，只是不太用（色偏更便宜）。
- **抬黑位／壓白位（輸出色階）整類不在可行域**。`lifted_curve_param` 補上了
  `T_c(x) = lift_c + (1 − lift_c − drop_c)·F_c(x)`，逐通道各一個 lift 和 drop，
  `lift_max + drop_max < 1` 保證不用鉗回，單調與斜率界都傳得下去。
  **設定檔寫好了，但從來沒有解出防禦圖、沒有跑過編輯、沒有任何位移數字**；
  只有一次振幅探針（天花板 12.89 → 28.90，解落在盒角、純綠）。

「只有對比亮度、不准變色」的直接量測就是第四節第 5 批：**約是基準的三分之一**。

# 六、被修正的說法（過度解讀清單）

這些是 Codex 在讀完全部資料與圖之後指出、並經核對成立的：

- **`bounded_cast_curve` 的預設形式是 `T(c) = P(L(c))`**——輸出只由亮度決定，
  同亮度不同色度的輸入得到同一個輸出。所以 −0.1032 ~ −0.1446 同時混著「限制膚色
  位移」與「捨棄輸入色度區別」兩件事，**不能全部歸因於自然度要求**。
  `C_max`／`d_max` 的耦合表也只屬於這個構造，不是所有映射的必要界。
- **0.018–0.027 不是普遍斜率**，那些「天花板」是梯度上升找到的**下界估計**。
  既不能據此說顏色映射沒空間，也不能精確扣掉 `out_no_id` 多出的 0.87 ΔE00。
- **`span=0` 的共用曲線不保證色相不變**：同一個非線性作用在不同 R、G、B 值上，
  不保證其相對關係不變。它保證的是「三通道不能各自獨立調整」。
- **`visited_knots()` 量的是支撐覆蓋，不是 Jacobian rank**，不足以證明被觸及的
  方向彼此獨立。
- **「結構保證都證出來所以自然度有保障」不成立**：證書只到 clamp 前的 Lab 端。
- **JPEG30／blur2 的振幅階梯記錄只有 ip2p 32 格**，淨化後的 inpaint 那一腿沒跑。
- **「LPIPS 大 = 指定編輯失敗」不成立**：防禦後的編輯圖照樣戴上了墨鏡，
  偏色與分層是從輸入帶過去的。

# 七、可重現性與實測過的坑

- **求解端在 900 步下跨卡不可重現**：同設定同種子的全圖 ΔE00 量到
  15.93／15.70／12.51。**每一批都要自帶對照臂，跨批比較不成立。**
- 即使同卡，`resample: true` 會讓解隨「該圖在批次裡的位置」而不同。
- **編輯端逐位元可重現**：同一格在兩張卡上四格 sha256 完全相同。

## 恆等起點的零梯度陷阱（踩過三次，形式不同）

1. **`FreeObjective` 的 `enc`／`cond`** 是差向量的範數，恆等點上是零向量，
   `torch.norm` 回傳零次梯度。`id` 權重歸零就一步都不動，交付原圖。
2. **`ChannelSpanCurveParam` 的恆等落在盒角**，`min(u, 1−u) = 0` 讓逐通道偏移的
   梯度**恰為零**，`init_jitter=0` 會讓整族靜默退化成一條共用曲線，不報錯。
3. **`fit_caps` 假設 `amplitude=0` 是原圖**。色盤類載體的零幅度是固定色盤，
   二分可能收斂到仍違反 cap 的解。

**新寫一個載體時，在設定檔實際會用的起點上跑一次 backward，逐個參數張量斷言
`grad.abs().max() > 0`，並寫成測試。**

## 遠端流程的十個坑

1. **一個 ssh 只能派一個 `nohup setsid ... &`**，串多個只有第一個會執行。
2. **`pgrep -f`／`pkill -f` 會匹配到自己的指令字串**——遠端 `pkill -f xxx` 會把
   執行它的那個 shell 一起殺掉。判定要看真正的 python 行程或改用 pid。
3. **`paper_baseline.py` 要整個分片跑完才寫 CSV**，看進度要**數 PNG 不要數 CSV 列**。
4. **shell 裡 `rc=$?` 前面不要放 `$(date -Is)`**，命令替換會覆蓋 `$?`。
5. **Python 寫 `.sh` 會變 CRLF**，遠端 bash 直接語法錯誤。本機寫好 scp 再
   `sed -i "s/\r$//"` 與 `bash -n` 驗。
6. **CSV 的合併鍵是 `arm`**，每個臂要給不同的 `--suffix`，否則靜默互相覆蓋。
7. **`--out` 目錄存在就拒絕啟動**的腳本，log 不要寫進輸出目錄。
8. **排程不可以在派解時挑好卡、幾小時後才拿去編輯**——那時候卡多半被別人佔走。
   **每一次用卡之前重新挑。**
9. **`edit_preflight.py` 預設跑資料集全部八張**，防禦圖只有四張時要給 `--images`。
10. **遠端 heredoc 裡有 `<` 會被當成重導向**；本機單引號字串裡有 `'` 會提前結束。
    複雜腳本一律本機寫好再 scp。

另：**先 `source ~/env.sh` 再 `cd`**（env.sh 會把工作目錄切走）；卡「空」要
沒有別人的 compute app **且**已用記憶體 < 1 GB，程式化判定用 `memory.used < 1500 MiB`；
**全局卡數由使用者逐次授權；未說明或說明不清時預設 6 張，所有 session、主機與排程合計**。

## 模糊與映射的交換誤差

`‖B(Tx) − T(Bx)‖ ≤ (M/2)·E_B‖x − E_B x‖²` 在形式上就是 **Jensen gap 的曲率界**：
B 是權重非負、和為 1 的平均算子時 `B(Tx) − T(Bx) = E[T(X)] − T(E[X])`，而
`m ≤ φ″ ≤ M` 給出雙邊界 `(m/2)σ² ≤ gap ≤ (M/2)σ²`。

- [arXiv 1707.08644](https://arxiv.org/abs/1707.08644)（Sharpening Jensen's Inequality）
- [arXiv 2601.05030](https://arxiv.org/abs/2601.05030)（Bounded Hessian 的雙邊界形式）
- [Gamma Correct Blurring](https://iquilezles.org/articles/gamma/)（影像處理側的對應現象）
- [arXiv 1809.08758](https://arxiv.org/abs/1809.08758)（Low Frequency Adversarial
  Perturbation：限制在 DCT 左上 `rd×rd`；JPEG q75 與 3-bit 下像素空間邊界攻擊完全
  卡住，低頻版可壓到 MSE ≈ 0.001，且不需知道施加了哪種轉換）
- [arXiv 2408.13114](https://arxiv.org/abs/2408.13114)（Controlled Learning of

## 目標函數那一側

- **PhotoGuard**——`enc`／`enc_target` 的來源。targeted 版最小化
  `‖E(x_def) − z_target‖ / ‖z_target‖`，把防禦圖的 VAE latent 拉到固定目標 latent
  （本專案用中性灰）。與無目標版的差別在梯度形狀：無目標版走任何方向都拿得到分，
  targeted 版整條路徑指向同一點，同樣預算走得比較遠。
- **AdvDM**——`diffusion` 的來源，最大化 `E_t ‖ε_θ(z_t,t,c) − ε‖²`。
- **Mist**（[arXiv 2305.12683](https://arxiv.org/abs/2305.12683)，底層論文
  [arXiv 2302.04578](https://arxiv.org/abs/2302.04578)，ICML 2023 Oral；
  repo `mist-project/mist`，查證 commit `99f5f3c`）——兩項融合：

  ```
  δ* = argmax_δ [ w · L_semantic(x+δ) − L_textural(x+δ, y) ]
  ```

  `L_semantic` 就是 AdvDM 的擴散訓練損失（**最大化**），`L_textural = ‖E(x+δ) − E(y)‖`
  把 latent 拉向固定目標圖 `y`（**最小化**）。兩個查證到的落差：論文 Eq (3) 寫 L2 範數，
  原始碼用 `nn.MSELoss(reduction="sum")`（**平方 L2 且對所有元素求和**），梯度方向
  等價但與 semantic loss 融合時尺度不同，直接影響 `w` 的有效值；
  `get_first_stage_encoding` 用**隨機 sample 不是 mean**，所以 textural loss 每次
  前傳都帶 VAE 後驗的抽樣雜訊。單次前傳只抽一個 `t` 與一個 `ε`。
- **SDS 版的 `sds` 項**：把 `∂ε_θ/∂z_t` 整項丟掉，只留
  `∂L/∂z₀ ≈ (2/N)·(ε_θ(z_t) − ε)·∂z_t/∂z₀`，`ε_θ` 只需一次無梯度前向，梯度只穿過
  VAE encoder。實作用 `value = mse + (surrogate − surrogate.detach())` 讓**回報值與
  `diffusion` 逐位元相同、梯度走 SDS**。**括號不能拿掉**——先加再減會在 float32 下
  吃掉 `mse` 的低位。時刻權重 `w(t)` 一律取 1，理由是 `diffusion` 對它的 k 個時刻
  是等權平均，加權重就不是同一個損失。
  加噪走 `z_t = (z₀ + σ_t·ε)/√(σ_t²+1)`，所以 `∂z_t/∂z₀ = 1/√(σ_t²+1)`；
  用該時刻自己的 σ 做無狀態加噪，避開 `EulerAncestralDiscreteScheduler` 的
  `step_index` 只在第一次呼叫時初始化的問題。
