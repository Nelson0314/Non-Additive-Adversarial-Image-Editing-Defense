# 知覺預算：把二值閘換成價目表

## 要解決的問題

本方法在**未淨化的防禦**上追不平對照組，而歸因指向「每單位失真換到多少
防禦效果」這個比值。IP2P 線、13 張人眼確認服從的影像上：

| 條件 | 位移／DISTS |
|---|---|
| DCT-Shield（eps 1.0、100 步） | **13.2** |
| 加性 delta（eps 0.04、latent_norm） | 6.8 |
| 紋理重相位（1000 步、低強度） | 6.6 |
| 紋理重相位（1000 步、帶邊緣） | 3.7 |

`RESULTS.md` 已把 DCT-Shield 那 2 倍歸因給 JPEG 量化階的約束，並註明
**那不是「加性」本身帶來的**（純加性只有 6.8）。

## 機制

`PhaseResidual.gate()` 是兩個因子的乘積：

```
gate[b, ω] = tex_gate[b] · freq_gate[ω]
```

`freq_gate` 由 `radial_gate()` 產生，是**二值**的帶通遮罩——歸一化半徑落在
`[r_min, r_max]` 內的頻格全部拿到同一個 `theta_max`。人眼不是這樣看的：
對比敏感度在中低頻達到峰值、往高頻單調衰減，同一振幅的擾動放在 r = 0.15 與
r = 0.9 上可見度差一個數量級。二值閘對兩者開同一個價，於是預算被平均撒在
看得見與看不見的頻帶上。

JPEG 的量化表正是一張以感知門檻定價的價目表。把它接到本模組的格點上，
`freq_gate` 就從「通／不通」變成「這一格值多少錢」。

## 構造

新增 `src/residual/perceptual_weight.py`：

```
freq_gate[ω] = radial_gate(ω) · w(ω)
```

`w` 由 `--freq-weight` 選擇，值域 (0, 1]：

| 名稱 | 是什麼 | 出處 |
|---|---|---|
| `binary` | 全 1，**逐位元等於加這個旗標之前** | — |
| `jpeg_luma` | 量化階正規化到最大值 1 | ITU-T T.81 (1992) Annex K 表 K.1 |

**座標對應按頻率而非索引**：8 點 DCT-II 的基底 `u` 對應 `u/16` cycles/pixel，
Nyquist（0.5）在 `u = 8`；`radial_gate` 用的歸一化座標 `fftfreq(block)·2`
是 `[-1, 1)`，1 即 Nyquist，故 `u = 8·f_norm`。表的索引只到 7，夾到 7 之後
雙線性內插——夾取只影響最靠近 Nyquist 的一圈，而那一圈的量化階本來就飽和。

量化階大 = 人眼在該頻率看不見 = 允許較多擾動，方向與「權重越大越放行」
一致，不取倒數。

實測的定價（`block = 32`、`r_min = 0.12`，通帶 477 / 544 格）：

| 半徑區間 | 格數 | 權重均值 |
|---|---|---|
| [0.12, 0.25) | 16 | **0.099** |
| [0.25, 0.40) | 39 | 0.126 |
| [0.40, 0.55) | 54 | 0.206 |
| [0.55, 0.70) | 77 | 0.399 |
| [0.70, 0.85) | 86 | 0.617 |
| [0.85, 1.00) | 106 | 0.721 |
| [1.00, 1.45) | 99 | 0.824 |

跨通帶約 8 倍的重新定價。通帶有效容量 `Σw/Σ1 = 0.544`，故同一個 `theta_max`
下動到的能量約減半——摸到同一個失真帶需要更高的半徑。

## 這不改參數化

- 仍是**非加性**：相位乘的仍是模長 1 的複數，幅度乘的仍是 `exp(g)`。
- `theta = 0` 的**逐位元恆等仍成立**（權重只縮放閘，閘只縮放 theta），
  由 `test_identity_at_zero_theta_survives_the_weight` 釘住。
- rfft2 的共軛對稱仍成立：權重是**相乘**而非相加，`fx = 0` 與 `fx = N/2`
  兩行在 `radial_gate` 裡已歸零，乘任何東西仍是零。
- `DECISIONS.md` 的「頻譜加性項不做」明文寫「閘的開度不受此限，兩者都只
  改變擾動被允許出現的位置，不改變參數化」。

## 怎麼驗收

`runs/ip2p_perceptual_weight` 對 `runs/ip2p_band_calibration/phase_r*`，
13 張人眼確認服從的影像，**唯一的自由變因是 `--freq-weight`**：兩邊都是
`phase_gain`、`gain_ratio 1.0`、`quantile 0`、`steps 1000`，半徑
1.5 / 2.0 / 2.5 / 3.0 逐點對得上（加權那邊另加 4.5 與 6.0 兩格，因為有效
容量降到 0.544，不延伸就摸不到同一個失真帶）。

判準是**同一個失真上限（PSNR ≥ 24、DISTS ≤ 0.15）內的 SigLIP 擋下率**，
位移與全指標並列照報。

若擋下率在帶內沒有改善，這個改動就是否決掉的——`w` 的形狀還有 CSF 一族可
換，但「知覺定價能買回那 2 倍」這個假設本身要先站得住。
