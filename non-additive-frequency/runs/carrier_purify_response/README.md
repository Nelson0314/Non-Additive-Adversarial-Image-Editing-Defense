# 四種內容形式的擾動撐不撐得過十二個淨化算子（純 CPU，未訓練）

**尚未進入 `docs/RESULTS.md`**，等使用者裁定。

`scripts/carrier_purify_response.py`。十張影像 × 十二個設定 × 十二個算子，
共 1440 列。**不需要 GPU，也不需要任何訓練。**

## 這份表回答什麼、不回答什麼

`runs/purifier_transfer/` 量的是**算子**：人造的帶限雜訊過了算子還剩多少。
這一份換掉自變數，改成**真正的參數化在真正的衣物載體支撐上渲染出來**的圖。
中間沒有擴散模型，因為問的是訊號處理的問題。

    energy   ‖P(x+δ) − P(x)‖ / ‖δ‖      擾動還剩多少
    align    cos( P(x+δ) − P(x), δ )     它還在不在原來的位置

**不回答效果。** 場是隨機起點、未最佳化的，量的是「這個參數化典型會產生的
內容有多耐算子」，不是「訓練出來的解有多耐算子」。最佳化會改變頻譜，兩者
可能不同——差多少要等 GPU 那批回來。依 `CLAUDE.md`「訓練方法的實驗：不設
判準」，**本表不得用來決定任何一批跑不跑**。

### 四件這張表說了的事

**一、帶限做到了它被設計來做的事。** `c = φ` 在模糊上是 0.76 / +0.79、
重取樣 0.79 / +0.82、C&R 串接 0.79 / +0.80；帶限之後三欄全部到
**0.97–0.99 / +0.99**。這與 `runs/purifier_transfer/` 第三節由算子側反推的
「結構要粗於 16 像素」一致，而這一份是在真實載體上直接量到的。

**二、S 的四個格點在這個讀數上幾乎分不開。** S=8 已經拿到 0.97，
S=32 是 0.98。**能把四個格點分開的東西不在這張表上**，只能來自效果讀數。
這正是那一批要跑的理由，不是不跑的理由。

**三、多邊形分割用 320 個參數拿到同一件事。** `voronoi_k64` 的抗低通與帶限
同級，參數量是 320 對 786 432。而且它的擾動 RMS **更小**（0.134 對 0.210）
——振幅小本來應該更難存活（`purifier_transfer` 第二節），它卻更好。
**差別因此不是振幅，是結構。**

**四、有限色數是這批裡唯一撐不住低通的。** `palette_k08` 過 JPEG 是
1.00 / +0.98，過模糊只剩 **0.60 / +0.68**，比 `c = φ` 的 0.76 還低。
與 `runs/carrier_survey/VORONOI.md` 的外觀讀數對得起來：調色盤壓的是色數，
**逐像素的指派場仍然是高頻的**，模糊吃的正是那個場。

## 二、幾何類那一欄：把 S 加粗只補得回一部分，而且會飽和

派工的格點是 S ∈ {8,16,24,32}。旋轉的 `align` 在那個範圍內單調上升
（+0.62 → +0.73）且沒有轉平，故另外量了四個**不派工**的粗格點，
看趨勢會不會續漲：

|---|---|---|---|---|---|---|

**會漲，但會飽和。** 旋轉 +0.53（`c = φ`）→ +0.62（S=8）→ +0.73（S=32）
→ **+0.80（S=128）**；裁切 +0.40 → +0.49 → +0.54 → **+0.59**。
S 由 32 加粗到 128（結構粗四倍、參數量少 16 倍）只各買到 +0.07 與 +0.05，
而且曲線已經彎平——**兩欄都停在遠低於 +1.0 的地方**。

低通那三欄則是在 **S=8 就已經飽和**（0.97 → 0.98），加粗完全沒有再買到東西。

兩件事合起來說的是：**內容場的粗細解決低通，解決不了登記。** 幾何類要的是
另一個軸（把擾動做成對小幅位移與旋轉不變，或在攻擊方那一側重新對位），
不是把 S 繼續加大。加大 S 還要付外觀與自由度的代價，而那兩項在這張表上量不到。

## 三、沒有被解決的那一欄

**幾何類算子對每一個形式都是開著的。** 裁切的 `align` 是 +0.12 到 +0.60、
旋轉是 +0.21 到 +0.80，而 `energy` 全部在 0.93–1.12——擾動原封不動地通過了，
只是沒有人替它對回去。十二個設定沒有一個把這一欄關掉。

（`crop_resize0.1` 的 energy 大於 1 是因為裁切之後升回原尺寸把擾動放大；
`quantize8` 的 1.02–1.06 是 `purifier_transfer` 第四節記過的放大器行為。）

## 四、三個限制

1. **隨機起點，未最佳化。** 見上。
2. **不是等失真比較。** 十二個設定的 RMS 落在 0.134–0.210，不是同一個值。
   方向對結論有利而非不利：RMS 較小的兩個多邊形分割臂存活率**較高**，
   而振幅小應該更難存活。
3. **十張影像，不是六張。** 影像清單由 `runs/ip2p_face_defence/clothing_plain_*`
   推導、未截斷；派工腳本取排序後的前六張，那六張含在這十張內。
