## 這一輪的實質結論（寫說明時的骨架）

**兩層論證，順序不能反：**

1. **第一層：重現。** 已通過（一半）。同一 κ = 0.06、N = 100、24 張真實照片
   × 20 種子下，PhotoGuard 兩根柱子達到或超過論文公布值——pg_encoder
   18.24／0.5518／0.2857／0.6903／0.6363（論文 18.84／0.6318／0.2118／
   0.7757／0.4131），五項中四項優；pg_diffusion 三項明顯優。**基準實作不是
   弱化版。** Lo 自己的 semantic attack 未重現，原因是協定只跑了一半
   （補充材料 §A 每個物件兩個編輯 prompt，Table 1 兩者一起平均，我們只跑
   `--prompt_index 0`）。使用者決定不追，semantic 改引用論文原數據並標註
   僅供參考，後續向作者提問。
2. **第二層：非加性在匹配失真下勝過加性。** 尚未成立。目前只有 n = 1。

**目前最重要的三個數字**（同一份資料、同一條評測路徑）：

| | 擾動 LPIPS | 編輯 LPIPS |
|---|---|---|
| pg_encoder（κ = 0.06） | 0.5514 | 0.6363 |
| site PF（τ_lpips = 0.10，收斂於 48 步） | 0.0992 | 0.2490 |
| site S（τ_lpips = 0.10，150 步跑滿未收斂） | 0.0163 | 0.0414 |

讀法：加性全秩用 **1/5.4 的可辨失真**取得 **0.41 倍的效果**。失真未匹配，
不是勝負判定，但兩條曲線各有了一個錨點。非加性臂（site S）弱六倍，而且
**只用掉 16% 的 LPIPS 預算就跑滿步數上限**——綁住它的不是 LPIPS 而是鈍化
約束。這對研究方向是不利訊號，但 n = 1，證據量不足以下結論。

**κ = 0.06 不是不可察覺的。** 實測擾動 LPIPS 0.49–0.55；放大後三種攻擊都在
皮膚與平滑區留下結構化的彩色波紋；使用者親眼確認「一眼看出」。對抗擾動文獻
普遍把 L∞ 球描述為 imperceptible，該描述在此不成立（LEDGER 2.21）。
