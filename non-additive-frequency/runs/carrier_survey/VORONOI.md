# Voronoi 結構化圖樣：參數少三到四個數量級，而且是第一個同時壓住色數與頻譜的

`src/defense/patch_param.py` 的 `PatchVoronoiParam`／`PatchVoronoiRandomParam`，
旗標 `--patch-seeds K`。移植自 *Structured Adversarial Camouflage via Voronoi
Diagrams*（arXiv:2606.17711），該篇最佳化種子點位置與每格顏色、胞結構由
Voronoi 圖決定、調色盤固定且可印。

## 構造

    seeds  s  (1,K,2)  歸一化座標
    palette p (1,K,3)
    w = softmax( −‖xy − s‖² / τ_v )
    field = Σ_k w_k · p_k

**用 softmax 不用硬 argmin**：argmin 對座標的導數處處為零，那是本專案記過的
零梯度陷阱。實測梯度確實同時通到座標與顏色（`tests/test_patch_palette.py`）。

## 讀數（同一張影像、真實衣物載體、隨機起點、**未最佳化**）

支撐內原圖 302 色，色數比以它為 1.0。

| 參數化 | 參數量 | 支撐內色數 | 色數比 ↓ | 譜斜率 drop |
|---|---|---|---|---|
| `free` | 786 432 | 3265 | 10.81 | +2.07 |
| `palette K=8`（S=1） | 2 097 176 | 251 | 0.74 | +2.39 |
| **`voronoi K=24`** | **120** | 218 | **0.64** | **+0.16** |
| **`voronoi K=64`** | **320** | 177 | **0.52** | +0.17 |
| `voronoi K=64` 隨機 | 0 | 201 | 0.60 | +0.08 |

## 兩件這張表說了的事

**一、參數量差三到四個數量級。** `voronoi K=24` 是 120 個參數，`free` 是
786 432 個——**6 500 倍**。而色數比反而更低（0.64 對 10.81）。

這直接對應 `docs/PIPELINE.md` §5 列的成本問題：單張 6000 步、約 50 分鐘。
參數量掉四個數量級，收斂步數**可能**跟著掉——那要實測，但它是同一批資料
順便就能回答的。

**二、它是第一個同時壓住色數與頻譜的參數化。**

| | 色數比 | 譜斜率 drop |
|---|---|---|
| `free` | 10.81（高） | +2.07（推向高頻） |
| `chroma` | 9.11（高） | +0.18 |
| `res 8` | 4.56 | **−0.45**（推向低頻） |
| `palette 8` | **0.74** | +2.39（推向高頻） |
| **`voronoi 64`** | **0.52** | **+0.17** |

調色盤壓色數但**不動**空間頻率（逐像素的指派場仍然是高頻的）；`res` 壓頻帶
但色數只到 4.56。Voronoi 兩邊都壓住——多邊形胞既是少數幾個顏色，也是空間上
平滑的。

**代價未知**：`docs/DIRECTION.md` §3.4b 的階梯說效果來自逐像素的高頻自由度，
而 Voronoi 把那個自由度砍得最兇。**效果的讀數要等 GPU。**

## 三個守門（都會靜默失效，故寫成測試）

1. **不與 `--patch-tile`／`--patch-res` 併用**：那兩個作用在可學張量的空間
   解析度上，而這裡的可學張量是**座標**不是場。給了就拋錯。
2. **不與 `--patch-palette` 併用**：Voronoi 本來就一胞一色。
3. **`geometry()` 覆寫**：父類算 `patch_palette_used` 時假設 `c` 是
   `(1,K,H,W)`，形狀對不上會拋 `IndexError`。逐列改記**實際渲染出來的胞數**
   ——種子點可以被最佳化推到重疊，那時胞數少於 K，只記 K 分不出來。

## 隨機對照

`PatchVoronoiRandomParam` **共用同一組色票**（由亮度分位數給，與最佳化臂
相同），只有種子點是隨機的。差別因此純粹在「胞長在哪裡」。

`docs/DIRECTION.md` §3.5 記過一個直接相關的事故：色彩網格的隨機解與最佳化解
**看起來一樣**。Voronoi 同樣會大幅改變外觀，沒有這個對照就分不出「像標記」
是學出來的還是參數化本來就長那樣——目前的讀數（0.52 對 0.60）顯示
**外觀主要由參數化決定**，與那次同型。
