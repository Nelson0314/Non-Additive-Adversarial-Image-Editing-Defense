## 2. 基準論文的做法（逐項照錄）

### 2.1 方法：semantic attack

加性，`x_adv = x + δ`，`‖δ‖ < κ`。損失是式 (5)：

```
L = ‖ Att(M ⊙ x_adv , c_a) ‖₁
```

其中（式 3）`Att(x, c_a) = Σ_{l=1..L} upsample_bicubic( A_l(x, c_a) )`，
`A_l` 是第 l 個 UNet cross-attention 層對 `c_a` 這個詞的注意力圖；
（式 4）`M = I( Att(x, c_a) > τ )`，由**原圖**的注意力圖二值化而得。

`c_a` 是**防禦方選擇要保護的內容**（例：`"woman"`），不是攻擊方的 prompt。
兩者在威脅模型裡屬於不同的人，故資料集必須分別宣告（§4）。

### 2.2 更新規則：Algorithm 1（timestep universal gradient updating）

```
δ ← 0
for n = 1..N:
    all_grad ← 0
    for t in T:                    # T 為取樣到的 timestep 集合
        對 x_adv 注入 t 對應的前向雜訊
        L ← ‖Att(M(x_adv^t), c_a)‖₁
        all_grad ← all_grad + ∇_{x_adv} L
    all_grad ← mean(all_grad)
    δ ← clip( δ + s·sign(all_grad), −κ, +κ )
    x_adv ← x − δ
```

逐 t 各自反傳再累加，而非把 T 個損失加總後反傳一次——兩者梯度相同但記憶體
差 T 倍，記憶體效率正是該論文的主要賣點（其 Figure 6）。

#### TF32 的取捨（實測，不是推論）

專案預設關閉 TF32（E28，見 `src/utils/device.py`），理由是跨機器數值可比與
BDIA 精確反演的精度。**本協定的路徑不走反演**（純像素加性，只有 VAE 編碼
與單步 UNet），故第二個理由不適用。實測：

| 攻擊（5 步） | TF32 關 | TF32 開 | 加速 | edit_lpips 變動 |
|---|---|---|---|---|
| `pg_encoder` | 0.8 s | 0.5 s | 1.6× | 0.4539 → 0.4561 |
| `semantic` | 10.8 s | 6.2 s | 1.74× | 0.3893 → 0.3950 |
| `pg_diffusion` | 19.0 s | 10.5 s | 1.81× | 0.4893 → 0.4919 |

指標變動 0.002–0.006，而本協定要分辨的效果量是 0.059（我們的 0.3466 對
PhotoGuard diffusion 的 0.4056），**差一個數量級**。故 L1 以
`WACV_ALLOW_TF32=1` 執行，並在報告中寫明。

#### 並行不是槓桿（實測）

峰值只用 11.4 GB 而卡有 96 GB，看似可同時跑多張。實測三個行程並行時，
每個的 `attack_seconds` 由 10.5 s 變成 **28.6 s**——慢 2.72 倍換 3 倍工作量，
吞吐量只增加 **1.10×**。單一行程已經把 SM 吃滿，**不要寫平行 driver**。
資料在 `runs/lo_par_1/`。

**可砍的地方，依效益排序。** 三個攻擊都是必要項；`pg_diffusion` 一項占 49%
（210 / 430 s），但它是 Table 1 的一欄，不能砍。**降種子數幾乎沒用**：評測
只占 20%，由 20 降到 5 僅省約 12%，卻讓平均值的標準誤差變大。若必須壓縮，
砍類別數而非每類張數（n < 2 時 `pstdev` 恆為 0，任何判定自動成立，
E25 曾因此產生 24 格假陽性）。

| 倒數第二 | 0.75 | 0.045 | 0.5318 | 29.64 | 比較可以接受 |

**這使兩件事成為有依據的敘述，而不是推論。**

1. **基準論文的失真預算在人眼上是可見的。** 對抗擾動文獻普遍把 L∞ 球描述
   為「imperceptible」，而 κ = 0.06 在本測試的影像上一眼可辨。本專案的
   研究問題「在匹配**人眼可辨**失真下比較」因此不是自設的難度，而是該領域
   既有評測的一個真實缺口。
2. **可接受的邊界落在 0.75κ 附近。** 使用者判為「比較可以接受」的那一級是
   L∞ 0.045、LPIPS 0.53。這是本專案第一個在 L∞ 軸上的人眼判讀——先前的
   判讀定出（τ_acut = 0.04、τ_chroma = 0.8）都在 LPIPS 0.05 的量級上。

**這個門檻判讀不改動 L1 的設定。** L1 仍在 κ = 0.06 上跑，因為那是論文寫死的
比較條件，改掉就不再是重現。該門檻的用途在 L4：非加性位置要與加性位置比較時，
匹配的軸是人眼可辨失真，而這裡給出了該軸在 L∞ 上的第一個座標。

**限制與此處相同**：單一影像、由 2 步解沿射線放大。L1 產生真實的 100 步解
之後應重做一次這道階梯，並擴到多張影像。

**這一項改變了兩件事的讀法。** 其一，本專案的加性實作落後基準（§6），
其中一部分可能只是預算差異——我們從未在接近 LPIPS 0.58 的預算上跑過任何
東西。其二，「匹配人眼可辨失真」這個研究問題因此更站得住：領域慣用的
L∞ 預算對應到的失真不是不可見的。
