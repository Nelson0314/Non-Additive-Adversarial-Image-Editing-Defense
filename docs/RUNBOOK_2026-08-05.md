### 0.3 四條硬規則

1. **GPU 工作不可並行。** 兩個 GPU 工作互搶必然變慢；CPU 密集工作（例如 pytest）
   與 GPU 工作並行時，實測把單張 SDEdit 由 222 s 拉長到 **30 分鐘以上**。
2. **所有腳本前加 `PYTHONIOENCODING=utf-8`。** 否則 cp950 編不了 `²`，
   症狀是腳本在**印出結果時**才炸，前面的計算全部白做。
3. **殺行程與啟動必須分成兩次 ssh 呼叫。** `pkill -f "<pattern>"` 的中括號技巧只避免
   模式字串自身被匹配；若同一條 ssh 指令的其他部分（例如 heredoc 寫出的啟動指令）
   含有目標的完整字串，正則會匹配到自己的 shell，整條指令在第一步就死掉。
4. **改動執行中的腳本不會影響那次執行。** Python 在 import 時把原始碼載入記憶體。
   要讓改動生效必須重跑。

### 0.4 資料保全

`runs/` 是唯一的證據來源，雲端容器會被刪除，實驗無法重跑。
**所有 CSV / JSON / log / PNG / HTML / PT 一律入版控。**

寫入任何新副檔名之前先跑 `git check-ignore -v <預計路徑>`。
`git status --ignored` 抓不到——檔案還沒寫出來時掃描結果是空的。
放行清單為 `.csv .json .md .log .png .html .txt .pt`，**`.yaml` 不在其中**。

## 4. 進度監察

**唯讀，不碰 GPU，不啟停任何行程。**

```bash
# 給 agent：單行機器可讀
python scripts/dashboard.py runs/b1 --json

# 給人看
python scripts/dashboard.py runs/b1 --watch 60

# 只看失敗
python scripts/dashboard.py runs/b1 --failed

# progress.json 壞掉時掃描產物重建
python scripts/dashboard.py runs/b1 --rebuild
```

### 狀態五態的意義

| 狀態 | 意義 | 該做什麼 |
|---|---|---|
| `pending` | 尚未開始 | 等 |
| `running` | 執行中 | 等 |
| `done` | 完成且產物齊全 | — |
| `failed` | **真的失敗** | 用 `--failed` 取全文，**回報使用者，不要自行重跑** |
| `skipped` | 結構上不適用（例如 N3 在低 τ） | **不是失敗**，不需處理 |

### 監察約定

- 輪詢一律用 `--json`，不要解析終端表格。
- 不要在 GPU 工作執行期間跑 pytest 或其他 CPU 密集工作（規則 0.3.1）。
- 不要自行判斷「這格失敗了重跑一次就好」——先驗實驗十次事後診斷都是
  「一個值被沿用到另一個對象上而且沒有症狀」，盲目重跑會把症狀蓋掉。

## 5. 失敗處理

| 症狀 | 可能原因 | 處置 |
|---|---|---|
| `CalibrationMismatch` | context 與校準表不符，通常是換了卡或改了解析度 | 看例外訊息列出的雙方內容。**不要放寬比對**，重跑段 0 校準 |
| `no kernel image is available` | torch 版本與卡不符 | 5090 需 torch ≥ 2.7 + cu128；V100 需 cu118 |
| 解碼出全黑圖 | SDXL VAE 在 fp16 下溢位 | VAE 改 fp32（V100）或全程 bf16（5090）。**不可改用 fp16-fix 權重**——那是換模型 |
| `element 0 of tensors does not require grad` | φ 沒進計算圖 | 檢查模組是否提供了四種能力之一；`CompositeResidual` 的成員是否都被 `disable()` |
| 找不到 `attn2` 層 | 模型不是 UNet 架構 | 確認用的是 SDXL 而非 SD 3.x（後者是 MMDiT，無 cross-attention） |
| 單張 SDEdit 耗時暴增到 30 分鐘 | 有另一個 GPU 或 CPU 密集工作在搶 | `nvidia-smi` 與 `ps` 查，停掉另一個 |
| `git pull` abort | `runs/` 未追蹤檔衝突 | 見 §1.2 的搬移作法 |

**禁止用 try/except 或條件跳過來掩蓋症狀。** 要找根本原因。
