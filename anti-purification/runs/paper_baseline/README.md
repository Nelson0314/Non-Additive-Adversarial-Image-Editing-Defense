# 第一層：三篇顏色論文在**它們自己的受害任務**上重現

`configs/paper_baseline_classifier.json`，`scripts/paper_baseline.py`。
48 張 ImageNet 驗證影像（ResNet-50 原本分對、信心中位 **0.997**）、
C&W logit margin、每篇自己的載體與預算。

## 為什麼要有這一層

要說「這三篇移植到擴散編輯的場景失效」，必須先證明**移植是對的**。沒有這一層，
「在 IP2P 上是零」與「實作錯了」在證據上分不開。

先前這條線沒有這一層，而且 `runs/ncf_ip2p/`、`runs/chroma/` **一張影像都沒存**
（本機與遠端都是 0 張 PNG），事後從 CSV 讀到的是 ΔE00 25–30、PSNR 7–8——那不是
三篇示例的樣子。`configs/recolor_paper.json` 那一族還帶著 `instruction`／`target`
鍵，屬於指令進迴圈的舊路徑（會高估防禦，2/15 對 1/25）。那些數字不能代表這些載體。

## 逐張看圖

- **`recoloradv_paper`**：自然照片，一層偏冷的色偏，襯衫由深藍轉暗紅。讀起來像
  換了白平衡的同一張照片。**這就是論文示例的樣子**，與本專案顏色線的
  ΔE00 16、21% 像素 ΔE00 > 25 完全不同族。
- **`advcf_paper`**：與原圖幾乎分不出來，只有很輕的色調曲線位移。產物在族內。
- **`ncf_paper_person`**：整張蓋上一層濃的鮭紅色調。仍讀得出是照片、是強色彩
  分級，但那個**均勻**的色調正是單一全域矩陣的痕跡。

## 三篇的重現程度不一樣，要照實分開講

**ReColorAdv 重現了。** 48/48，失真在論文量級，產物在族內。這一篇之後說什麼都
站得住。**它原本在這個 repo 裡根本沒有實作**——`carrier.kind="recoloradv"` 只
存在於舊設定檔，類別在 `6cb0f96` 那次裁剪時消失了，`src/defense/recoloradv_param.py`
是這次重寫的。

**AdvCF 只到 21/48。** 產物在族內（幾乎看不出改動），但成功率低於論文報的量級。
第一次用 `lr 0.01`／100 步只把 margin 從 +9.58 推到 +3.91，改成 `lr 0.05`／200 步
才有這個數字——分段線性曲線的參數尺度是 `1/K = 1/64`，步長要相應放大。還沒收斂
到論文的水準，**不能說 AdvCF 已經完整重現**。

**NCF 只到 17/48，而且失真明顯偏大**（ΔE00 20.4、PSNR 15.5）。這與已知的偏離
一致：論文**逐分割類別各挑一組分布再按面積混合**，需要它們的 Swin-T UperNet；
這裡是**單一全域 MK 矩陣配一個指名的 ADE20K 類別**。均勻的鮭紅色調就是這個
偏離在圖上的樣子。**這一篇的重現度最低，報告裡要標清楚。**

另外 NCF 的 `margin_start` 是 +3.50 而不是 +6.47：它 `reset` 之後的 render 已經
不是恆等，起點就帶著一部分色彩位移。這一點與其他三個臂不可直接並列。

## 對外可以怎麼說

可以說：**ReColorAdv 在它自己的受害任務上完整重現（48/48），產物是自然照片。**
不能說：AdvCF 與 NCF 已完整重現——它們分別卡在最佳化收斂與逐類別匹配上。
