# 可學補丁的抗淨化：比相位族耐洗，裁切最弱

`scripts/phase_retention.py`，來源是 `runs/ip2p_patch_direct/ig_comp_subj`
（補集支撐 ＋ `image_guidance` ＋ 主體加權）。兩張影像、三種子、十個算子、
共防禦參照一併記。空白地板另跑一格（`floor_all.csv`），非幾何類逐格扣除；
`crop_resize` 屬 `GEOMETRIC_KINDS`，換參照且地板恆為 0。

## 兩張影像的平均

| 算子 | 淨增益 | 佔 identity | 顏色族 16×16（參照） |
|---|---|---|---|
| identity | 0.6750 | 100% | 100% |
| auto_levels | 0.6750 | 100% | 99% |
| gray_world | 0.6634 | 98% | 98% |
| clahe | 0.6031 | 89% | 106% |
| jpeg 75 | 0.5611 | 83% | 100% |
| grayscale | 0.5304 | 79% | 97% |
| jpeg 30 | 0.5153 | **76%** | 107% |
| blur σ=2 | 0.5037 | 75% | 116% |
| blur σ=1 | 0.4357 | 65% | 105% |
| **crop 0.1** | 0.3103 | **46%** | 93% |

## 三件這張表說了的事

**一、比相位族耐洗很多。** JPEG 30 是 **76%**，相位族同欄是 **11%**
（`anti-purify/COLOR_AND_DECOY.md` §4.2）。

**二、裁切是最弱的一欄（46%）**，而且理由是構造性的：補丁是**局部**的，
裁掉一部分就少一部分。顏色族在這一欄是 93%，因為它的擾動鋪滿全圖。

**三、比顏色族差一截。** 顏色族十欄是 93–116%，補丁族是 46–100%。
但顏色族那個工作點的**產物不自然**（`runs/ip2p_color_hunt/README.md` 一之二節），
兩者不是同一個交換條件。

## 限制

1. **只有一個工作點**（補集 ＋ IG ＋ 主體加權）。5% 方塊那一格沒有測，
   而它的失真低得多，衰減形狀不能從這一格外推。
2. 只有兩張影像。
3. `impress`、`gridpure`、`fdpure` 三個針對性最強的算子沒有測。
