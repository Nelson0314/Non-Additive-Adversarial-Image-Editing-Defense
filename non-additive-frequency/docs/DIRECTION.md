# 方向：防禦以什麼方式進入影像

## 走過的兩段

**一、頻域／相位。** 原本的目標是以外掛模組的形態做非加性的影像防禦，
把擾動放進相位而不是像素，並希望它同時能抗編輯。量到的抗淨化形狀是
**只對 JPEG 有一點抗性**，模糊與重取樣幾乎全數抹掉。該線已停止。

**二、顏色與色調。** 走過的方法共同的性質是**防禦都在往影像的高頻加東西**，
而那正是淨化最先抹掉的頻帶。於是轉向色彩自由度：一件衣服的顏色不承載身分，
整件換色仍然是一張正常的照片，所以失真預算可以開得比任何 `L∞` 球大，
而且改動落在低頻。

## 現行的兩個載體

**整圖顏色濾鏡。** 一個 `顏色 → 顏色` 的映射套用到整張照片。

**衣物換色。** 同一個 `顏色 → 顏色` 的映射，但支撐只有衣物：ATR 的衣物類別
經導向濾波貼回真實的衣緣、扣掉 MTCNN 的人臉框、向內侵蝕、向內羽化
（`src/defense/ncf_runner.py` 的 `ncf_support`）。每一步都只會**移走**權重，
所以支撐外的像素逐位元照抄原圖。

兩個載體的保護性質不同，不可互相推定：衣物載體上人臉像素逐位元不動，而整圖
濾鏡的支撐就是整張照片，**人臉在支撐內**，談不上「不動主體」。整圖濾鏡那一
側要看的是身分讀數與 `gate_*` 欄位，不是逐位元相同。
