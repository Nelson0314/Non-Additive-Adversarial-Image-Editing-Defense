原載體將 `(a,b)` 位移與亮度曲線分離：`ab'=ab+d(ab)`、`L'=100F(L/100)`。

其編輯圖保留相應色調。`man_01` 的太陽眼鏡及制服等編輯仍可見，
`woman_00` 的安全帽格則出現重複人物／安全帽。這些具體格子說明顏色傳遞與

全圖 ΔE00 中位數 13.20 尚未碰到 16，並不表示所有約束均有餘裕。
臉框、同色支撐及彩度限制可先起作用。非幾何保留率 1.03946 也未顯示
「淨化洗掉防禦」是此處的主要差距來源。擴大色度半徑或填滿全圖 ΔE00，
只能改變工作點，不能據此推導固定輸入 LPIPS 下的主體位移增量。

## 3. 候選方向與排序

**第一順位：全域三角式 Lab 耦合，採用為 `ab_prism`。**
第一階段以原像素的 `(a,b)` 混合低次數單調亮度曲線，第二階段依輸出亮度
平滑改變色度旋轉、正比例縮放與平移。前者增加「色度決定明暗斜率」的自由度，
後者提供陰影、中間調及亮部的連續調色。兩階段在 Lab 域皆可逆，沒有位置輸入、
局部濾波、臉部／背景混合或任意高頻 LUT。此方向以受限的色彩 Jacobian 改變
主體材質的對比反應；假說針對固定失真下的編輯反應分配，並非增加色偏幅度。

**第二順位：保留 RBF 色度位移並加入低秩亮度條件。**
以二次 Bernstein 基底在三組 `(a,b)` RBF 位移間內插，並維持單一單調亮度曲線。
相同色度的不同亮度取得不同位移，且仍為逐像素全域映射。此方向與 `ab_warp`
最接近，便於消融，但多組任意位移的色度 Jacobian 不保證正定或可逆；縮小核寬
還會增加色彩空間中的局部起伏。其新增自由度主要仍用於調色，須與等失真隨機
對照一起量測，不能以耗盡 ΔE00 當作理由。

**第三順位：固定載體，改用無指令編輯的交換殘差目標。**
以相同噪聲比較 `N(F(x))` 與 `F(N(x))`，其中 `N` 是無文字條件的短編輯鏈，
藉此將單純穿過編輯的色彩轉換與編輯器非交換反應分開。此目標不使用臉框權重
或攻擊提示，亦不倚賴平坦的身分餘弦。然而它仍是代理，正規化、梯度截斷及
跨提示轉移須另行校準，並增加原圖短鏈成本。本輪不把目標變更與載體變更綁在
同一臂；後續只在相同載體、相同輸入失真及相同求解步數下比較此目標。

## 4. 採用方向的精確定義

### 4.1 參數與函數

令 `u=L/100`、`c=(a,b)`、`b(r)=r/sqrt(1+r²)`。`b` 將無界原始參數映到
`(-1,1)`，不執行參數投影。其導數為 `(1+r²)^(-3/2)`，仍隨大參數減小，
因此輸出紀錄包含 `raw_abs_max`；不以有界座標宣稱沒有飽和。

色度錨點為 `{-90,-45,0,45,90}²` 共 25 點，`sigma=45` Lab 單位。

```text
phi_i(c) = exp(-||c-c_i||²/(2 sigma²)) / sum_k exp(-||c-c_k||²/(2 sigma²))
s_ij = exp(log(1.5) b(r_ij)), j=0,1,2,3；s_i4=1
d_j(c) = sum_i phi_i(c) s_ij
B_j,n(u) = C(n,j) u^j (1-u)^(n-j)
I_j(u) = sum_{k=j+1}^5 B_k,5(u)
F(u,c) = sum_{j=0}^4 d_j(c) I_j(u) / sum_{j=0}^4 d_j(c)
L' = 100 F(u,c)
```

`I_j/5` 是四次 Bernstein 基底的積分，分子分母的 `1/5` 相消。
亮度參數為 `25×4=100`；固定第五個係數去除整組斜率同乘常數的冗餘。
對固定 `c`，`F(0,c)=0`、`F(1,c)=1`，且 `4/9 < ∂F/∂u < 9/4`。
亮度曲線為五次多項式，不設影像中的分段界線。

令 `v=L'/100`、`h_k=B_k,2(v)`，三組調色參數各含旋轉、尺度及二維平移：

```text
theta(v) = (12 pi/180) sum_{k=0}^2 h_k b(q_k0)
g(v) = exp(log(1.25) sum_{k=0}^2 h_k b(q_k1))
t_k = 20 (q_k2,q_k3) / sqrt(1+q_k2²+q_k3²)
c' = g(v) R(theta(v)) c + sum_{k=0}^2 h_k t_k
y = clip_[0,1](LabToRGB(L',c'))
```

因此旋轉不超過 12 度，正比例尺度介於 0.8 與 1.25，平移範數小於 20 Lab。
調色共有 `3×4=12` 個參數，總數為 **112**。既有 `ab_warp` 存放
`7×7×2+16=114` 個參數；本設計改變函數結構，沒有依靠大幅增加參數數量。

第一階段保留 `c` 並單調映射 `L`；第二階段保留 `L'` 並對 `c` 作正尺度相似變換。
兩階段的 Jacobian 行列式分別為 `∂F/∂u` 與 `g²`，乘積為正。
此論證限於色域裁切與量化之前；RGB 裁切仍會丟失資訊，故紀錄 `clip_fraction`
並保留防禦圖檢視。低次數、寬核、正斜率及有界調色構成外觀先驗，
自然度不交由 NIQE、平均 ΔE00 或 CVaR 懲罰來建立，也不宣稱數學可逆性等同自然度。
相同的 RGB 像素在任何位置均得到相同輸出；影像內容可影響求解所得參數，
固定參數後的 render 不讀座標、臉框、鄰域、遮罩或影像統計量。

### 4.2 約束集合

臉框固定為原圖最大偵測框經既有 `expanded_box` 擴張的範圍。
其用途限於身分量測、臉框色差與膚色中心校準，不產生 render 的空間權重。
`skin_colour_support` 依臉框中 `(a,b)` 中位數定中心，取原圖所有距離中心
不超過 12 Lab 的像素；此集合跨越全圖，不以位置決定膚色保護。

| 約束名稱 | 完整上界 |
|---|---|
| `frame` | 全圖平均 ΔE00 ≤ 16 |
| `face_box` | 固定臉框平均 ΔE00 ≤ 8 |
| `skin_colour` | 原圖同色集合平均 ΔE00 ≤ 8 |
| `chroma_p95` | 輸出 Lab 彩度 p95 ≤ 原圖 p95 × 1.15 |
| `input_lpips_upper` | `P(y) ≤ T_i + 0.0025` |
| `input_lpips_lower` | `2T_i-P(y) ≤ T_i + 0.0025`，即 `P(y) ≥ T_i-0.0025` |

`P(y)=piq.LPIPS()(y,x)`，採既有 VGG 定義、`[0,1]` RGB、512×512，
凍結指標模型參數並保留對 `y` 的梯度。上下界以相同的正分母 `T_i+0.0025`
進入 solver，避免將下界轉成倒數而在恆等映射附近產生奇異值。
預設 `T_i` 讀取 `lab/results/fidelity.csv` 中 `arm=ab_warp` 的八張逐張 LPIPS，
數值即第 2 節第二欄。這些 CSV 數值四捨五入至四位，誤差至多 0.00005；
正式校準須保留未四捨五入值與來源 PNG 雜湊。**平均 0.301 不作為每張圖的共同目標。**

六道約束全部交給 `Cap` 與既有 `optimise_carrier`。色差 soft 使用共用的
`delta_e00_torch`，hard 在量化張量上使用同函數的 float64 路徑；最後另以原專案
skimage `delta_e00` 檢核三個色差上限並記錄。任一獨立檢核超界即報錯，
不修圖、不縮放，也不把超界 PNG 當成可行輸出。此 hard 後端與舊臂的差異必須
保留於實驗紀錄；外部 fidelity 表仍統一採 skimage 定義。空臉框、空同色集合、
遺漏 LPIPS 目標及非正上界均明確報錯。

### 4.3 求解設定

| 項目 | 設定 |
|---|---|
| 初始化 | 所有 112 個 raw 參數獨立 `Normal(0,0.03²)`；種子 0；非恆等起點 |
| 最佳化器 | 既有 solver 的 Adam；900 步；學習率 0.02 |
| 學習率排程 | cosine；最終倍率 0.2，即 0.004 |
| 增廣 Lagrange | `rho=10`；乘子初值 0；每 5 步更新；1 次 restart |
| checkpoint | 每 10 步及最後一步檢查量化圖；固定驗證抽樣分數選最佳可行點 |
| probe／log | 每 50／100 步；保留 solver 的起始及終點紀錄 |
| 代理目標 | 原 `FreeObjective`；`id=1.0, enc=0.5, cond=1.0` |
| 代理抽樣 | `k=4, steps=50, chain_steps=6, grad_steps=1, s_i=1.5` |
| 重抽與空間權重 | `resample=True, face_weight=0.0`；噪聲種子 0 |

分數仍為 `id - 0.5 tanh(enc) - tanh(cond)`；`enc` 分母為原圖 VAE latent
範數，`cond` 為各原圖噪聲預測範數，不改成微小殘差分母。原實作會取得空字串
embedding，沒有讀取攻擊提示；因此精確敘述為「無攻擊文字條件」，而非
「從不呼叫 text encoder」。既有身分項僅為可比性保留，不增加 ArcFace 項或其權重。
`free_term_*` 與 `1-tanh(term)²` 一併記錄，後者是飽和程度的讀數，
不是編輯端效果的證據。

`project()` 只驗證有限值，不修改參數。共用 solver 在無可行 checkpoint 時會
進入 `fit_caps`；新載體拒絕該路徑的 `set_amplitude` 呼叫並明確報錯。
最佳 checkpoint 載入後只接受原幅度 1。無可行點的結果保留錯誤原因與 log，
不事後投影、不二分縮放，也不以增加步數的自動重試隱藏校準狀態。

## 5. 成本估計

基準為八張、各 900 步共 8.1 GPU-h，後續鏈約 1.5 GPU-h，共 9.6 GPU-h。
新載體沒有額外擴散呼叫；新增成本為 LPIPS 上下界、float64 色差檢核與純張量映射。
目前上下界分別呼叫 LPIPS，因此估計包含每步兩次 LPIPS 前向及相應反傳。
以原求解時間的 1.10–1.20 倍編列，八張為 **8.9–9.7 GPU-h**，
加後續鏈約為 **10.4–11.2 GPU-h**。此數字是工作量估算，沒有以 CPU smoke
推算 GPU 吞吐量；後續先記錄前 50 步時間，再照 900 步比例報告實測預估。

1.5 GPU-h 沿用交接文件的保守鏈成本。交接文件仍以 64 格編輯及 448 格淨化後
編輯描述舊鏈；本協定只跑 ip2p，實際格數為 32 與 224，不增加 inpaint 以湊成本。
純 ip2p 鏈的時間須另行記錄，不先假設精確減半。

主錨點最低比較包包含新臂、重新校準的 `colour_curve_ours` 及五組新函數族隨機
對照，既有 `ab_warp` 直接作錨。兩組 900 步校準估計 17.8–19.4 GPU-h，
七條後續鏈估計 10.5 GPU-h。隨機候選上限 `8×4096=32768` 張，
若每個候選含校準量測需 0.1–0.4 秒，另計 0.9–3.6 GPU-h；合計
**29.2–33.5 GPU-h**。候選吞吐量為明示的規劃假設，須報告實際候選數與時間。
額外失真錨點、共同約束比較及舊函數族隨機對照另計，不包含在單臂成本中。

## 6. 僅限 ip2p 的評估規格

### 6.1 固定資料、編輯與分母

採用既有八張 512×512 RGB 人像及四條 `edits.ip2p` 提示，提示依序為太陽眼鏡、
警察制服、安全帽、蝴蝶結。防禦求解不使用提示。攻擊端固定
`timbrooks/instruct-pix2pix`、`s_t=7.5`、`s_i=1.8`、50 步、種子 20260812，
四個提示共用同一張防禦圖。沿用既有 `edit_preflight/ip2p_si18` 及淨化後
`undefended` 的 PNG；記錄其雜湊，不重新產生未防禦分母。

淨化僅含 `jpeg30/50/80`、`blur1/blur2`、`crop_resize0.1`、`rotate15`。
前五種非幾何與後兩種幾何分開彙整；幾何分區依現行讀數程式同步處理。
不執行 inpaint，不將其既有列混入本表。

### 6.2 逐張等輸入 LPIPS

1. **主錨點**為每張既有 `ab_warp` PNG 的 `T_i`。以未四捨五入 LPIPS 重新
   整理目標 CSV，但不改動既有圖及其編輯結果。新臂從非恆等起點受約束求解。
   `colour_curve_ours` 在另存於 `lab/` 的評估 adapter 中使用既有
   `ColorCurveParam(pieces=64,radius=5,bound_mode='advcf')`、900 步、學習率
   0.05 與原 `FreeObjective`，加入相同 LPIPS 上下界重新求解；不縮放舊成品。
   `ab_warp` 類別及 CLI 的預設行為不修改。
2. 每個 checkpoint 的可行性均在 8-bit 量化圖上判定；各臂要求
   `|P_i-T_i|≤0.0025`，並列出所有臂兩兩差。任兩臂最大差為 0.005。
   LPIPS、ΔE00、PSNR、L∞、rms、裁切比例、臉框及同色色差逐張報告，
   不宣稱等 LPIPS 同時等化其餘失真。
3. **次錨點**固定為 `0.50T_i` 與 `0.75T_i`，在看編輯結果前決定。
   每臂各自從原圖重新求解；不沿成品插值、不外推位移。三個錨點用於畫出
   主體／全圖位移相對實際輸入 LPIPS 的曲線，以檢視增量是否只來自多付失真。
4. **原生約束表**保留各臂原本色差條件：`ab_warp` 與新臂四道上界，
   `colour_curve_ours` 為原本全圖 ΔE00≤16。另建**共同約束表**，三個函數族
   全部使用本文件四道色彩上界及同一 LPIPS 帶。此表中的兩個舊載體由 lab
   adapter 重新求解，無可行點同樣報錯；不把原生約束差異稱為函數族收益。
5. 某張在 900 步內沒有可行 checkpoint 時，保留該張、目標、最近檢查值、
   每道約束殘差及錯誤。32 格表的四個相應格子明確標示未校準，不補零、不刪列、
   不用寬鬆目標代替；配對平均同時列出涵蓋的影像／格數。無完整八張配對時，
   不產生假稱完整 32 格的平均。`woman_02` 的 T=0.5129 也適用相同規則。

本輪交付的是新臂與其主錨點求解入口；舊載體的評估 adapter、隨機候選生成器及
跨臂報表屬後續實作項目。下列抽樣規格固定其行為，不借用會事後縮放的
`randomise_carrier`。

### 6.3 同函數族隨機對照

新臂的隨機對照使用**同一 `AbPrismParam`**、相同 112 維參數、核寬、曲線次數、
RGB 轉換及量化。每張圖、每個錨點最多抽 4096 組完整 raw 參數。候選 `j` 的
種子為 `100000 + 10000*i + j`，`i=0..7` 對應第 1 節影像順序；
依該種子先從 `{0.03,0.1,0.3,1,3}` 等機率選擇標準差，再抽 112 個獨立常態值。
每一候選是一次完整抽樣，不將既有候選乘上另求得的幅度。

每組候選僅檢查四道色彩上界、量化後 LPIPS 帶及獨立 skimage 檢核。
按 `j` 順序取最先合格的五組，分別形成五個隨機 replicate；不看
`FreeObjective`、編輯位移、blocked 或提示來篩選。未達五組時報告實際數量，
保存所有候選的種子、原始參數、LPIPS、每道約束值及拒絕原因，不能悄悄放寬上限。
同一候選庫可檢查三個錨點，避免以編輯結果驅動追加抽樣。

對新臂，每格報 `D_opt - mean_r D_random,r`，分開列主體及全圖，
用以描述同函數族內的最佳化增量。另報 `D_new,opt-D_old,opt` 的兩組配對差。
這兩類差值分別涉及最佳化與載體，但不足以單獨識別純函數族效應。
為進一步拆分，共同約束表另對 `ab_warp` 與 `colour_curve_ours` 各抽五組
同類隨機對照：分別對其原始參數抽樣並執行該載體原有的參數域映射，
只作候選拒絕抽樣，不縮放輸出；種子再分別加 1000000 與 2000000。
各族均使用相同標準差混合及 4096 次上限。

完整分解報告 `mean(D_new,random)-mean(D_old,random)`、
`D_new,opt-mean(D_new,random)`、`D_old,opt-mean(D_old,random)`，
以及兩個最佳化增量之差。各項保留抽樣分布及可行率；隨機參數先驗本身也影響
平均值，故將此稱為「指定抽樣分布下的函數族差」，不作無條件的因果宣稱。

### 6.4 讀數、圖像與報告形式

主要讀數為 32 格 `disp_lpips_subject`；並列 `disp_lpips_full`、背景位移、
blocked、SIGLIP 原值及既有 threshold=0.837。主體不是臉框，分區沿用原圖的
既有主體支撐；該支撐只供讀數，不輸入新載體。每個配對差報平均、中位數、
正差格數與全部逐格數字。提示屬同張影像內重複量測；不把 32 格當成 32 個
獨立人物。區間使用以影像為群集的 bootstrap：種子 1729、10000 次、有放回
抽八個影像群集，每次保留四個提示；隨機對照另列五組 replicate 的離散度。

淨化後報全圖及主體的位移原值與保留率，非幾何、幾何分表。
身分餘弦低於既有 0.55 的格子照列並標記分母可比性，不刪除。
以匿名臂名並列原圖、防禦圖及四種編輯圖，固定曝光與縮放，逐張記錄
膚色偏移、過飽和、色帶、髮際／領口光暈、臉框環、材質對比，以及提示產物。
無損防禦 PNG 與原尺寸編輯 PNG 同時保存。

既有色彩族在成本—位移線上相差約 ±6%，同設計內最佳化相對隨機約增加
32%–61%，兩者作為既有觀察背景，不設成新臂的門檻。
「離開既有線」的操作性問題是：在同一張原圖、同一輸入 LPIPS、同一約束集合
及同一編輯設定下，主體位移的配對差與其跨錨點形狀如何變化；並由隨機對照
拆分抽樣函數族與最佳化增量。文件只預先指定校準及讀數，不宣告成立、失敗或優勝。

## 7. CPU 與靜態檢查的界線

`lab/code/check_ab_prism.py smoke` 使用一張合成 64×64 RGB 張量，實際執行
新載體 render、六道約束 soft/hard、梯度、有限差分、色彩 Jacobian、
空間重排等變性、checkpoint 存取及既有增廣 Lagrange solver 的四步 CPU 求解。
LPIPS 注入點使用明示的合成 MSE 函數，沒有載入 VGG 或任何編輯模型；
因此此檢查驗證約束連接與數值運算，不提供新臂 LPIPS 校準或編輯效果數值。
另以子程序執行不可行帶的求解，核對實際 exit=1 及禁止 `fit_caps` 的明確錯誤。

原 arm 的整檔 SHA256 在修改前為
`555a9e1b44582fcb7bdc924d7ded7991340e5e3854c2d8f393a0a47c2ca61753`。
`defaults` 檢查先核對此雜湊與 `git show HEAD` 的完整位元組，再將修改前後
`AbWarpParam` 的完整 class AST 原樣執行，使用真實共用 Lab 轉換，在合成張量上
比較預設初始化、四次 Adam 更新、梯度、render 及量化結果的逐位元一致性。
此方式沒有模型 stub，也不執行原 arm 頂層的擴散／指標前端。
