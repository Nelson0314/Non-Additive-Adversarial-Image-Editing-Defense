# 新穎性還剩什麼：一次盤點，與一個沒有被佔走的框架

**這一份回答一個具體的擔憂**：本專案越做越像 DCT-Shield。這個擔憂不是多慮，
下面第一節用我們自己的量測把它量出來。第二節是這個領域 2026 年走到哪裡，
第三節逐條檢查還沒被佔走的地，第四節提一個定位——**它不是再一個頻域旋鈕**。

既有的定位分析見 [SURVEY_POSITIONING.md](SURVEY_POSITIONING.md)（候選 A–E 與
排序），本頁不重複，只補上該檔之後才查到的東西與一個新的框架。

---

## 第一節 新穎性侵蝕：逐條盤點

**每一條都是被我們自己的量測拆掉的，不是被審稿人。**

| 曾經的差異點 | 現況 | 證據 |
|---|---|---|
| 「只旋轉相位、幅度譜逐位保留」 | **已放棄。** 可學幅度增益定案開啟，新穎性主張改寫為「頻譜重參數化」 | `DECISIONS.md` |
| 「純非加性」 | **放棄一半。** 加性下限 0.04 是兩個主線設定之一；而**純加性下限單獨就到得了失真帶並拿 12/13**，等失真下唯一有鑑別力的軸是 PSNR（差 2.5–2.9 dB） | `ip2p_floor_only` |
| 空間選擇性（逐區塊可用預算 Gini 0.531 對 DCT-Shield 的 0.000） | **量不出價值。** 收緊（`quantile` 0.3／0.6）三者在雜訊裡；讓它更均勻（加性下限 0.531→0.163、`complement_rank`→0.078）反而更好或幾乎免費 | `ip2p_quantile_sweep`、`allowed_budget_gini.csv` |
| 「殘差對準影像內容」 | **分不開。** 本方法 0.894／0.897，DCT-Shield 也有 0.797–0.845，差距小於條件內的離散度 | `residual_texture_alignment` |
| 「效果來自實現特定的結構」 | **否證。** 區塊置換後兩者保留率差 0.0011 | `residual_permute` |
| 量化交付 | **這就是 DCT-Shield 的核心技巧**（把擾動放在量化格點上），我們是把它搬過來 | `ip2p_deliver_jpeg` |
| 整併版（旋轉作用在整數係數上） | **動作空間與 DCT-Shield 相同**：78–85% 的整數位移落在它的 `ε=1` 球內；設計文件自己寫著只能主張「約束不同」不能主張「動作不同」 | `ip2p_dct_unified`、`dct_phase_design` §5.3 |

**剩下的差異只有兩項**，而兩項都不是方法強度：

1. **參數化的形式**（乘性重參數化 vs 加性位移）——買到的是**感知代價**
   （等 DISTS 下 PSNR 較好），不是防禦強度。
2. **失真的型態**（我們的殘差是紋理狀、它的鎖在 8×8 格點上）——這是可量的
   指紋差異，但沒有轉成任何一個讀數上的優勢。

**擔憂成立。** 再往「DCT 域的另一個旋鈕」走，只會讓這張表更長。

## 第二節 這個領域 2026 走到哪裡

本輪新查到、且與定位直接相關的六筆。

### 2.1 攻擊側已經走到「模型不匹配」，而且贏了

**Purify Once, Edit Freely: Breaking Image Protections under Model Mismatch**
（[arXiv:2603.13028](https://arxiv.org/abs/2603.13028)）。兩個淨化器——
`VAE-Trans`（latent 空間投影）與 `EditorClean`（指令引導的 DiT 重建）——
**不需要接觸受保護影像或防禦內部**，在六個防禦方法上都成功，PSNR 升 3–6 dB、
FID 降 50–70%。結論逐字是：保護方法為特定模型設計，攻擊方換一個架構就失效，
**該領域需要在模型不匹配下重新評測、並重新設計**。

**對本專案的意義有兩面。** 不利的一面：所有「我方在某個算子上勝過某個對手」
的比較，價值都被這一篇壓低了。有利的一面：**它把「診斷型貢獻」的相對價值抬高**
——機制分析不會因為換一個攻擊模型就作廢，而勝負表會。

### 2.2 「抗預處理」實際上已經走出純擾動的範式

**GuardDoor**（[arXiv:2503.03944](https://arxiv.org/abs/2503.03944)）用的是
**保護性後門**：模型提供者微調影像編碼器、影像擁有者貼上觸發器，攻擊方一編輯
就得到無意義的輸出。它明確以「傳統對抗擾動撐不過壓縮與加噪」為動機，而它換到
的穩健性代價是**必須有模型提供者配合**。

**對本專案的意義**：這是一個獨立的證據，說明「讓純擾動撐過預處理」這件事難到
讓人願意去改模型。**它支持把「限制」寫成貢獻**，而不是再試一個旋鈕。
本專案的白盒 ＋ 外掛模組假設不允許走這條路（`GOAL.md`）。

### 2.3 其餘四筆的方向

| 論文 | 方向 | 與本專案 |
|---|---|---|
| Universal Image Immunization via Semantic Injection | **通用**（影像無關）的免疫擾動 | 與 `GOAL.md` 已否決的 amortized generator 同族 |
| TDAE: Towards Transferable Defense Against Malicious Image Edits（[arXiv:2512.14341](https://arxiv.org/abs/2512.14341)） | 影像 ＋ 文字雙模態聯合最佳化以提升**轉移性** | 語意軸已四項否證；且轉移屬 `GOAL.md` 不做的黑盒 |
| Immune2V（[arXiv:2604.10837](https://arxiv.org/abs/2604.10837)） | 影像轉**影片**的免疫 | 新模態，不在本專案範圍 |
| Neutralizing Proactive Defense using Diffusion-based Upsampling（ACM IH&MMSec 2026） | 用擴散升取樣破解主動防禦 | 又一個破解器，同 2.1 的方向 |

**一句話**：2026 的主戰場是**通用性、轉移性、與模型不匹配**，而攻擊側領先。
「在單一模型上比誰的淨增益高」這條路的邊際價值正在下降。

## 第三節 還沒被佔走的地

逐條檢查，**與 `GOAL.md` 的「明確不做的事」和 `RESULTS.md` 的已否決清單衝突者
直接寫出來**。

| 候選軸 | 佔走了嗎 | 與本專案既有裁定的衝突 |
|---|---|---|
| DCT 域的另一種非加性動作 | 沒有，但**這正是擔憂的來源** | 無衝突，但第一節已說明它只會讓相似度更高 |
| 幾何不變／同步 | 佔走且已證明不可移植（需要解碼端） | log-periodic 已實測是零寬窄峰 |
| 保護性後門 | GuardDoor 佔走 | **衝突**：需要模型提供者配合，違反外掛模組假設 |
| 通用（影像無關）擾動 | 佔走 | **衝突**：amortized generator 已否決 |
| 跨模型轉移 | 2.1 剛把它點名為缺口 | **衝突**：黑盒轉移在 `GOAL.md` 的不做清單裡（理由是「不在白盒假設範圍內」）。**2.1 之後這條裁定值得重新考慮，但那是使用者的裁定** |
| 語意／文字模態 | TDAE 佔走 | **衝突**：語意抵抗四軸全否證 |
| 「擾動要成為淨化算子的不動點」這個**框架** | **沒有人佔** | 無衝突。見第四節 |

## 第四節 建議的定位：不動點框架

### 4.1 一句話主張

> 一個防護擾動能不能撐過某個淨化算子，**不取決於它放在哪個頻帶，而取決於
> 交付出去的影像能不能落在那個算子的不動點集合上**。四個常見算子的不動點
> 集合結構完全不同，這決定了哪一格能贏、哪一格是結構性的輸。

### 4.2 它為什麼不是「再一個頻域旋鈕」

因為它**解釋 DCT-Shield 而不是模仿它**。DCT-Shield 抗 JPEG 的全部祕密就是
「δ 直接加在量化後的整數係數上」——用這個框架講就是：**它的輸出天生落在 JPEG
的不動點集合裡**。同一個框架也立刻說明它為什麼在模糊上只有 +0.010：模糊沒有
那樣的集合。

### 4.3 四個算子，四種結構，三個已經量到

| 算子 | 代數性質 | 不動點集合 | 本專案的實測 |
|---|---|---|---|
| **JPEG(Q)** | 近似冪等的投影（同品質重壓只改 0.02–0.17% 的係數） | 量化格點 | **可行且有效**：自壓後保留率 0.76–0.94（隨機 0.22），jpeg30 淨增益 2.39 倍 |
| **高斯模糊 σ** | 壓縮映射，`blur∘blur = blur_{σ√2}`，**不冪等** | 退化成 `H(ω)≈1` 的低頻 | **結構性不可行**：相位保留 ρ=0.967 而能量只剩 8.9%；交付低頻＝放行低頻，兩軸皆較差已否決 |
| **裁切縮放 s** | 以中心為不動點的相似變換 | 對數極座標上以 `ln s` 為週期的場 | **存在但寬度為零**：s=1.2488 上方向存活 0.9726，1.15 與 1.30 已歸零 |
| **擴散淨化**（DiffPure／GrIDPure） | 往資料流形投影 | 該模型的高似然集合 | **未測。這是唯一開著的一格** |

**前三列的證據都已經在手上，不需要新的 GPU 時間。**

### 4.4 它與既有定位（`SURVEY_POSITIONING` 的 C＋A）的關係

**互補，不是取代。**

- **A（機制三分法）回答「擾動怎麼死的」**：拿走能量／打散方向／只是搬走。
- **不動點框架回答「什麼情況下死得掉」**：交付集合與不動點集合有沒有交集。

兩者合起來是一個完整的敘事：**機制決定症狀，不動點結構決定可不可救。**
而 C（空間選擇性 ↔ 幾何脆弱性）是這個框架下的一個實例——集中度高的擾動在
相似變換下對不回去。

### 4.5 唯一還要跑的那一格

**把「交付到不動點集合」推廣到擴散淨化器。**

作法：在最佳化的損失上加一項，要求防禦圖在攻擊方會用的那個擴散模型底下是
**高似然的**（等價地：在淨化器實際使用的時間步上，去噪殘差要小），同時維持
對編輯路徑的對抗性。直覺是：**淨化器找不到東西可以移除，因為在它自己的模型
眼裡這張圖已經是乾淨的**。

**與最接近的前例 AntiPure（ICCV 2025）方向相反，這一點要寫清楚**：AntiPure
是**破壞**淨化器（削弱它對高頻的支配力、破壞跨時間步的一致性），本提案是
**迎合**淨化器（讓它認為沒有東西要修）。兩者的損失符號是反的。AntiPure 是加性、
ℓ∞ = 16/255、只評測 GrIDPure，比較時必須對齊失真而不是對齊 ε。

**事前判準**：
- **F1**：等失真下，`gridpure` 與 `impress` 兩格的淨增益要高於現行主線。
  高不了就代表「迎合淨化器」這條路在擴散淨化上也不成立，框架的第四列填「不可行」
  ——**那仍然是一個完整的表**，四個算子四種結論。
- **F2**：未淨化那一側的損失不得超過量化交付那一筆（等失真 −21%）。超過就
  代表這一項與防禦強度互斥。
- **F3**（歸因）：要有一個「只加似然項、不加對抗項」的對照，否則分不出改善
  來自迎合淨化器還是來自失真型態改變。

**成本**：似然項要多跑一次 UNet 前向，防禦單點由 60–85 分鐘變約兩倍；
三個點約 7 GPU-h，抗淨化另計。

### 4.6 這個定位的三個好處

1. **它不需要贏。** 四個算子裡三個已經有答案，其中兩個是「結構性不可行」——
   而那正是內容。第四個不論成敗都填得滿那張表。
2. **它把 DCT-Shield 由對手變成實例。** 相似度的問題因此消失：我們不是做了一個
   像它的方法，我們是給出了一個把它包含在內的判準。
3. **它對 2.1 的「模型不匹配」有抵抗力。** 不動點結構是算子的代數性質，換一個
   編輯模型不會改變 JPEG 冪等或模糊不冪等。
