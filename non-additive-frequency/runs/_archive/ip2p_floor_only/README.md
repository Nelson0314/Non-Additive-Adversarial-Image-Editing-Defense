# 只有加性下限：等失真下位移一樣，但 PSNR 差 2.5–2.9 dB

**這些數字尚未進入 `docs/RESULTS.md`**，等使用者裁定。

由 `scripts/floor_only_sweep.sh` 跑出，六個 `--spectral-floor` 工作點、13 張
人眼確認服從的影像。條件是 `floor_only`：**相位與幅度都不動，只有加性下限**。

## 這一格在補什麼

`DECISIONS.md` 撤回「頻譜加性項不做」時，站得住的唯一理由是

> 非加性那一半買的是**感知代價**——等 DISTS 下純加性擋下率一樣好甚至略好，
> 但 PSNR 差 2.4–3.2 dB

而那句話的證據是一次性探針裡 `radius 0.1` 的**近似**（`theta_max` 與
`gain_max` 都還留著 0.1，不是真的關掉），程式已刪除、`hop` 還是舊的 16。
**這一批是那句話在現行程式上的正式量測**，也是整個加性裁決底下唯一沒跑過的對照。

**強度旋鈕是 `--spectral-floor` 不是 radius**（radius 在這一格上完全沒有作用），
分析一律要給 `matched_distortion_table.py --strength spectral_floor`；用預設的
`radius` 分桶會把整條曲線摺成一個點。

## 等失真的對照

內插到三個既有工作點的失真上（`matched_distortion_table.py --strength spectral_floor`）：

| 錨點 DISTS | 對照的是誰 | 純加性下限：位移 / PSNR / 擋下 | 對照組：位移 / PSNR / 擋下 | PSNR 差 |
|---|---|---|---|---|
| 0.0976 | `dct_e18` | 0.6622 / 25.17 / 10.4 | 0.7016 / 25.12 / 10 | +0.05 |
| 0.1286 | 純相位＋下限（`b_ph_rpi`） | 0.6968 / 22.86 / 11.9 | 0.7011 / **25.36** / 11 | **−2.50** |
| 0.1447 | 含加性主線（`b_pg_r20`） | 0.7013 / 21.85 / 12.0 | 0.7012 / **24.74** / 11 | **−2.89** |

**`DECISIONS.md` 那句話在現行程式上成立，而且數字落在它宣稱的區間內
（2.4–3.2 dB）。** 實測 **2.50 與 2.89 dB**。

**位移在這個區間不可解讀**（`PENDING.md` 第〇節：主讀數在 0.70 附近飽和，
三個位移是 0.6968／0.7013 對 0.7011／0.7012）；擋下數的差異（11.9 對 11、
12.0 對 11）小於 ±2/13 的重跑雜訊。**唯一有鑑別力的軸是 PSNR，而它一致地
指向乘法那一半。**

## 這對加性裁決的意思

1. **乘法那一半買得到的東西被量清楚了：同樣的 DISTS、同樣的位移，
   PSNR 高 2.5–2.9 dB。** 它買的是感知代價，不是防禦強度——`DECISIONS.md`
   本來就是這樣寫的，現在有正式證據。
2. **反過來也成立：純加性下限單獨就能到失真帶並拿到 12/13。** 也就是說
   「非加性」在防禦強度上不是必要的。新穎性主張要照這個寫。
3. 與 `PENDING.md` 第〇節對讀：`spectral_floor` 從 0.14 到 0.20，DISTS 漲 29%、
   PSNR 掉 2.4 dB，位移只由 0.6981 動到 0.7064、擋下不動。**這一支自己也在
   0.70 飽和**，拐點在 0.14 附近。
