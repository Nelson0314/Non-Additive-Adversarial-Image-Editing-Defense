# 封存：逐次執行的原始紀錄

**這裡的檔案不是判準來源。** 結論與判準一律以 `../FINDINGS.md`、
`../DECISIONS.md`、`../DEFECTS.md` 為準。

裡面是 2026-08-05 到 08-09 的逐日紀錄。它們按時間寫、彼此交互引用、
後面的節次會推翻前面的（例如 `RESULTS_2026-08-07` §6 的方向被
`RESULTS_2026-08-08` §1.3 更正，而 §7.4 又被 §9.7 更正）——那正是本次
整理要消除的形態。

保留原文只為兩件事：

1. **追溯**某個數字當初是怎麼量的、在什麼設定下量的。
2. **查那些尚未被歸納的細節**——若某個結論在這裡而不在 `FINDINGS.md`，
   表示它還沒有被複核歸納，引用前要自行查證。

程式碼註解裡若出現 `RESULTS_2026-08-08 §12.1` 這種引用，指的是這裡的檔案。
那是「這個常數當初怎麼量的」的出處指標，不是閱讀順序的相依。
