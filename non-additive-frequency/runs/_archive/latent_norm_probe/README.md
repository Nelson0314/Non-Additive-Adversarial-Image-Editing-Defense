# 各族的防禦圖把 `‖E(x_def)‖₂` 壓到哪裡

`scripts/latent_norm_probe.py`。**不訓練，只讀已存的防禦圖。**
`results.csv` 是盆栽人與瑪利歐的主表，`mario_extra.csv` 是後補的兩格。

問的是歸因問題：色彩族的位移只有相位族的一半上下，**是因為它壓不動損失，
還是因為同樣的損失值換不到同樣的位移**。

## 結論：位移不是 `‖E‖` 的函數

| 條件 | `‖E‖` ÷ 原圖（盆栽人／瑪利歐） | DISTS | 位移 |
|---|---|---|---|
| DCT-Shield | 0.471 / 0.401 | 0.080 | 0.676 |
| 相位增益 r0.9 | 0.594 / 0.526 | 0.083 | 0.542 |
| 色彩網格 `latent_norm` 收斂 | 0.667 / 0.760 | 0.166 | 0.287 |
| 色彩網格 `image_guidance` | 0.880 / 0.951 | 0.231 | 0.452 |
| **色彩網格隨機 r0.10** | **1.067 / 1.059** | 0.176 | **0.317** |

**隨機那一格的範數比原圖還高（完全沒有往損失的方向走），位移卻高於把範數
壓到 0.667 的最佳化版。** 只要有這一格，「位移是 `‖E‖` 的遞減函數」就不成立，
「損失只差 12% 所以差一點點跨過界線」這個讀法也沒有立足點。

後續改量對應機制的 `image_guidance` 殘差，記在 `runs/ig_probe/README.md`。
那一批的 Spearman 顯示 `L_ig` 對主體內位移是 −0.848，`‖E‖` 只有 −0.558。
