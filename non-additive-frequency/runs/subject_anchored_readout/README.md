# 主體錨定讀數與盲評的聯結

不重跑任何訓練，只用 `runs/chroma/` 已存的輸出重新判讀。

## 為什麼重判

`src/metrics/identity.py` 的 `embed()` 走 `MTCNN(select_largest=True)`，取畫面上
**面積最大**的那張臉。編輯輸出多長出一張臉且比主體大時，`id_def` 量到的是新的人。
新增的 `embed_box()`／`subject_identity_row()` 改成把嵌入錨定在**與原圖主體框
重疊最大**的框，重疊為零記空值，並附 `subject_box_iou` 與三張圖的臉數。

## 盲評

三十格防禦圖加兩格未防禦對照，順序打亂、條件在全部評完前不顯示，
四問：指令是否完成在原主體身上、是否仍是同一個人、輸出對攻擊者可用與否、
防禦圖外觀。標記由使用者做。

seed 47002 的十五格不可解讀：該種子的**未防禦**編輯本身被判「不可用」。
可解讀的是 seed 47001 的十五格。
