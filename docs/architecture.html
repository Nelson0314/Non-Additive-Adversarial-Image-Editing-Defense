§4.1

低秩殘差：外積參數化

秩不是懲罰出來的，是參數化方式決定的。

算式

Δ[c] = Σ(i=1..r) U[c,i,:] ⊗ V[c,i,:]ᵀ # U[c,i,:] ∈ R^H, V[c,i,:] ∈ R^W, ⊗ 為外積 delta = torch.einsum('cri,crj->cij', U, V) # (C, H, W)

秩至多為 r：矩陣的每一列都是 r 個固定向量 V[c,1..r,:] 的線性組合，列空間維度不超過 r。這是代數事實，不需事後驗證，也不依賴任何懲罰項權重。

數值舉例

取 H=W=6、r=2、單一通道。兩組外積相加得到 6×6 矩陣，其秩為 2。

低秩殘差長什麼樣

下列 64×64 殘差以相同的隨機種子生成，只改變 r。低秩殘差是結構性、大尺度的；秩升高後逐漸接近各向同性噪聲。這正是本設計預期耐淨化的機制來源 —— v2 已實證高頻像素訊號會被 JPEG、模糊、去噪剝離。

這張圖是機制假說，不是結果。 「低秩 ⟹ 結構性 ⟹ 耐淨化」這條推論鏈的最後一步必須由 E3 實證。若不成立，如實報告。

為何不用 truncated SVD

  • 秩在代數上精確等於 r，不需事後驗證，也不需調懲罰項權重。
  • 訓練迴圈內不執行 SVD。SVD 在奇異值簡併時反向傳播數值不穩定，且成本高。
  • 參數量小（見 §4.3 表），單圖優化下不致過擬合。
  • rank 掃描退化為更改一個整數，ablation 設計乾淨。
初始化。 U ~ N(0, 0.02)、V = 0。初始 Δ = 0 即 x_def = x，同時 ∂L/∂V ≠ 0 梯度可流動。沿用 LoRA 的 A 高斯／B 零慣例。

§5

Loss 與梯度路徑

無低秩懲罰項。秩是架構硬約束，不以懲罰項近似。

L(φ) = λ_def · L_def + λ_fid · L_fid

L_def — 防禦項

L_def = E[P∼𝒫, ε∼N(0,I)] max(0, m − d( E(P(x_def), ε), E(x, ε) ))
  • hinge 形式。 偏移超過 margin m 後不再施力。無界最大化會發散，此為必要設計。
  • 𝒫 含恆等算子（不淨化）與各淨化方法。把耐淨化性寫進訓練目標，而非事後量測。
  • E(x, ε) 對 φ 為常數，每 (圖, prompt, seed) 只算一次並快取。

L_fid — 保真項

L_fid = LPIPS(x_def, x) + α · (1 − SSIM(x_def, x)) + β · max(0, ‖Δ‖_∞ − τ) + γ · max(0, PSNR_floor − PSNR)

後兩項硬地板的存在理由是 v2 的直接實測：apa 方法的 LPIPS 與 pg_enc 幾乎相同，但 PSNR 相差 12.7 dB、L∞ 相差 28 倍。若保真項只用 LPIPS，優化過程會利用其量測盲區，產生 LPIPS 數值良好但人眼可見的失真。

E3 的因果切割

P 是低秩加性殘差，L 是低秩非加性殘差。v2 已實證一般加性擾動（高頻像素訊號）會被淨化剝離。此對比把「秩」與「非加性」兩個混淆因素分開。

P 亦耐淨化

機制是秩結構。

P 不耐、L 耐

機制是非加性。

兩者皆耐且相近

兩機制不可分辨，須再設計實驗。

三種結果都是可發表的發現。此設計不存在「實驗失敗」的分支。

§9–10

待決事項與風險

審核時請特別看這一節。

§9.1 資料集 — 阻擋 E2。 現有 data/dayn_testset/ 僅 6 張影像。新網格為 2 sites × 6 ranks = 12 格，6 張圖的統計效力不足以支撐 E3 的因果判斷。v2 報告自身已將「n=6、1 seed、誤差區間偏寬」列為保留事項，而 v2 的網格比這個小。此項不決定，E2 結論強度受限。
§9.2 淨化的可微代理。 L_def 要求淨化進入訓練目標，但 JPEG 與 GrIDPure 不可微。代理實作方式待定；若代理與真實實作差距過大，改為僅將可微淨化納入訓練、不可微者僅用於評測，並在報告中說明。

不得引用 LRDM 的 VLB 定理作為本方法的理論保證

LRDM 式 (7)–(12) 證明「限制在低秩子空間 ⟹ 更緊的變分下界」，其成立前提是「訓練擴散模型以最大化 VLB」。本規格的目標函數是對抗性 loss，不是 VLB，該定理不可直接轉移。可借用的是它的假設（近域殘差低秩）與實證觀察（中等秩優於全秩），兩者在 spec §6.1 已逐項標明借用內容與差異。
