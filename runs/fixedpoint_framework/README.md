# 不動點框架：什麼樣的淨化算子擋得住，什麼樣的擋不住

**這是設計文件，不是結果。** 各列的證據路徑寫在表裡；還開著的那一格的協定與
判準寫在第五節。與既有定位分析的關係見第六節。

## 一、一句話

> 一個防護擾動能不能撐過某個淨化算子，**不取決於它放在哪個頻帶，而取決於
> 交出去的影像能不能落在那個算子的不動點集合上**。四個常見算子的不動點集合
> 結構完全不同，這決定了哪一格能贏、哪一格是結構性的輸。

## 二、形式化

攻擊方拿到防禦圖 `x'` 之後先套一個淨化算子 `T`，再編輯。防禦成立的條件是
`Edit(T(x'))` 離 `Edit(x)` 夠遠，而**空白地板** `Edit(T(x))` 已經離 `Edit(x)`
有一段距離，所以主讀數是扣掉地板的淨增益（`GOAL.md`）。

擾動完全不被淨化影響的充分條件是

```
T(x') = x'        即   x' ∈ Fix(T)
```

於是可行性由兩個集合的交集決定：

```
可交付且有效  ⟺  Fix(T) ∩ {對編輯有效的 x'}  非空且夠大
```

**`Fix(T)` 的幾何結構因算子而異，而且差別是結構性的，不是程度性的。**
下一節逐個算子寫出它的結構與本專案的實測。

**一個已量到的通則**：落到 `Fix(T)` 上不是免費的。把輸出約束到 JPEG 的格點
上，**未淨化那一側要付大約兩成**——相位族等失真下位移由 0.7012 掉到 0.5561
（−21%），DCT 學習平面由 0.6382（浮點、DISTS 0.1285）掉到等失真內插的 0.5106
（−20%）。**兩條互相獨立的路走到同一個數字**，這比單一觀測強。

## 三、四個算子

### 3.1 JPEG(Q)：近似冪等的投影 → **可行且有效**

`T = JPEG_D ∘ JPEG_E` 幾乎是一個投影：同品質重壓只改 **0.02–0.17%** 的係數。
`Fix(T)` 是量化格點的解碼像，它**稠密**——任何影像距離某個不動點都不超過半個
量化階，所以與「有效」的交集又大又好找。

| 讀數 | 值 |
|---|---|
| 自壓後擾動保留率 | **0.76–0.94**（隨機擾動 0.22） |
| jpeg30 淨增益（對 DCT-Shield 論文設定） | **2.39 倍** |
| 交付要付的代價 | 未淨化 −21% |

**證據**：`ip2p_deliver_jpeg`、`ip2p_mainline`

### 3.2 高斯模糊 σ：壓縮映射 → **結構性不可行**

`T` 是線性算子，頻域特徵值是 `H(ω) = exp(−2π²σ²f²) ∈ (0, 1]`，**不冪等**
（`blur_σ ∘ blur_σ = blur_{σ√2}`）。`Fix(T)` 只含 `H(ω) = 1` 的分量，也就是
**退化成常數影像**；近似不動點則是低頻子空間。

**而低頻正是編碼器看不見的地方。** 兩條曲線方向相反且都很陡：

| | 跨帶變化 |
|---|---|
| 模糊存活率／知覺代價 | 最低帶是現行工作帶的 **13.5 倍** |
| 編碼器敏感度（move/DISTS） | 278 → 242507，**三個數量級** |
| **兩者乘積** | 幾乎是平的，極大值 **只高 1.54 倍**（事前判準 3） |

**`Fix(T)` 與「有效」的交集近乎為空，而且是可量的。**

**證據**：`fixedpoint_blur/README.md`、`phase_drift_diagnosis`

### 3.3 裁切縮放 s：相似變換 → **不動點集合存在，但寬度為零**

中心裁切再放大等於以中心為不動點、倍率 `s = 1.2488` 的純放大（實測亮點
64 → 16、448 → 496、**256 不動**）。`Fix(T)` 是對數極座標上以 `ln s` 為週期的
場——**非平凡且無窮維**，但它**綁死在那一個 s 上**。

| s' | 1.05 | 1.10 | 1.15 | **1.2488** | 1.30 | 1.40 |
|---|---|---|---|---|---|---|
| 方向存活 | −0.068 | −0.029 | −0.018 | **0.975** | −0.009 | −0.048 |

**相鄰倍率立刻歸零。** 對一族 `s` 取交集是平凡的，所以「落在 `Fix(T)` 上」在
這裡等於對單一算子 co-adapt——而那是已否決的方向。

**這也解釋了為什麼浮水印的幾何工具箱搬不過來**：它們靠的是**解碼端先估出 s
再反轉**，而防護擾動沒有解碼端（`reference/SURVEY_NOISE_RESISTANCE.md` §1.4）。

**證據**：`log_periodic_probe`、`ip2p_residual_signature/band_transfer.csv`

### 3.4 擴散淨化：往資料流形投影 → **開著的那一格**

`T` 是把 `x'` 加噪到 `t*` 再逆向取樣。它既不是線性的也不是投影，但它的**近似
不動點是該擴散模型的高似然集合**——模型認為已經乾淨的影像，它沒有東西要修。

`Fix(T)` 在這裡是**非線性、資料相依、而且我們知道它的模型**（白盒假設下，
攻擊方用的是公開權重）。這是四個算子裡唯一一個「不動點集合又大又可寫下來、
而且還沒有人從這個角度試過」的。

**證據**：本批 `runs/ip2p_fixedpoint/diffusion/`（進行中）

## 四、這個框架能主張什麼、不能主張什麼

**能主張**

1. 抗淨化的可行性是**算子的代數性質**決定的，不是防禦方調參的結果。
2. 它把 DCT-Shield **解釋成一個實例**而不是對手：它抗 JPEG 的全部祕密就是
   輸出天生落在 `Fix(JPEG)` 裡；同一個框架立刻說明它在模糊上只有 +0.010。
3. 它對「模型不匹配」有抵抗力（`reference/SURVEY_FRONTIER.md` §2.1）：換一個
   編輯模型不會讓 JPEG 變得不冪等、也不會讓模糊變成冪等。
4. **交付到不動點集合要付大約兩成的未淨化效果**，兩條獨立的路量到同一個數字。

**不能主張**

1. **`x' ∈ Fix(T)` 是充分條件不是必要條件。** 擾動不必完全不動也可能還有效；
   框架給的是可行性的上界解釋，不是「不在 `Fix` 裡就一定失敗」。
2. **不動點集合隨算子參數移動。** `Fix(JPEG_85) ⊄ Fix(JPEG_30)`，而實測我方在
   jpeg30 反而勝出——**這一格框架解釋不了**，目前的解釋來自另一條線
   （DCT-Shield 的 `|δ| ≥ 一個量化階` 條件在低 `Q_alg` 下與失真帶互斥）。
   **這是框架的一個明確缺口，要寫在論文裡而不是繞開。**
3. 三列的證據規模不同（模糊十張、裁切十三張、JPEG 十張），不可混算。

## 五、還開著的那一格：協定與判準

### 5.1 第一步（本批，進行中）：先量現況

用**既有的**十張防禦圖跑 GrIDPure，含空白地板，不重跑防禦。
`scripts/purify_diffusion_row.sh`。

**事前寫下的可證偽預測**：

> **D1**：量化交付（`ours_ph_q`）相對不交付（`ours_pg_m`）在 gridpure 上
> **不應該**有優勢——JPEG 的量化格點不是擴散淨化器的不動點集合。它在 jpeg30
> 上的優勢是 2.19 倍。**若 gridpure 上也出現同一量級的優勢，第二節「不動點
> 集合是算子專屬的」這條就要修正。**

D2（地板必跑）與 D3（這一批不是等失真的，只能回答定性問題）寫在腳本檔頭。

### 5.2 第二步（只有 D1 通過才做）：把交付推廣到擴散的不動點集合

在損失上加一項，要求防禦圖在攻擊方那個擴散模型底下是**高似然**的（等價地，
在淨化器實際使用的時間步上去噪殘差要小），同時維持對編輯路徑的對抗性。

**與最接近的前例方向相反**：AntiPure（ICCV 2025）是**破壞**淨化器（削弱它對
高頻的支配力、破壞跨時間步的一致性），本設計是**迎合**淨化器。兩者損失的符號
是反的。AntiPure 是加性、ℓ∞ = 16/255、只評測 GrIDPure，比較必須對齊失真。

**判準**：

- **F1**：等失真下 `gridpure` 與 `impress` 兩格的淨增益要高於現行主線。
- **F2**：未淨化那一側的損失不得超過量化交付那一筆（−21%）。超過就代表這一項
  與防禦強度互斥。
- **F3**（歸因）：要有一個「只加似然項、不加對抗項」的對照，否則分不出改善
  來自迎合淨化器還是來自失真型態改變。

**成本**：似然項多一次 UNet 前向，防禦單點由 60–85 分鐘變約兩倍；三個點約
7 GPU-h，抗淨化另計。

## 六、與既有定位分析的關係

`reference/SURVEY_POSITIONING.md` 排出的第一名是「機制三分法（A）＋ 空間選擇性
取捨（C）」。本框架**不取代它，補上它缺的那一半**：

- **A 回答「擾動怎麼死的」**：拿走能量／打散方向／只是搬走。
- **本框架回答「什麼情況下死得掉」**：交付集合與不動點集合有沒有交集。

合起來是一句話：**機制決定症狀，不動點結構決定可不可救。** C（空間選擇性 ↔
幾何脆弱性）是這個框架下的一個實例——集中度高的擾動在相似變換下對不回去。
