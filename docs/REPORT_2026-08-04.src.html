1. 系統結構

3. 擾動怎麼產生：最佳化 ／ 同 LPIPS 的隨機

做了什麼。同一張照片改兩次。第一次讓最佳化自己去找該怎麼改；第二次不最佳化，直接灑高斯雜訊，並用二分搜尋把雜訊調到與第一次「看起來一樣不同」（LPIPS 相同）。兩張改完的圖各自交給 SD 編輯一次，兩邊用的是逐元素相同的 5 組評測噪聲，故可以逐種子相減。

想看到什麼。如果最佳化找到的方向真的有用，它讓編輯失效的程度應該明顯多過隨便灑的雜訊。如果兩者差不多，那效果來自「影像被改動了」本身，而不是「改得有道理」——這是文獻上很少有人放的一條對照。

4. 擾動加在哪：像素相加 ／ 空間變形

做了什麼。把「怎麼改影像」換掉，其餘全部不動（同一張照片、同一個損失、同樣 60 步、同一組評測噪聲）。做法一是逐像素加一層東西上去；做法二是把像素搬到旁邊的位置、不加任何東西。兩種各自再配一條同失真的隨機對照。

想看到什麼。這是整個研究問題本身：搬動像素這種非加性的做法，能不能在同樣看得出來的失真下，比加東西上去更能擋住編輯。因為兩種做法在同一個上限下實際到達的失真不同（0.535 對 0.108），不直接比絕對數字，改比各自「相對自己的隨機對照多降了多少」。

結論

在同樣看得出來的失真下，加東西上去的做法，最佳化比隨機有用；搬動像素的做法，最佳化反而比隨機還差一點。就這一組資料而言，非加性這條路沒有優勢。

另外，搬動像素能造成的失真本來就小得多——即使把上限開得很寬，它也只走到十分之一左右。上表逐項確認過，這不是被任何一個設定卡住，是這種改法本身推不動。

限制：一張影像、5 組評測噪聲、一個損失。

5. 位移場的控制點數：32×32 ／ 128×128

做了什麼。只把位移場的控制點由 32×32 換成 128×128，也就是讓變形可以做得更細（可調參數由 2,048 增為 32,768）。其他一個字都沒動，包含重取樣的方式。

想看到什麼。§4 的空間變形結果不好，一個可能的原因是它能表達的變形太粗，只能整片一起推。如果把細緻度提高 16 倍之後結論翻轉，代表先前量到的是容量不足；如果不翻轉，代表問題不在細緻度。

6. 損失讀網路的哪一層

做了什麼。三個文獻方法用完全相同的資料（24 張真實照片）、相同的擾動幅度上限、相同的 20 組評測噪聲，差別只在訓練時損失讀路徑上的哪一個位置——圖 1 的①（VAE 編碼器輸出）、②（交叉注意分佈）、③（輸出影像）。

想看到什麼。兩件事。一是哪一個位置最能讓編輯結果不再照 prompt 走；二是文獻最常用的那五個影像距離數字，會不會給出跟 SigLIP 一樣的排序。若排序不同，代表「拿哪一組數字宣告免疫成功」這件事本身會改變結論。

結論

三個做法裡，只有把力氣放在交叉注意的那一個，能讓編輯結果不再照 prompt 走。另外兩個的 SigLIP 是上升的，也就是加了保護之後編輯反而更照 prompt 走。

但文獻最常用的那五個距離數字給出的排序正好相反：它們把 encoder 排第一、把唯一有效的 semantic 排最後。而 encoder 之所以分數高，是因為它把畫面整個弄糊了（NIQE +5.81）。

所以拿哪一組數字來宣告免疫成功，會直接改變誰是最好的方法。

7. 同一個 LPIPS 下，失真的種類

做了什麼。這一節不跑防禦。只做一件事：把四種性質不同的失真（模糊、雜訊、兩種空間變形）各自調到 LPIPS 完全相同，然後量其他數字，並把四張圖排出來看。

想看到什麼。本報告到處在用 LPIPS 代表「人眼看得出多少不同」，§3 與 §4 更是拿它來說「兩種做法的失真一樣大」。如果這個代表性成立，四張圖在其他數字上也應該接近。如果差很多，那「LPIPS 相同 = 失真相同」就不能直接拿來當比較的前提。

所以「兩個方法的 LPIPS 一樣」不能直接當成「兩個方法的失真一樣」。這正是 §3 與 §4 必須各配一條自己的隨機對照、而不是直接比絕對數字的原因。

這組影像的另一個用途是檢查一個候選指標實際對哪種失真敏感：把它套到這四張上就看得出來。目前用的兩個自訂指標是這樣選出來的，SSIM 等五項是這樣排除的——SSIM 把雜訊判得比同樣 LPIPS 的模糊貴約 2 倍，拿它當限制會讓最佳化轉去把畫面弄糊。

8. 擾動幅度：L∞ 由 0 到 0.06

做了什麼。取同一個擾動，整體放大縮小到六個幅度（L∞ 由 0 到 0.06），量每一級對應的其他數字，並把六張圖並排交給人眼看。

想看到什麼。文獻與基準論文都用 L∞ ≤ 0.06 當作擾動大小的上限，並普遍把這個範圍描述為看不出來的。要確認兩件事：在我們的資料上這個描述成不成立，以及該幅度換算成 LPIPS 是多少——後者直接決定 §3–§5 該把預算設在哪裡。

這一節用到的指標

指標量的是什麼哪個方向是防禦方要的
L∞擾動裡最大的單點改變量（像素值以 0–1 計）。文獻普遍用它當作擾動大小的限制越小代表擾動越受限。§7 顯示它與人眼看得出多少對不上
LPIPS（擾動）把兩張圖各自送進一個訓練過的網路，比對中間層特徵差多少，用來代表「人眼看得出多少不同」。0 = 兩張完全相同越小越好：防禦後的影像要盡量像原圖
PSNR逐像素誤差換算成分貝，數字越大表示兩張圖越接近量輸出時越小越好；量擾動時越大表示防禦圖越像原圖
SSIM比較亮度、對比與局部結構的相似度，1 = 完全相同量輸出時越小越好
RMS擾動的均方根，即平均改變量越小代表平均改動越少
銳利度偏差同上的量，但取與原圖的偏離量，0 = 完全沒變越大代表高頻被動得越多

結論

文獻標準的擾動幅度是看得出來的，不是無感的。L∞ = 0.06 這一級人眼一眼就能看出背景扭曲。

它換算成 LPIPS 接近 0.6。因此 §3–§5 把預算設在 0.55 是與文獻同一個量級，不是特別寬鬆或特別嚴格。

9. 這六組數據合起來

  1. 搬動像素這條路，目前沒有優勢。在同樣看得出來的失真下，加東西上去的做法，最佳化比隨機有用；搬動像素的做法，最佳化反而比隨機差。把變形做得更細也沒有翻轉，而且能造成的失真本來就小一個量級。（§4、§5）
  2. 力氣該放在交叉注意上。三個文獻做法裡，只有這一個能讓編輯結果不再照 prompt 走；另外兩個反而讓編輯更照 prompt 走。（§6）
  3. 拿哪一組數字宣告成功，會改變誰是最好的方法。常用的五個距離數字把畫面被弄得最糟的那個排第一，與 SigLIP 的排序相反。（§6、§3）
  4. LPIPS 一樣不代表看起來一樣。因此比較兩個做法時不能只對齊 LPIPS，必須各自帶一條同失真的隨機對照。（§7、§3）
  5. 文獻標準的擾動幅度看得出來，不是無感的。本報告的預算設在同一個量級，不是特別寬鬆。（§8）
