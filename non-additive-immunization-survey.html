Survey 結論

一、研究缺口。 針對 editing 之非加性防禦尚無人做過。現有非加性方法皆屬攻擊分類器(AdvDiff、APA、SCA)或人臉隱私(DiffProtect、Weakening Purification)情境;editing/inpainting 防禦(PhotoGuard、DAYN、DiffusionGuard、PromptFlare、AdvPaint)則全為加性。「影像端、非加性、editing」之組合在文獻中為空白。

二、baseline 挑選須涵蓋兩維。 攻擊模型分兩類:可學習攻擊(對受保護影像做 fine-tune,如 DreamBooth、LoRA)與非學習攻擊(以現成模型直接推論編輯,如 inpainting、img2img);DAYN 屬後者。淨化亦分兩類:非學習之輕量淨化(JPEG、crop-resize、blur、AdverseCleaner)與可學習/重度之擴散式淨化(DiffPure、GrIDPure、Noisy Upscaling)。須避免僅測輕量淨化即宣稱抗淨化(DiffusionGuard、PromptFlare 有此局限)。

三、非加性可用之方法與攻擊部位。 組合邏輯:以 DDIM inversion 錨定原圖 → 以兩階段解耦維持相似性 → 以 AdvDiff 之注入機制將「編輯失敗」注入生成過程 → 作用於 cross-attention 等 editing 部位 → 以 DiffPure 之準則確保抗淨化。詳見下表。

核心九篇重點

Fragile by Design (AAAI'26) 評估 2511.10382

證明四個 additive customization 防禦在三種淨化下普遍失效(Anti-DreamBooth ISM 0.40→0.61,近乎無保護),最輕量淨化僅需兩行 OpenCV。提供威脅模型形式化(替換擾動約束即為非加性之入口)與 AntiDB_Purify 評估框架。用途:motivation 與評估依據。

DiffPure (ICML'22) 淨化 2205.07460

兩步淨化(淺加噪 + 反向 SDE 去噪),理論證明何種訊號可存活:大尺度、全域、語意綁定、on-manifold;小範數高頻 off-manifold 擾動(即 additive 保護)最易被移除。SDE 換 ODE 掉 30 分,顯示隨機性為防禦力核心。用途:防禦方之主要對手,其準則即非加性方法之設計依據。

AntiPure (ICCV'25) 防禦 2509.13922

additive 陣營抗淨化之代表,改為攻擊淨化過程本身(兩個 guidance:高頻 DCT、timestep 混淆)。能力上限:最佳 ISM 僅 0.5475、FDFR 0.04–0.10,僅達成「輸出可辨為偽造」,無法阻止身份被學習。§4 論證語意層級破壞在此框架結構性不可行。用途:界定 additive 抗淨化之上限,即本研究欲突破之對照。

APA (NeurIPS'25) 攻擊 非加性 2506.01511

非加性攻擊工具,victim 為分類器。以 DDIM inversion 錨定原圖,兩階段解耦(先 LoRA 鎖視覺一致性、再注入對抗性)避免 reward hacking。對 DiffPure 之抗性遠高於 additive 攻擊,將「非加性較抗淨化」由定性轉為實測。用途:本研究之核心技術來源,機制同構、僅需將 victim 換為 editing pipeline。場景相反:APA 攻破辨識系統,immunization 使惡意編輯失敗。

AdvDiff (ECCV'24) 攻擊 非加性 2307.12499

非加性攻擊之基礎工作。兩個具貝氏依據之注入點:每步注入(反向每步沿目標梯度)、起始噪聲注入(更新 x_T 再重生成)。理論證明生成先驗使樣本維持真實。用途:注入機制之核心來源,兩注入點與生成機制解耦、可搭配 inversion,code 已定位於 ddim_adv.py。

editing 防禦(四篇,皆 additive)

  • PhotoGuard(2302.06588)— editing 防禦起點,提出 encoder / diffusion attack。JPEG 壓縮即可移除其保護。
  • DAYN(本組,CVPR'24)— 攻 cross-attention、具記憶體效率;editing 情境,屬非學習攻擊之防禦。
  • DiffusionGuard(2410.05694)— 攻 early steps + mask augmentation;測輕量淨化,強度不及 DiffPure。
  • PromptFlare(2508.16217)— 將 cross-attention 導向無語意之 BOS token,切斷 prompt 影響,達成 prompt-generalized;與 DAYN 同攻 attention,惟 DAYN 抑制特定內容、PromptFlare 導向錨點。

customization 防禦(Anti-DreamBooth)2303.15433

customization 防禦起點,提出 ASPL(交替更新 surrogate 與 δ,解 victim 依賴 δ 之相互依賴問題),為 SimAC、DisDiff、AntiPure 之共用骨架。

全局整合

能力邊界

additive 之上下限: PhotoGuard / Anti-DreamBooth 建立方法 → Fragile by Design 證明其在淨化下普遍失效(下界)→ AntiPure 抗淨化但僅達成「輸出可辨為偽造」(上限)→ DiffPure 說明成因(小範數高頻 off-manifold 訊號在淺 t* 即被移除)。

非加性之優勢: APA、SCA 實測顯示 inversion 生成影像對 DiffPure 之抗性顯著高於 additive。缺口:將此機制用於 editing 防禦,文獻中尚未見。

判準:提供可移植之非加性生成機制、可對抗淨化之具體做法、或界定範圍與評估依據者列入。

甲、可移植之生成機制

  • APA(2506.01511)— 核心。DDIM inversion + 兩階段解耦之完整框架,移植方式明確。
  • AdvDiff(2307.12499)— 核心。兩個注入點,最基礎且可移植,與生成機制解耦。
  • SCA(2410.02240)— edit-friendly inversion + MLLM 引導,與編輯情境契合。
  • DiffProtect(2305.13625)— 操作語意編碼之非加性早期實例(人臉隱私,非 attention 方法)。

乙、對抗淨化之做法

  • Weakening Diffusion Purification(2503.10350)— 核心。少數同時為非加性且主動對抗淨化之防禦。
  • Diff-PGD(2305.16494)— 使樣本貼近自然分布,報告較佳之抗淨化能力,佐證核心假設。
  • DiffPure(2205.07460)— 界定何種訊號可存活淨化,即設計準則。

丙、範圍與評估

  • Fragile by Design(2511.10382)— 威脅模型模板與 AntiDB_Purify 框架。
  • BlurGuard(2511.00143)— additive 頻域抗淨化之最新對照;多淨化 worst-case 評估可沿用。
  • Pixel is Not a Barrier(2408.11810)— 有效性與模型類型(PDM/LDM)相關,提醒勿僅於 SD 驗證。
  • AdvPaint / PromptFlare / DiffusionGuard — editing 情境之直接 baseline 與評估項目來源。
整體判斷 最直接者為 APA(可移植框架)、AdvDiff(注入機制)、Weakening Purification(非加性且抗淨化之示範)。所有非加性做法目前皆出自攻擊分類器或人臉隱私情境,尚無直接針對 editing 者,此即切入點,亦為移植時最大之未知(editing pipeline 之 victim 定義與梯度計算較分類器困難)。

延伸文獻

  • BlurGuard(NeurIPS'25)2511.00143 — 頻域 irreversibility,additive 抗淨化之最新努力。
  • DiffVax 2411.17957 — optimization-free,以網路取代逐圖優化(仍屬 additive)。
  • Universal Immunization via Semantic Injection 2602.14679 — UAP 語意注入,免逐圖優化。
  • GuardDoor 2503.03944 — backdoor 抗淨化,惟需模型方配合(threat model 不同)。
  • Pixel is Not a Barrier 2408.11810 / Pixel is a Barrier 2404.13320 — PDM 對 additive 攻擊較 robust。
  • SCA 2410.02240 / DiffProtect 2305.13625 / Diff-PGD 2305.16494 / Weakening Purification 2503.10350 — 非加性 / inversion 攻擊與保護。
  • AdvPaint 2503.10081 / EditShield / DDD(IJCAI'24)/ Semantic Attack(Lo et al.)— editing 防禦近作;Semantic Attack 須確認是否為指導者 Ling Lo 之工作。
  • I2VGuard(CVPR'25)/ Vid-Freeze 2509.23279 — image-to-video 保護,新興方向。

待確認事項

  1. 目標情境定為 editing/inpainting(同 DAYN)或 customization?此決定 victim、baseline 與評估之全部設計。
  2. 非加性下,相似性約束由 pixel norm 改為 perceptual/semantic 度量,「保護影像與原圖允許可見差異」之假設是否可接受?
  3. GuardDoor 需模型方配合,threat model 不同,須確認是否納入對照。
  4. Semantic Attack(Lo et al., 2024)是否為指導者 Ling Lo 之既有工作?若是,其與 DAYN 之關係須釐清。
  5. 研究構想(待討論):以可學習之 discriminator 取代 APA 固定之相似度 reward,強化其解耦框架第一階段。前置依賴:上述情境須先確認。
