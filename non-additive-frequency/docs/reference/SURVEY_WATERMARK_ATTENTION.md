# 兩篇與現行方向直接對照的論文

- **Zhu et al., CVPR 2024** — *Watermark-embedded Adversarial Examples for
  Copyright Protection against Diffusion Models*（LY Corporation）
- **Trippodo et al., ACM MM 2025** — *Immunizing Images from Text to Image
  Editing via Adversarial Cross-Attention*（Attention Attack，arXiv:2509.10359）

兩篇都讀過全文（Zhu 的 PDF 逐頁抽文，Trippodo 讀 arXiv 摘要與正文摘述）。

---

## 一、Zhu (CVPR 2024)：與本專案最接近的前例

### 它做什麼

**目標式攻擊**：把一張指定的浮水印影像 `m` 當成目標，逼擴散模型的**輸出**
帶上那個浮水印。

    x' := argmin ‖θ(x') − m‖    s.t. ‖x − x'‖ ≤ δ

不是逐圖最佳化，而是訓練一個條件 GAN 生成器 `x' = x + G(x | m)`，三個損失：
`L_adv`（逼輸出接近浮水印）、`L_GAN`（逼 `x'` 接近 `x`）、`L_pert`（壓擾動）。
5–10 個樣本、2–3 分鐘訓一個浮水印的生成器；之後每張圖 0.2 秒。

資料：WikiArt 3000 張、ImageNet。場景：text-guided img2img 與 textual
inversion。

### 可以參考的地方

1. **它證實了「可見的產物比混亂紋理好」這個論點已被同儕接受。** 論文的核心
   賣點正是「AdvDM 那類方法產生 chaotic textures，不足以指出侵權；我們讓
   輸出帶上可讀的浮水印」。本專案「可見的防禦是允許的」這條裁定與它同向，
   而且它是 CVPR 的正式論文——這是可引用的立場支撐。

2. **amortization 的具體作法。** 本專案每張圖 6000 步 PGD（單張約 50 分鐘）；
   它用生成器把成本壓到 0.2 秒。若日後要把補丁族推到幾十張以上，這是現成的
   路線圖：條件生成器 ＋ 三損失。

3. **`L_adv` 的形式與本專案的 `image_guidance` 是同一族**（都對 latent 或
   輸出下目標），差別在它有明確的目標影像而本專案是「推離原編輯」。
   **模板錨定那條線**（`anti-purify/OVERNIGHT_FINDINGS.md` §四之二列為待辦，
   「給一張指定 logo T，加 λ‖c − T‖ 懲罰再掃 λ」）與它的 `L_adv` 幾乎是同一
   件事，只是本專案罰在**防禦圖的補丁內容**上、它罰在**編輯輸出**上。
   若要做模板錨定，罰在輸出上是有前例的作法。

### 與本專案立場衝突的地方

1. **它是 L∞ 球內的加性擾動，本專案不是。** `L_pert` 的目的就是「讓擾動對
   人眼不可見」，而使用者已裁定「可見的防禦是允許的，條件是主體不動」。
   兩者的失真預算不在同一個軸上，**不可以直接比數字**。

2. **抗淨化那一節與本專案的量測協定不相容。** 它的 Table 7 只有三個防禦
   （JPEG、Randomized Smoothing、TVM），而且：
   - **沒有空白地板**。它報的是 NCC 與 FID 的絕對值，沒有扣掉「淨化算子自己
     就會把生成推開」那一項。
   - **沒有等失真的隨機對照**。本專案已經量到：淨化之後最佳化相對同幾何隨機
     雜訊的優勢幾乎消失（裁切 1.13、jpeg→resize 1.04，見
     `runs/ip2p_patch_breadth_purify/README.md`）。沒有隨機對照就分不出
     「防禦守住了」與「衣服上有一塊很吵的東西」。
   - 它自己的數字顯示**淨化把浮水印打掉一半以上**：NCC 由 0.31 掉到
     JPEG 0.21、RS 0.20、TVM 0.16。論文的行文把這讀成「仍有殘留」，
     但那個衰減形狀與本專案量到的補丁族相近。

3. **保護對象不同。** 它保護的是**畫作的風格與版權**（模仿類攻擊），
   本專案現行的保護對象是**人的身分**（編輯後認不出是誰）。它的 NCC 量的是
   輸出裡浮水印的相關係數，量不到「還認不認得出那個人」。

## 二、Trippodo (ACM MM 2025)：對「怎麼量」提出的批評與本專案同向

### 它做什麼

**Attention Attack**：破壞文字 prompt 與影像表徵之間的 cross-attention。
關鍵設計是**用原圖自動生成的 caption 當作編輯 prompt 的代理**，於是
**不需要知道攻擊者會下什麼指令、也不需要知道用哪個編輯方法**。
基準：TEDBench++。

### 可以參考的地方

1. **它明確質疑既有的免疫成功度量，並提出兩個新的。** 這與本專案反覆踩到的
   同一個坑一致——代理讀數看起來很好、拉圖之後判讀相反（本專案已發生三次）。
   它提出的兩個：
   - **Caption Similarity**：比較「編輯原圖」與「編輯防禦圖」各自 caption 的
     語意一致性。
   - **semantic IoU**：用分割遮罩量空間佈局被破壞的程度。

   本專案現行的主讀數是**臉部身分相似度**（`src/metrics/identity.py`），
   與它們互補：身分讀數回答「還認不認得出是誰」，Caption Similarity 回答
   「畫面內容還是不是同一件事」。**semantic IoU 特別值得補**——本專案已經
   在跑 ATR 分割，量編輯前後的遮罩 IoU 幾乎沒有額外成本，而它能抓到
   「人還在但被整個換掉」這種身分讀數與 LPIPS 都判不準的情形
   （實測 `284852`／`410264` 的輸出是服飾型錄照，人被換掉了）。

2. **不需要知道編輯 prompt** 這個設定比本專案現行的更嚴格。本專案目前是
   白盒且指令已知（三類 prompt 都是我方指定的）。它的 caption 代理是一個
   把設定放寬到「指令未知」的具體作法。

### 與本專案立場衝突的地方

**它要求 imperceptible**（摘要明寫 "while remaining imperceptible"），
與使用者裁定的「可見的防禦是允許的」相反。同 Zhu 那一篇，**失真預算不在
同一個軸上，數字不可直接並列**。

## 三、對現行工作的三個具體影響

1. **可見產物的立場有 CVPR 論文背書**，不再只是本專案的內部裁定。撰稿時
   可引 Zhu 對 chaotic texture 的批評作為動機。

2. **模板錨定（給定 logo）有現成的作法可抄**：罰在編輯輸出上而不是防禦圖的
   補丁內容上。那是 Zhu 的 `L_adv`。

3. **semantic IoU 應該補進讀數**。成本近乎零（ATR 已在跑），而它針對的正是
   本專案量不準的那一類失效。

**兩篇都沒有本專案的量測協定**（空白地板、等失真隨機對照、兩個失真軸），
故它們報的抗淨化數字不可直接拿來對照本專案的表。
