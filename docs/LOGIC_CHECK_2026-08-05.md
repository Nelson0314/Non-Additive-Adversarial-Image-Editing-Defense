### ~~C2 80% 門檻與隨機對照的關係沒有寫成判定式~~ —— 已解決

**使用者 2026-08-05 定案：門檻提高到 85%，並加上與高斯隨機對照的比較為必要條件。**

```
主張二成立 ⟺ (a) drop(非加性) ≥ 0.85 × drop(最佳 baseline)
           且 (b) drop(非加性) >  drop(R)
```

(b) 是防止「達標但只是隨機水準」——先驗實測高斯隨機雜訊即可取得最佳化解
60–74% 的語意失效，只有 (a) 的話落在該區間內的結果仍可能達標。

R 的構造是「同一種參數化、參數取高斯隨機、射線縮放到同一 τ」，
故 (b) 量的是最佳化相對於同形狀隨機擾動的增益，不混入參數化本身的效果。

### C4 編輯成功閘門未排進主表之前 —— 使用者裁決：先跑主表，事後補

> **2026-08-05 使用者裁決**：閘門不排在段 0 之前，主表先跑，閘門事後補。
> 以下記錄該決定所承擔的風險，供事後判讀主表時參照。

先驗總結（`ADVISOR.md`，已移除，取回見 `INDEX` §4）§2 第三項要求「三個目標的實驗均須在『該模型於正常情況下確實能
完成編輯』的影像上進行」。先驗實驗未做這道過濾，24 張中至少 3 張的未防禦編輯
明顯失敗（`woman_00 → a man` 輸出仍為女性、`man_02 → a woman` 仍為男性、
`bird_00 → a butterfly` 仍為鳥）。

**但那批證據是在 w = 1 下量的**，而該文件 §3.4 把「攻擊方未啟用
classifier-free guidance」列為 147 格不可解讀的第一成因：該設定下 SD v1.4
幾乎不服從 prompt（`CLIP(原圖) 0.2030 → CLIP(編輯結果) 0.2132`，升 0.0101
而標準差 0.0169，即編輯根本沒有發生）。故先驗的失敗率對 w = 7.5 的設定
**沒有預測力**，真實失敗率未知。

**承擔的風險**：若 N = 3 之中有影像的未防禦編輯本來就失敗，該影像上的
免疫效果不可解讀，而 N = 3 下失去一張即失去三分之一。

**事後補的作法**（主表跑完後執行，不得省略）：

1. 對主表用的 N 張影像，各以未防禦原圖跑 n = 5 個種子的完整攻擊方 pipeline
   （w = 7.5、50 步、strength = 0.6），算
   `edit_effect = SigLIP(y_edit, prompt) − SigLIP(x_orig, prompt)` 的平均與標準差 σ。
   **σ 必須在 SDXL／1024²／w = 7.5 上重量**，先驗的 0.0237 是 v1.4／512²／w = 1 的值。
2. 判定 `edit_effect > 2σ`。
3. 人眼複核：`compare.html` 逐張確認未防禦編輯確實照 prompt 改動。
   指標與人眼矛盾時以人眼為準（§1.1 的判準位階）。
4. 未通過的影像，其全部格點在報表中標為不可解讀，**不從平均中悄悄剔除**。

工具已存在：`scripts/l3_edit_success.py`（只跑 SigLIP 前向，不跑 SDEdit）。
