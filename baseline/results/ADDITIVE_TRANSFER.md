# 穿透拆解：位移裡有多少是防禦端的改動原樣穿過編輯器

> 本文的顏色列數字屬於舊顏色方法 `colour_curve_ours`（對應 commit `0dd243b` 的 `passthrough.csv`）。現行 `passthrough.csv` 的顏色列已換成 `color`，本文未改寫。

`results/displacement.csv` 的位移 `D = LPIPS(edit(x), edit(x_def))` 把兩件事算在
一起：防禦圖的改動**原樣穿過**編輯器所造成的差異，以及編輯器真的被推離原本輸出的
部分。這份讀數把兩者分開。

    D   = LPIPS( edit(x),    edit(x_def) )     現行位移
    P   = LPIPS( edit(x),    T̂(edit(x)) )      完全等變時的預測位移
    D_T = LPIPS( T̂(edit(x)), edit(x_def) )     扣掉穿透後的位移

`T̂` 是把防禦端的改動套到編輯輸出上的預測。**本檔的 `T̂` 是加性族**：
`T̂(y) = clip(y + (x_def − x), 0, 1)`，再量化到 8 bit（編輯輸出是從 PNG 讀進來的，
預測不走同一個量化階，`P` 會含一層只存在於浮點的差異）。

主表十二個條件裡十一個是加性擾動（像素域或 DCT 係數域的 PGD、前饋式的 DiffVax），
這個 `T̂` 對它們就是該方法自己的擾動，不是近似。**`colour_curve_ours` 是全域色調
映射**，它的 `T̂` 該由參數族回推；本檔對它照樣用加性版本，是為了讓十二列落在同一個
`T̂` 定義下。兩種算法在它身上的差距見下面「與另一批的對照」。

協定：ip2p、主種子 20260812、四句指令、八張人像，每條件 32 格，共 704 列。
`piq.LPIPS()`（VGG），分區遮罩與 `code/edit_displacement.py` 同源。
逐格資料在 `results/passthrough.csv`，產生程式 `code/passthrough_readout.py`。

## D_T 大於 D 的那幾列

`D_T/D` 有五列超過 100%（原生的 `dct_shield_y` 122%、`dct_shield` 116%、
`photoguard_linf` 115%、`photoguard_c` 106%，等失真的 `dct_shield` 107%、
`photoguard_c` 101%、`dct_shield_y` 105%、`photoguard_linf` 112%）。

**LPIPS 不是度量**，`D`、`P`、`D_T` 之間沒有三角不等式可用，所以 `D_T ≤ D` 不成立。
對加性擾動，`T̂(edit(x))` 是「編輯輸出**再疊上一層原始擾動**」，而 `edit(x_def)` 裡
的擾動已經被擴散過程改造過；兩層高頻雜訊不對齊，量到的距離可以比不疊那一層時更遠。
把 `T̂` 從加性改成別的族不會改變這件事，它來自「編輯器對高頻擾動不等變」。

## 擾動有沒有原樣穿過：直接量 δ 與 Δ 的關係

上面的 `P` 只回答「假設改動原樣穿過，位移會有多大」，不回答「它有沒有真的穿過」。
後者可以直接量：`δ = x_def − x`（防禦端的改動）與 `Δ = edit(x_def) − edit(x)`
（編輯端的差）。改動原樣穿過時 `Δ ≈ δ`——相關係數接近 1、殘差比
`‖Δ − δ‖ / ‖Δ‖` 接近 0、放大倍數 `‖Δ‖ / ‖δ‖` 接近 1。

八個代表性的臂 × 條件（每個 32 格的平均，純算術、不用模型）：

| 臂／條件 | corr(δ, Δ) | 殘差比 | \|δ\| rms | \|Δ\| rms | 放大 |
|---|---|---|---|---|---|
| native `colour_curve_ours` | 0.709 | 0.630 | 0.14198 | 0.16090 | 1.13× |
| native `photoguard_linf` | 0.279 | 0.937 | 0.04712 | 0.18055 | 3.83× |
| native `mist` | 0.239 | 0.958 | 0.04617 | 0.13184 | 2.86× |
| native `dia_r` | 0.064 | 1.003 | 0.00925 | 0.07671 | 8.29× |
| native `dct_shield` | 0.027 | 1.002 | 0.03234 | 0.30341 | 9.38× |
| aligned `dia_r` | 0.065 | 1.003 | 0.00949 | 0.07759 | 8.18× |
| aligned `mist` | 0.041 | 0.999 | 0.00372 | 0.06938 | 18.65× |
| aligned `dct_shield` | 0.029 | 1.002 | 0.01027 | 0.11038 | 10.75× |

全域色調映射那一列的相關是 0.709、放大 1.13 倍：防禦圖上的色偏與編輯結果上的色偏
是同一個東西。加性擾動各列的相關在 0.03–0.28，編輯端的差比防禦端的擾動大
2.9 到 18.7 倍，殘差比接近 1——**編輯輸出上的痕跡不是防禦圖上那層擾動被帶過去的，
是編輯器產生的另一個更大、圖案也不同的東西**。

這與各方法的設計一致：Mist 把 VAE latent 推向目標圖，擴散因此畫出目標圖的紋理；
那是編輯器的輸出，不是 `δ` 的複製。所以這類痕跡落在 `D_T`（編輯器被推離原輸出）
而不是 `P`（改動原樣穿過）。兩者都讓輸出變了，但來源不同，拆解的用途就是分開它們。

**這八列是代表性抽樣，不是全部二十二個臂 × 條件。** 逐格資料在
`results/perturbation_transfer.csv`（若該檔不存在表示完整版尚未跑，量法見本節）。
