## 1. 任務界定

**目標：為「保真約束」找出更好的方法，不限於目前用的 LPIPS / PSNR / DISTS。
要做 paper survey，找更多研究與指標來做約束訓練。**

**這仍然是為主軸服務的，不是新方向。** 主軸未變：

> 在白盒（攻擊方用 stock Stable Diffusion）、外掛模組形式下，找出非加性方法，

保真約束之所以現在變成關鍵，是因為 E18/E19 證明了**現行約束會被鑽漏洞**：
最佳化去買 LPIPS 不收費的模糊，使「匹配失真」這個前提失效。主軸的成敗
直接卡在這裡——不修好它，site S 的 1.15× 與 A 族的 0.0716 都無法解讀。

## 2. 為什麼需要這件事：兩條獨立證據

**證據一（E19）**：`latent_opt` 的損失是 `mse + λ·lpips`。λ=0.1 時 LPIPS 改善
47%，銳利度卻從 95.7% 掉到 84.2%。LPIPS 對這種模糊幾乎不收費。

**證據二（E15 重判）**：匹配 LPIPS 時，site S 的銳利度 85.2%、site P 100.7%，
差 15.4 個百分點。所謂「匹配失真」在銳利度這一軸上完全沒有匹配。

**人眼確認**：使用者看 E18 的前後比對，回報「不差，但比較鈍」——與上述量測
一致，且是在指標給出矛盾訊號時由肉眼定調的。

**DISTS 不是解答**：依鈍化程度排序，DISTS 判退步的三張是第 1、4、5 名，
dog_01 鈍化到 81.9% 仍判改善。已加入的 `acutance` 補上了這一項，但那只是
一個補丁，不是有系統的保真約束設計。

### 3.2 值得調查的方向

以下是待查證的候選，**尚未做過 survey，不要當成結論**：

- **多指標聯合約束**：如何組合而不讓某一項被鑽漏洞。是加權和、還是各自設
  hinge、還是取最壞者？後者對「鑽漏洞」最穩健但可能過嚴。
- **對抗性強健的感知度量**：LPIPS 被直接梯度下降時會被攻擊，這在文獻上
  應有討論（可查 perceptual metric robustness / adversarial attacks on
  perceptual metrics）。
- **無參考品質指標**：NIQE 已在 suite 裡但沒用過。它不需要原圖，可能對
  「看起來鈍」較敏感。
- **頻域約束**：銳利度只是一階近似。功率譜距離、頻帶能量分佈可能更完整。
  `src/metrics/spectrum.py` 已有頻譜相關程式，先看它做了什麼。
- **人眼實驗的替代**：本次是靠使用者肉眼定調的。是否有可自動化的 proxy，
  使這種判斷不必每次都靠人。

### 3.3 判準

任何候選要能回答：**把它加入約束後，site S 還能不能靠模糊換取防禦效果？**
可用 E15 τ=0.05 的資料直接檢驗——那組影像的 `orig.png` 與 `defended.png`
已在 `runs/e15_{S,P}_tau0.05/` 入庫，不需 GPU 即可重算指標。
