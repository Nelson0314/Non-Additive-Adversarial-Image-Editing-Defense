## 三件這張表說了的事

**一、網格族在兩個失真軸上都勝過同失真的隨機對照，倍率隨強度遞減。**
DISTS 軸 1.50 → 1.11，LPIPS 軸 1.48 → 1.20。兩個軸的判定一致，
這一點與 `位移場`（FND-004，與同失真隨機無法區分）不同。

**二、曲線族只有一個錨點與它的隨機對照可比，倍率 1.09×。**
等 LPIPS 0.1882 上 `color_curve` 0.2560 對 `color_curve_rand` 0.2358。
其餘錨點兩條曲線的範圍不相交，回報範圍外。**曲線族目前沒有「最佳化買到東西」
的證據**；192 個參數（3K）的自由度是不是不夠，這一批答不了，要加半徑或加
分段數才問得出來。

**三、隨機對照抽角點是必要的。** 抽盒內均勻時，曲線族 64 個係數的擾動互相
抵消，同半徑下的失真只到角點的三分之一（`runs/color_field_cost/`），
兩條曲線幾乎不重疊、每個錨點都會回報範圍外。**那不是「贏過隨機」，
是根本沒比到。** 抽樣方式逐列寫在 `color_rand_draw` 欄。

## 與其他兩族並排時的三個保留

1. **影像集合不同。** 相位族與 DCT-Shield 的頭對頭（`runs/ip2p_matched_headtohead`）
   只有兩張，本批六張，明暗場十三張。三者的平均不是同一組影像上的，
   逐圖相減做不了。
2. **失真軸對色彩族偏鬆。** LPIPS 與 DISTS 是結構／紋理度量，對全域色偏的
   懲罰偏輕。ΔE00 那一欄就是為此而加：本批最佳化工作點的 ΔE00 落在
   10.7–18.2，**遠高於「剛可辨」的 1**，這些防禦圖在顏色上是明顯不同的。
   使用者已裁定可見的防禦是允許的，但比較時要三個軸一起看。
3. **未淨化欄不是這一族的主張所在。** 在 DISTS 0.0941 上網格族是 0.2956，
   而相位族在 0.0829 上是 0.537（不同影像集合）。這一族若成立，成立的地方
   是抗淨化那幾欄——那正是 `runs/ip2p_color_purify/` 在量的。
