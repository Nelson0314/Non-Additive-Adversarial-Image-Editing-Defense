## 1. 算子

```
x_def = OLA( irfft2( rfft2(w·P_b) · exp(i·g_b·m_ω·θ_b) )·w ) / OLA(w²)
```

把影像切成 32×32 重疊區塊（hop 16、Hann 窗），對每個區塊做 rfft2，**只把相位
乘上一個模長為 1 的複數，幅度譜逐位保留**，再 irfft2、加窗、重疊相加，最後除
以 `OLA(w²)` 正規化。512² 上共 1089 個區塊 × 32×17 個頻格，**592,416 個參數**
（加性 δ 為 786,432）。

`θ` 是唯一的參數。兩個閘由原圖算一次即固定、**不參與最佳化**：

- `g_b` **紋理閘**：結構張量的 coherence 導出，`(1 − coh²)·clamp(energy/ref, 0, 1)`。
  邊緣與平坦區皆為 0，只在紋理區開啟。實測有效面積 0.279–0.465
- `m_ω` **徑向閘**：`r < r_min = 0.12` 的低頻歸零，另把 `fx = 0` 與 `fx = N/2`
  兩行歸零以維持共軛對稱（544 格中的 67 格）

### 三個由構造保證的性質（皆已逐次複驗）

| 性質 | 實測 |
|---|---|
| `θ = 0` 時輸出等於原圖 | `max|x_def − x|` = **5.96e-07**（float32 機器精度） |
| 單區塊的幅度譜逐位保留 | `max‖X·e^{iθ}| − |X‖` = **4.77e-07** |
| 整圖幅度偏差（重疊相加後） | θ=1.30 時 **0.0236** |

第一條由 `OLA(w²)` 正規化保證。該式是 Griffin & Lim (1984) 對「由被修改過的 STFT 還原訊號」的最小平方解，**依賴的是 NOLA 而非 COLA**（COLA 是充分條件，必要的只是 `Σw² > 0`）。第二條是代數恆等式
`|X·e^{iθ}| = |X|`，實作上乘單位模複數而非拆 `abs`／`angle`——後者在原點的
梯度未定義。

**文獻依據**：Random Phase Noise（Galerne, Gousseau & Morel, IEEE TIP 20(1):
257–267, 2011）——隨機化 Fourier 相位可保留微紋理的外觀。`phase_rand` 就是
RPN 本身，是紋理重相位的同失真對照組。

### 為什麼失真有天花板

相位是週期量，`|θ| ≤ π` 是**構造上的上限**，與加性的 ε 可以無限放大不同。
天花板落在哪由 `r_min` 決定：`r_min=0.25` 對應 DISTS 最多 0.055、`0.12` 對應
0.10、`0.05` 對應 0.43——但 `0.05` 的幅度譜偏差由 0.03 衝到 0.41、PSNR 掉到
12 dB，**那已不是重排相位而是毀圖**，故定 `r_min = 0.12`。

## 2. 怎麼量的

### 條件

| 組 | 條件 | 預算 |
|---|---|---|
| 紋理重相位 | `phase` | θ = 1.30（人眼門檻） |
| 內部對照 | `add` | ε∞ = 1.2/255（人眼門檻） |
| 內部對照 | `phase_rand` | θ = 1.30（同失真隨機相位＝RPN） |
| 弱 baseline | `apa_weak` | 原生 ε_a = 0.4（latent） |
| 強 baseline | `mist` | 原生 ε∞ = 16/255 |
| 強 baseline | `dia_r` | 原生 ε∞ = 0.025 |
| 強 baseline | `photoguard_c` | 原生 ‖δ‖₂ = 16（**L2 不是 L∞**） |

`phase`／`add`／`phase_rand` 三者共用**同一個損失、同一條更新式、同一個步數與
種子**，唯一的變因是參數化——這是本專案第一次做到可歸因的加性 vs 非加性比較
（先前每次都同時換掉四五個東西，見 FND-028／029）。

損失是 encoder-targeted `‖E(x_def) − E(gray)‖²`，形式取自 PhotoGuard 的
encoder attack（Salman et al., ICML 2023 §3.1）。**`add` 因此本質上就是
PhotoGuard 的 encoder attack**，不是我們的發明。

### 讀數

- `effect` ＝ `LPIPS(未防禦的編輯, 防禦後的編輯)`，量在完整 512² 上
- `retention` ＝ `effect(淨化) / effect(identity)`，3 個編輯 seed，
  分母低於三倍標準差時標 `usable=False`

### 人眼門檻怎麼定的

`runs/phase_sweep` 掃 9 個 θ × 9 個 ε × 6 張影像，報十六項指標，做成對比頁由
使用者人工劃線。裁定：**phase θ = 1.30、add ε = 1.2/255**。

**沒有任何單一指標能當兩個家族的共用預算軸**——兩條門檻在十六項指標上沒有
一項落在同一個值：

| 指標 | phase @ 1.30 | add @ 1.2/255 | 差距 |
|---|---|---|---|
| DISTS | 0.0374 | 0.0083 | 4.5× |
| **LPIPS** | 0.2067 | 0.1609 | **1.28×（最接近）** |
| GMSD | 0.0526 | 0.0015 | 35× |
| L∞ | 0.3326 | 0.0047 | 71× |
| PSNR | 34.37 | 48.46 | −14.1 dB |

NIQE 看似只差 0.9%，但它在整條相位掃描上只從 3.75 動到 4.28 且非單調——
**一致來自不敏感，不是準確**。

## 4. 被推翻過的說法（不要重犯）

### 「retention 比值可以直接比」——不成立

`retention` 與**分母大小**的相關是 Pearson **r = −0.83**（`runs/hb5`）。順序
幾乎完全由 `effect(identity)` 決定：

| 條件 | 分母 | 平均 retention |
|---|---|---|
| `mist` | 0.5758 | 0.8825 |
| `phase` | 0.4412 | 0.9408 |
| `photoguard_c` | 0.4378 | 0.8358 |
| `apa_weak` | 0.2717 | 1.7511 |
| `add` | 0.2516 | 1.3421 |
| `phase_rand` | 0.1915 | 2.1022 |

機制：**強淨化算子自己就會把編輯推開**。`crop_resize` 之後七個條件的絕對
位移量收斂到 0.495–0.617，`noise 0.05` 之後收斂到 0.434–0.564——與有沒有
防禦幾乎無關。比值 =（防禦效果 ＋ 算子地板）/ 防禦效果，分母越小越被灌大。

FND-033 的「勝 9/10」在 DISTS 對齊下成立，因為當時兩個分母只差 7.7%
（0.5094 對 0.4728）。人眼門檻把 `add` 的分母壓到 `phase` 的 57%，比值就
失去可比性。**FND-033 不必撤回，但適用條件必須寫明「分母相近」。**

### 「DISTS 與 LPIPS 低估相位的可見失真」——方向相反

我曾從 3× 放大圖判定相位的塊狀斑駁比加性的顆粒更難看，並據此說 DISTS 低估
相位。使用者的門檻判定推翻了這一點：**人眼接受 phase 到 DISTS 0.0374，加性
只到 0.0083**——同一個 DISTS 上相位便宜 4.5 倍。3× 放大不是觀看尺度。

連帶：FND-032 的 0.90–0.93× 是在 DISTS 對齊軸上量的，而該軸把 `add` 放到
它自己可接受上限的 4.8 倍。**0.90–0.93× 是悲觀下界，不是樂觀上界。**

### 已測過並否決的方向

注意力抑制／分類器 CE／latent／CLIP 四種 reward、DISTS 進 loss 的軟約束、
Adam 更新規則、位移場、cross-attention 注入、分階段注入、amortized generator、
顏色通道、**紋理重相位搬進 latent（latent 臂）**。結論留在 FND-004、FND-023…034。

latent 臂無效的機制：要利用的落差是「人眼與 DISTS 對紋理重取樣寬容、VAE encoder
對相位敏感」，而 latent 擾動已在 encoder 之後。**優勢是像素空間特有的。**

## 5. 還缺什麼（依優先序，2026-08-16 更新）

**已補上的**（原第 1 項）：空白地板控制組已於 2026-08-16 跑完（FND-043）。
主張一因此可判定：扣掉地板的淨增益上，本方法勝加性 9/9、勝 photoguard_c 8/9、
勝 dia_r 9/9、勝隨機相位 9/9，輸 mist 0/9（而 mist 的失真是 3.3 倍）。

仍然缺的：

1. **逐圖把 θ 對齊到固定失真。** 現行固定 θ = 1.30 讓 PSNR 逐圖漂 **16.4 dB**，
   而該漂移與「相位在哪張圖上贏」的相關是 **r = +0.776**（FND-038）。
   `fit_to_budget` 已存在，只是沒有用在人眼門檻的批次上。
   另一條路是 `arXiv:2602.06577` 的幅度相依相位上限 `2·arcsin(ε/(2|X|))`，
   讓可動範圍隨局部幅度反比縮放（`SURVEY_2026-08-16.md` §2.2）。**最高優先**
2. **人眼裁定操作點。** 閘掃描顯示固定 θ 時 `r_min` 拉高在四個指標上一致更省；
   但把省下的失真用 θ 花掉之後，優勢只剩 DISTS 軸，LPIPS 反而變差（FND-042）。
   兩個軸相反，只能由人眼決定用哪個操作點
3. **`photoguard_c` 的失真是否通過人眼門檻**。它的 L∞ 是 36–116/255（遠超
   加性門檻的 1.2/255），但 L2 球讓擾動極稀疏故 PSNR 仍有 40.9。指標分不出來，
   只能人眼裁定
4. **雙盲 2AFC 使用者研究**。目前的門檻是單一評分者、非強迫選擇，審稿人會直接
   攻擊「相位拿到 8.3 倍的 DISTS」。**排在第 1 項之後**——若逐圖對齊改變了數字，
   門檻要重定，先做的 2AFC 會白做
5. 把 **DCT-Shield（ICCV 2025，arXiv:2504.17894）** 加進 baseline。它是 DCT 係數上的
   **加性**方法，主張與本方法逐條重疊（更少瑕疵、抗 JPEG、參數量少 67%），
   且**它同時是「保不保留幅度」的對照組**（`SURVEY_2026-08-16.md` §1、§4.2）
6. **「同樣位置、同樣頻帶的加性」對照組**。效果與幅度譜偏差的相關是 r = +0.449
   （FND-040），目前沒有任何實驗排除「效果來自那 1–6.5% 的新能量」。
   `add` 是全圖無限制的加性、`phase_rand` 也保留幅度，兩者都不隔離這個變因

## 6. 怎麼重跑

```bash
# 失真掃描（定人眼門檻）
python scripts/phase_distortion_sweep.py --out runs/<批次>

# 像素臂：人眼門檻
python scripts/phase_ablation.py --out runs/<批次> --data data/lo_aligned \
    --human-threshold

# 七條件對照（弱＋強 baseline）
bash scripts/run_hb5.sh <job> <gpu>        # 具名工作表見該檔

# 抗淨化（跑在已存的防禦圖上，不重跑攻擊）
python scripts/phase_retention.py --run runs/<批次> --seeds 3

# 空白地板（算子自己造成的位移，2026-08-16 新增）
python scripts/phase_retention.py --run runs/<批次> --seeds 3 --floor     --images man_02 woman_02 dog_03 horse_03 cat_01     --out runs/<批次>/retention_floor.csv

# 第二個編輯 prompt／換目標影像／換閘設定（2026-08-16 新增的旗標）
python scripts/phase_ablation.py --out runs/<批次> --human-threshold     --prompt-index 1
python scripts/phase_ablation.py --out runs/<批次> --human-threshold     --conditions phase --target data/targets/noise.png
python scripts/phase_ablation.py --out runs/<批次> --human-threshold     --conditions phase --r-min 0.25 --phase-radius 2.6

# 報告
python scripts/hb5_arch_assets.py --out runs/<批次>/arch
python scripts/hb5_report.py --out report.html
```

**平行必須分片**：`write_csv` 每次呼叫都整份覆寫 `results.csv`，兩個行程寫
同一個目錄會互相蓋掉。每張卡給自己的 `--out`，最後用 `merge_runs.py` 併。
