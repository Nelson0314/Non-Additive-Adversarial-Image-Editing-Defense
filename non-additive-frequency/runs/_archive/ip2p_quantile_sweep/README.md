# 紋理閘的開度：在等失真上完全沒有作用

**這些數字尚未進入 `docs/RESULTS.md`**，等使用者裁定。

由 `scripts/quantile_sweep.sh` 跑出。`--quantile` 是紋理閘的開度，
`PENDING.md` 第二節記為「**從未量過**」——它一直跟著半徑一起動，沒有單獨掃過。
13 張人眼確認服從的影像，兩個開度 × 三個半徑，其餘旗標與 `b_ph_*` 相同
（純相位、`--spectral-floor 0.04`、`latent_norm`、1000 步）。

## 這個旋鈕的方向要先講清楚

閘是 `clamp(tr / ref, 0, 1)`，其中 `ref = quantile(tr, --quantile)`，`tr` 是
逐區塊的紋理能量。

- **`--quantile 0`**：`ref` 取最小值，於是幾乎每個區塊都被夾到 1，
  **閘等於全開**——這是**現行主線的設定**。
- **`--quantile` 越大**：`ref` 越高，只有能量最高的那一小撮區塊拿得到滿權重，
  **閘越選擇性**。

所以這一批掃的方向是「**把閘關得更緊**」。往「更均勻」的方向沒有可掃的空間——
主線已經在最開的那一端。逐區塊的空間集中度（`block_gini` 0.43–0.65）因此不是
來自這個旋鈕，而是來自 `(1 − coh²)` 的邊緣抑制與 `|spec|` 本身的乘法性。

## 等失真：三個開度落在同一條曲線上

`matched_distortion_table.py` 把三族各自內插到同一個 DISTS：

| 錨點 DISTS | quantile | 位移 | PSNR | 擋下 |
|---|---|---|---|---|
| **0.0833** | 0（全開） | 0.6310 | 27.47 | 9.0 |
| | 0.30 | 0.6322 | 27.43 | 7.8 |
| | 0.60 | 0.6168 | 27.29 | 9.0 |
| **0.1172** | 0（全開） | 0.6835 | 25.89 | 11.2 |
| | 0.30 | 0.6887 | 25.76 | 11.2 |
| | 0.60 | 0.6828 | 25.56 | 12.0 |

**三者在兩個錨點上都落在彼此的雜訊裡**：位移差不到 1.1%（0.6168–0.6322 與
0.6828–0.6887）、PSNR 差不到 0.35 dB、擋下數的差異全部小於 ±2/13 的重跑雜訊
（`PENDING.md` 第〇節與 `DECISIONS.md`）。

**判定：`--quantile` 不是一個槓桿。** 把閘關緊到只放行能量前 40% 的區塊，
換不到也不損失任何東西——它只是沿著同一條取捨曲線移動。

## 這對「空間選擇性」那個主張的意思

把這一格與既有的兩格併起來讀，方向一致：

| 動的是什麼 | 可用預算 Gini | 等失真下的差異 | 出處 |
|---|---|---|---|
| 加性下限開啟（`--spectral-floor 0.04`） | 0.531 → 0.163 | 擋下 6/13 → 12/13（**大幅變好**） | `PENDING.md` |
| 價目改成 `complement_rank` | 0.163 → 0.114 | PSNR +0.47 dB、位移 −0.4%（幾乎免費） | `ip2p_floor_gate` |
| 閘關緊（本檔，`--quantile` 0 → 0.6） | — | 全部在雜訊內 | 本檔 |

**「空間選擇性」在現行工作點上量不出價值。** 讓它變均勻（加性下限）大幅變好；
讓它更均勻（`complement`）幾乎免費；把剩下那一點選擇性收緊（本檔）沒有差別。
而空間選擇性正是本方法對 DCT-Shield 的主要構造差異（它由構造 Gini = 0）。

**這不是說閘沒有用**——`(1 − coh²)` 的邊緣抑制沒有被這一批測到，而
`逐像素紋理閘` 已因人臉損傷被否決。測到的是**能量開度這一個旋鈕**沒有作用。
