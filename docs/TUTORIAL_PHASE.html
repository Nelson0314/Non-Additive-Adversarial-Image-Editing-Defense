0　範圍與符號

本專案的任務：攻擊方拿到一張照片，用 stock Stable Diffusion 的 img2img （SDEdit）加上一句文字指令去編輯它。防禦方在照片公開之前，對它做一次 不可見或近乎不可見的修改，使得編輯的結果偏離「未防禦時會得到的結果」。 這是白盒設定：防禦方知道攻擊方用哪個模型。

絕大多數既有方法是加性的——輸出 x + δ， δ 是一張與影像同形狀的小擾動圖，受 ‖δ‖∞ ≤ ε 之類的約束。 本專案要找的是非加性方法：輸出不是「原圖加上某張圖」， 而是原圖經過一個帶參數的變換。紋理重相位就是這樣一個變換。

符號意思
x原圖，取值 [0,1]，形狀 (3, 512, 512)
x_def防禦後的圖
θ相位偏移量，本方法唯一的可學參數
g_b紋理閘，逐區塊一個純量，由原圖算一次即固定
m_ω徑向頻率閘，逐頻格一個 0/1，固定

x_def = OLA( irfft2( rfft2(w · P_b) · exp(i · g_b · m_ω · θ_b) ) · w ) / OLA(w²)

1　一維：訊號與頻率

1.1 離散傅立葉變換

先看一維。一段離散訊號是 N 個數字 x[0], x[1], …, x[N−1]。 離散傅立葉變換（DFT）把它改寫成 N 個複數： 

X[f] = Σ(k=0..N−1)  x[k] · e^(−i·2π·f·k/N)          f = 0, 1, …, N−1

由歐拉公式 e^(iφ) = cos φ + i·sin φ，那個指數項就是單位圓上的一個點。 第 f 個係數 X[f] 在做的事是：讓一個「每繞完整個訊號長度剛好轉 f 圈」 的單位向量掃過整段訊號，每一格用 x[k] 加權，然後把這些向量相加。 若訊號本身含有轉速 f 的成分，那些向量會同向疊加成一個長向量； 若不含，它們散布在圓上互相抵消成接近零。

逆變換把係數變回訊號：

x[k] = (1/N) · Σ(f=0..N−1)  X[f] · e^(+i·2π·f·k/N)

這條式子的意思是：任何一段訊號都可以寫成 N 個複指數（等價於正弦與餘弦） 的加權和，而 DFT 就是把那組權重算出來。權重是複數。

1.2 幅度與相位

一個複數 X[f] 可以寫成極式 X[f] = A·e^(iφ)。 A = |X[f]| 稱為幅度（magnitude）， φ = ∠X[f] 稱為相位（phase）。 把逆變換的第 f 項與它的共軛項（第 N−f 項）合併，得到一個實數的餘弦波： 

(2A/N) · cos(2π·f·k/N + φ)

所以：幅度決定這個頻率成分有多強，相位決定它的波峰落在哪個位置。

數值範例（實算） 取 N = 8，構造一段已知成分的訊號： 
x[k] = 5 + 3·cos(2π·1·k/8) + 2·cos(2π·2·k/8 + π/3)

x = [9.0000, 5.3893, 4.0000, 4.6107, 3.0000, 1.1466, 4.0000, 8.8534]
對它做 DFT（只列前五格，其餘由共軛對稱決定，見 §2.2）：
f複數係數幅度 |X|相位 ∠X對應到
040.0000 + 0.0000i40.00000.0000常數項 5（× N = 40）
112.0000 − 0.0000i12.00000.0000振幅 3、相位 0 的成分
24.0000 + 6.9282i8.0000+1.0472振幅 2、相位 π/3 = 1.0472
30.0000 − 0.0000i0.0000—訊號裡沒有

係數把當初放進去的東西原封不動地取了出來：幅度 40／12／8 就是 5／3／2 乘上比例常數，相位 +1.0472 就是 π/3。DFT 不是近似，是一組座標的更換。

1.3 相位旋轉在單一頻率上等於平移

把某個係數乘上 e^(iθ)，其幅度不變（|X·e^(iθ)| = |X|·|e^(iθ)| = |X|， 這是代數恆等式），相位加了 θ。由 §1.2，該頻率成分的餘弦波整條平移了。

數值範例（實算） 
y      = cos(2π·1·k/8)  = [ 1.0000,  0.7071,  0.0000, −0.7071, −1.0000, −0.7071, −0.0000,  0.7071]
把 f=1 的相位加 π/2 後：   [ 0.0000, −0.7071, −1.0000, −0.7071, −0.0000,  0.7071,  1.0000,  0.7071]

|Y|  = [0, 4, 0, 0, 0]
|Y'| = [0, 4, 0, 0, 0]      ← 逐格相同
波形整條往右移了兩格（8 格的四分之一週期），幅度譜一個位元都沒動。

這是整個方法的核心操作。差別在於：本方法不是對整段訊號的單一頻率轉相位 （那只是平移整張圖），而是對很多個小區塊、很多個頻率各自轉不同的角度。 每個小區塊裡的每個頻率成分各自被推到不同的位置，合起來就是紋理內部的重排。

1.4 幅度與相位誰比較重要

Oppenheim & Lim（Proc. IEEE 69(5):529–541, 1981，The Importance of Phase in Signals） 做過一個著名的實驗：取影像 A 的幅度譜、配上影像 B 的相位譜，逆變換後看到的是 B。結論是相位承載了可辨識的內容結構，幅度不。

這對本方法是一個必須正面處理的問題 如果相位承載內容，那麼隨便動相位就會毀掉影像。本方法能成立， 靠的是 §4.1 的 Galerne 結果與 §6 的兩個閘：只在紋理區、 只在中高頻動相位。§4.4 說明這兩個結論為何不衝突。

2　二維與實數影像

2.1 二維 DFT

影像是二維數字表。二維 DFT 就是先對每一列做一維 DFT、再對每一行做一維 DFT （順序無所謂，這叫可分離性）： 

X[fy, fx] = Σ(ky) Σ(kx)  x[ky, kx] · e^(−i·2π·(fy·ky/H + fx·kx/W))

每一個 (fy, fx) 對應一個二維的平面波：一個沿某個方向、 以某個空間頻率起伏的條紋圖樣。fx 大代表橫向條紋密， fy 大代表縱向條紋密，兩者都大代表斜向的細條紋。 (0,0) 是整塊的平均亮度。

把離中心（低頻）的距離定義為歸一化半徑 r = √(fy² + fx²)（頻率先歸一化到 [−1,1]）。 r 小 = 大尺度、緩慢變化的結構；r 大 = 細節與紋理。 本方法的徑向頻率閘 m_ω 就是用這個 r 來決定哪些頻格可以動。

2.2 共軛對稱與 rfft2

影像的像素值是實數。實數訊號的 DFT 有一個嚴格的結構： 

X[−f] = conj(X[f])          （二維：X[−fy, −fx] = conj(X[fy, fx])）

也就是說，一半的係數是另一半的鏡像，存兩份是浪費。 numpy 與 torch 的 rfft2 因此只存半個平面： 一個 n×n 的區塊變成 n × (n/2+1) 個複數。

數值範例（實算） 8×8 的實數區塊 → rfft2 輸出形狀 (8, 5)。
32×32 的區塊 → (32, 17)，即每個區塊 544 個複數係數。

用 rfft2／irfft2 的直接好處是：輸出是實數這件事由型別保證， 不需要事後檢查或取實部。這在本方法裡很重要，因為我們要對係數做任意的改動， 必須確保改完之後逆變換回來仍然是一張合法的實數影像。

2.3 兩行自共軛的頻格

半平面裡有兩行是特例。fx = 0 與 fx = n/2（在 32×32 裡就是第 0 行與第 16 行） 這兩行沒有「另一半」可以配對——它們必須對自己共軛： 

X[−fy, 0] = conj(X[fy, 0])          X[−fy, n/2] = conj(X[fy, n/2])

如果對這兩行的每一格施加獨立的相位旋轉，這個自共軛關係就被破壞。 逆變換出來的東西仍然是實數（irfft2 保證）， 但它不再是「原幅度、轉了相位」的那個訊號—— irfft2 實質上把不合法的部分丟掉了，幅度譜隨之改變。

數值範例（實算，8×8 區塊）
對哪一行乘上 e^(i·0.8)該行是否自共軛逆變換後幅度譜的最大變化
fx = 0是0.505
fx = 4（= n/2）是同上量級
fx = 2否1.1 × 10⁻¹⁵

radial_gate() 把 fx = 0 與 fx = n/2 兩行一律設為 0， 即這兩行的相位永遠不動。代價是 544 格中失去 64 格的自由度 （另有 3 格因半徑過小被關掉，合計關閉 67 格）。

選擇這樣做而不是「近似地忽略」，理由是後者不會有任何症狀： 圖仍然是實數、看起來也正常，只有那兩行的幅度悄悄變了。 這種只在局部失效、又不報錯的近似是最難查的缺陷。

Galerne 的 RPN（§4.1）不切塊、對整張圖操作，處理的是整張圖的共軛對稱； 切塊之後每個區塊各自有這個問題，這一項是本專案自己的處理。

3　切塊、加窗、重疊相加

3.1 為什麼要切塊

對整張 512×512 的圖做一次 FFT，每個係數都是全域的： 它描述「整張圖裡有多少這個頻率的成分」，不含位置資訊。 改動任何一個係數，改變會抹在整張圖上。

本方法要做的是「只動紋理區、不動臉與邊緣」，這需要局部性。 標準做法是切成小塊、對每一塊各自做 FFT。這樣一來， 第 b 塊的係數只描述第 b 塊裡的內容，改它只影響那一塊附近。

代價是邊界不連續。DFT 隱含假設訊號是週期的： 它把區塊的右邊界直接接到左邊界。真實影像的區塊左右兩邊不會剛好接得上， 那個跳階在頻域裡表現成一整條假的高頻能量（稱為頻譜洩漏）， 而且逆變換之後區塊與區塊的接縫會看得出來。

3.2 Hann 窗

解法是在做 FFT 之前，先把區塊乘上一個兩端趨近於零、中間為一的權重函數， 稱為窗。這樣區塊的邊界值都是 0，接起來就連續了。 最常用的是 Hann 窗： 

w[k] = 0.5 − 0.5·cos(2π·k/n)          k = 0, 1, …, n−1     （週期版）

二維的窗取一維的外積 w[ky]·w[kx]（可分離構造）， 所以中央亮、四邊暗，像一個平滑的圓丘。

數值範例（實算，n = 8 的週期 Hann 窗） 
w   = [0.0000, 0.1464, 0.5000, 0.8536, 1.0000, 0.8536, 0.5000, 0.1464]
w²  = [0.0000, 0.0214, 0.2500, 0.7286, 1.0000, 0.7286, 0.2500, 0.0214]

本專案取週期（periodic）版而非對稱（symmetric）版。 週期版在 hop = n/2 時相鄰窗相加恰為常數 1（見下表），對稱版不是。 本方法的恆等性不需要這個性質，但保留它可以讓 §3.3 的分母遠離零。

3.3 重疊相加、COLA 與 NOLA

區塊之間必須重疊。若不重疊，加了窗之後每個區塊的邊界都被壓到 0， 拼回去就是一張帶格線的圖。取 hop = n/2（相鄰區塊位移半個區塊寬）， 每個像素會被兩個（一維）或四個（二維）區塊覆蓋，把它們相加就補回了邊界。 這個步驟稱為 overlap-add（OLA）。

問題是相加之後總權重不見得是 1。兩個相關的條件：

3.4 STFT：分析與合成框架

「切塊 → 加窗 → FFT」這一整套稱為短時傅立葉變換（STFT）。 反過來「逆 FFT → 加窗 → 重疊相加」是它的合成。 這個框架的統一處理見 Allen & Rabiner，A Unified Approach to Short-Time Fourier Analysis and Synthesis, Proc. IEEE 65(11):1558–1564, 1977。

直接引用 本方法的切塊、Hann 加窗、FFT、重疊相加全部是這套標準框架， 沒有任何修改。這不是本專案的貢獻，是它站的地基。

3.5 修改過的 STFT 與一致性投影誤差

關鍵在這一步。若不改動任何係數，把區塊做 FFT 再做逆 FFT 拼回去， 問題只是「權重要怎麼歸一化」。但本方法要改動係數—— 每個區塊各自轉自己的相位。改完之後會出現一個結構性的問題：

那組係數一般不對應到任何一張真實影像。

原因是重疊。同一個像素同時屬於四個區塊，這四個區塊的係數之間本來有嚴格的 一致性關係。各自獨立轉相位之後，四個區塊對那個像素的「主張」彼此矛盾。 這種係數組稱為 modified STFT。

Griffin & Lim（Signal Estimation from Modified Short-Time Fourier Transform, IEEE TASSP 32(2):236–243, 1984）解的就是這個問題：給定一組不一致的 STFT 係數， 找出一個訊號，使它的 STFT 與那組係數的平方誤差最小。 他們的閉式解是： 

x̂ = OLA( irfft( 修改過的係數 ) · w ) / OLA(w²)

分析時乘一次窗、合成時再乘一次窗，多出來的那一次用窗的平方和除掉。 這正是本方法算子式子裡的 / OLA(w²)。

直接引用 OLA(w²·x) / OLA(w²) 不是本專案發明的。它是 Griffin & Lim (1984) 對「由被修改過的 STFT 還原訊號」的最小平方最佳解，逐字對應。 本專案在 2026-08-16 之前沒有引用這篇，是一個已修正的缺漏。

後果一：θ = 0 時輸出逐位等於原圖

若 θ = 0，係數沒有被改動，分子恰好是 OLA(w²·x)， 與分母 OLA(w²) 逐位相消，得到 x。這是恆等式，不是近似—— 與「加一個懲罰項讓它接近原圖」在性質上完全不同。

數值範例（實算，一維，故意用不滿足 COLA 的 hop = 3） 
分母 Σw²（核心區） = [0.9786, 0.9786, 1.0429, 0.9786, 0.9786, 1.0429, …]
最大重建誤差        = 1.11 × 10⁻¹⁶      ← 浮點機器精度

分母不是常數（COLA 不成立），但恆等仍然成立，因為需要的只是它不等於零（NOLA）。 專案的測試 test_identity_holds_for_non_cola_hop 釘的就是這一點。 實際模組在 float64 下量到 5.6e−16、float32 下 2.98e−07。

後果二：θ ≠ 0 時，「幅度譜逐位保留」只在單一區塊內是恆等的

在一個區塊之內，係數乘上模長為 1 的複數，幅度絕對不變， 這是代數恆等式。但重疊相加＋歸一化這個投影會改動係數， 所以把最終影像重新切塊、重新做 STFT 之後， 各區塊的幅度譜與原圖的不會完全相同。

這個差距就是模組裡的 amplitude_deviation()，記作 amp_dev。 它有正式的名字：STFT 一致性投影誤差。

數值範例（一維玩具，實算）

玩具的數字大很多，原因有二：白噪聲的頻譜是平的（區塊之間毫無相關）， 以及玩具沒有紋理閘與徑向閘去限制 θ 能作用的位置。 真實影像上兩個閘把作用面積壓到 28%–47%，偏差因此小一個數量級。

這是目前方法最大的內部風險

amp_dev 若很大，代表本方法實際上在造新的能量， 而不是重排既有的能量——那它就退化成「一個被紋理遮蔽的加性高頻噪聲」， 非加性的主張就不成立。

實測 amp_dev 與防禦效果的相關是 r = +0.449（FND-040）， 也就是說偏差越大效果越好。這個相關本身不能證明因果， 但它使「效果來自新能量」這個解釋無法被排除。

判別的方法已經知道：Griffin & Lim 論文裡的迭代投影可以把 amp_dev 壓下去（反覆做「STFT → 換回原幅度 → 逆 STFT」）。 跑幾輪之後看效果掉多少，就直接回答了這個問題。此實驗尚未執行。

4　紋理、相位、感知

4.1 Random Phase Noise（Galerne, Gousseau, Morel 2011）

Random Phase Textures: Theory and Synthesis, IEEE TIP 20(1):257–267, 2011。 這篇處理的原生問題是紋理合成：給一張紋理樣本，生成更多張 「看起來是同一種紋理」但不完全相同的圖。

他們的方法（Random Phase Noise，RPN）只有一步： 把影像的傅立葉相位換成均勻隨機值，幅度譜原樣保留 （並維持共軛對稱以保證輸出是實數）。

論文的理論結果是：對一類稱為 micro-texture 的影像 （沒有明顯輪廓、由統計性的細節構成，例如砂石、布料、樹皮、草地）， RPN 的輸出與原圖在知覺上屬於同一種紋理。 機制是紋理的知覺由二階統計量（即幅度譜／功率譜）刻畫， 相位只決定個別紋素落在哪裡，而人眼不逐一追蹤紋素的位置。

數值範例（實算，32×32 紋理區塊隨機相位） 
幅度譜最大差   = 5.33 × 10⁻¹⁵        ← 逐位保留
像素最大差     = 0.4654               ← 像素層級改動很大
像素 RMS 差    = 0.1357
原圖標準差     = 0.1012
輸出標準差     = 0.1012               ← 統計量不變
本專案怎麼用它

把「隨機」換成「最佳化」。 RPN 隨機抽相位； 本方法讓相位成為可學參數 θ，用梯度下降去找「最能推開編輯結果」的那組相位。

RPN 本身在本專案裡以 phase_rand 這個條件存在， 是同失真隨機對照組：若最佳化過的相位贏不過隨機相位， 就代表最佳化沒有找到任何相位特有的東西。 專案先前有兩個方向（位移場 FND-004、另一個 FND-018）正是被這個對照組擋下來的， 所以它從第一天就在，不是事後補的。實測 phase / phase_rand = 2.661， 逐圖 24/24。

另外三項與 Galerne 不同：(a) 本方法切塊，Galerne 對整張圖操作； (b) 本方法有兩個閘限制作用範圍，Galerne 全圖無差別； (c) 因為切塊，出現了 §2.3 那個每個區塊各自的自共軛問題，Galerne 遇不到。

4.2 結構張量與 coherence

紋理閘要回答「這個區塊是紋理，還是邊緣，還是平坦」。用的工具是結構張量 （Förstner & Gülch 1987；Bigün & Granlund 1987）。

先用 Sobel 算子算出每個像素的亮度梯度 (gx, gy)， 再在區塊內對梯度的外積取平均：

J = [ ⟨gx·gx⟩   ⟨gx·gy⟩ ]
    [ ⟨gx·gy⟩   ⟨gy·gy⟩ ]

J 是 2×2 對稱半正定矩陣，有兩個非負特徵值 λ₁ ≥ λ₂。它們的意思是：

  • 直邊：所有梯度都指向同一個方向 → λ₁ 大、λ₂ ≈ 0
  • 雜亂紋理：梯度方向散布 → λ₁ ≈ λ₂，兩者都不小
  • 平坦區：沒有梯度 → λ₁ ≈ λ₂ ≈ 0

把它壓成一個 [0,1] 的數，稱為 coherence：

coherence = (λ₁ − λ₂) / (λ₁ + λ₂)

這個量與這個名稱來自 Weickert，Coherence-Enhancing Diffusion Filtering, IJCV 31:111–127, 1999。該篇的原生問題是影像去噪與線狀結構增強： 沿著相干方向做強擴散、垂直方向做弱擴散，可以把斷掉的線接起來。 它需要一個「這裡有多像一條線」的量，就是 coherence。

本專案的紋理閘是：

g_b = (1 − coherence²) · clamp(梯度能量 / 參考值, 0, 1)
數值範例（實算，16×16 區塊）
區塊內容coherence梯度能量1 − coh²閘的結果
直邊（左黑右白）1.00000.03570.0000關閉
斜條紋1.00000.04500.0000關閉
雜亂紋理0.24100.00640.9419開啟
平坦0.00000.00001.0000被第二個因子關掉
哪裡是自己的設計

coherence 本身是引用的。本專案自己的部分有三項：

  • 取 1 − coh² 而不是 1 − coh： 要的是「不像邊緣」，平方使中間帶（coh 約 0.5）仍然算作可用的紋理。
  • 乘上梯度能量的飽和項：平坦區的 coherence 是 0／0 的雜訊， 單看它會誤判成紋理，而平坦區任何改動都直接可見。
  • 參考值取該影像自己的分位數（預設中位數）而非固定常數： 梯度能量的絕對值隨影像內容差好幾個數量級，用固定常數會讓不同影像 拿到不同的有效閘，而那個差異不會有任何症狀。

實測閘的有效面積是 0.279–0.465，即三成到四成半的區塊被允許改動。

4.3 DISTS：為什麼「重排紋理」在感知指標上便宜

Ding, Ma, Wang, Simoncelli，Image Quality Assessment: Unifying Structure and Texture Similarity, TPAMI 2021。這是一個學習式的全參考影像品質指標。 它把兩張圖丟進 VGG，逐層取特徵，然後不比較特徵的逐點差異， 而是比較每個通道的全域統計量（平均值與變異數）與結構相關項。

論文明文的設計目標之一是 tolerant to texture resampling： 同一種紋理的兩個不同取樣（例如同一塊草地拍兩張）應該被判為高度相似， 而 LPIPS 之類逐點對齊的指標會把它們判成很不同。

本方法的機制假設

要被否證的那一句話是：

人眼與 DISTS 對紋理重取樣寬容，而 VAE 編碼器的卷積特徵對相位敏感。

若這個落差存在，則在同一個「人眼可接受的失真」之下， 相位擾動能換到比加性擾動更大的 latent 位移。這是整個方法要押的東西。

相關證據：專案曾把同樣的相位參數化搬到 latent 空間，無收益（FND-032）。 機制解釋正是——要利用的落差在 encoder 上，而 latent 擾動已經在 encoder 之後。 這個優勢是像素空間特有的。

4.4 Oppenheim 與 Galerne 表面上的矛盾

來源結論適用範圍
Oppenheim & Lim 1981相位承載可辨識內容整張圖、含輪廓與物件邊界的低頻相位
Galerne et al. 2011隨機相位不改變紋理外觀micro-texture、中高頻的統計性細節

兩者不衝突，因為它們談的是不同的頻帶與不同的影像成分。 本方法的兩個閘就是把作用範圍限制在 Galerne 適用、Oppenheim 不適用的那一塊：

閘擋掉什麼對應到哪個結論
紋理閘 g_b（空間上）邊緣與平坦區避開 Oppenheim 的輪廓相位
徑向閘 m_ω（頻率上）低頻格避開區塊的位置與大尺度結構

徑向閘的另一個作用是工程上的：低頻格帶著整個區塊的位置資訊， 動它會讓區塊之間對不齊，重疊相加後產生可見的接縫。

為什麼閘不能隨防禦圖走 若閘隨著當前的 x_def 重算，它就變成最佳化目標的一部分： 梯度會去改變閘自己，把擾動搬到閘剛好放寬的地方。那量到的就不是 「在紋理區做相位擾動能拿到多少」，而是「最佳化能把閘騙開多少」。 程式在閘未備妥時直接拋 RuntimeError，不用預設值兜過去。

  3. m[:, 0] = 0、m[:, −1] = 0（§2.3 的自共軛兩行）

7　訓練與最佳化

7.1 什麼被優化、什麼不被優化

物件是否可學說明

Hann 窗否常數

注意這裡沒有「訓練資料集」也沒有「泛化」。 每一張影像各自跑一次最佳化，θ 是那張圖專屬的。 這與訓練一個神經網路不同，更接近「解一個帶約束的最佳化問題」。

7.2 損失函數

L(x_def) = ‖ E(x_def) − E(y_target) ‖²          y_target = 一張純灰圖

E 是 Stable Diffusion 的 VAE 編碼器。這條損失要求 「把防禦圖編碼出來的 latent，推到跟一張灰圖的 latent 一樣」。 若成功，攻擊方的 SDEdit 在潛空間裡看到的就不是原本那張照片。

形式取自 PhotoGuard 的 encoder attack（§5.3）。選它當三個條件的共用損失有兩個理由：

  1. 只跑 VAE 編碼器，不跑 UNet 也不跑去噪軌跡。一次前向加反向在 512² 上是毫秒量級， 所以「對半徑做二分搜尋以對齊預算」這件事負擔得起。
  2. 它不偏袒任何一個參數化。損失只看 latent，不看擾動長什麼樣子， 加性與相位在同一個目標下競爭。

目標 latent 只編碼一次並 detach——它是常數， 每次迭代重編碼除了浪費之外還會把 VAE 的隨機性帶進損失曲線。

7.3 更新規則：PGD

for i in 0 .. steps−1:
    x_def ← param.render(x)              # 相位條件：跑一次 §6.2 的六步
    g     ← ∇_θ L(x_def)                 # 反向傳播穿過整個算子
    θ     ← θ − α · sign(g)              # 只取梯度的正負號
    θ     ← clamp(θ, −θ_max, +θ_max)     # 投影回約束範圍

三件事值得說明：

梯度怎麼傳回 θ

整個算子（unfold、乘窗、FFT、複數乘法、逆 FFT、fold、除法） 全部是 torch 的可微運算，autograd 自動處理。 θ 影響的是 exp(i·shift) 這個複數乘法， 所以梯度會穿過逆 FFT、重疊相加、VAE 編碼器一路回來。 這是為什麼要避開 angle()：它在幅度為零處的梯度未定義。

為什麼取 sign 而不是直接用梯度或 Adam

取 sign 是為了與三個加性 baseline 中的四篇對齊（它們都用 sign）。 專案自己的實驗（FND-029）已記載 sign 丟掉梯度大小會讓可見失真變差—— 這裡要的是可歸因，不是最佳。 Adam 更新規則也測過，同樣被否決。

7.5 預算怎麼對齊

要比較兩個不同家族的方法，必須讓它們的可見失真相同。有兩條路：

路線 A：對半徑二分搜尋（fit_to_budget）

給定目標 DISTS（例如 0.04 或 0.075），對半徑做二分搜尋， 使最終迭代的 DISTS 落在目標上。 不沿迭代軌跡挑一格——那樣拿到的是一個還沒收斂的 φ， 兩個條件各自停在不同的最佳化進度上，比較的就不只是參數化。 sign 更新會把半徑用滿，所以「半徑 → 最終失真」是單調的，二分搜尋有意義。

相位有構造上的天花板（§6.5），達不到的預算點標為 unreachable 而非 failed。

路線 B：人眼門檻（--human-threshold）

掃 9 個 θ × 9 個 ε × 6 張影像，報十六項指標，做成比對頁由使用者人工劃線， 裁定每個條件各自的可接受上限：phase θ = 1.30、 add ε = 1.2/255。這才是「匹配人眼可辨失真」的字面意思。

「共用同一組噪聲」是必要的：若兩次編輯用不同的隨機噪聲， 測到的差異裡會混入噪聲本身造成的差異，防禦效果就無法歸因。

8.2 效果怎麼量

effect = LPIPS( SDEdit(原圖), SDEdit(防禦圖) )

即「有防禦時的編輯結果，離沒有防禦時的編輯結果有多遠」。 量在完整的 512×512 上。這個讀數在 CSV 裡的欄位名是 edit_lpips。

前置條件 未防禦的編輯必須真的成功（看圖確認），否則這個比較的分母不成立—— 若原圖的編輯本來就沒動，那「防禦後偏離很遠」就沒有意義。

8.3 保真怎麼量

全部指標照報、不挑選：LPIPS、DISTS、PSNR、SSIM、CLIP 影像相似度、 NIMA、CNNIQA，另有 NIQE 與銳利度。加上語意軸的 CLIP-T／SigLIP 掉幅 （照報但不作為成敗判準，理由見 §5.5）。

8.4 抗淨化與空白地板

攻擊方可能先對受保護的圖做一次「淨化」，試圖把擾動洗掉再編輯。 專案測十個淨化算子：blur σ=1、noise 0.05、 quantize 16、jpeg 75、jpeg 30、 crop_resize 0.1、jpeg→resize 串接、 adverse_cleaner、impress，加上 identity。

2026-08-16 補上的關鍵控制組

問題：淨化算子自己就會改變編輯結果，即使完全沒有防禦。 若不扣掉這一項，「淨化後某條件的位移量比較大」無法排除 「該算子本來就把編輯推得比較開」。

空白地板 = effect(purify(原圖))， 即對未防禦的原圖做淨化再編輯，量它與「原圖直接編輯」的距離。

實測地板佔淨化後位移量的 47%–92%。 crop_resize（92%）與 noise 0.05（90%）兩列 實質上不具鑑別力。

9.5 目前已知的四個問題

  1. 新穎性主張必須收窄。相位擾動 ＋ 幅度保留有前例（§5.4）。
  2. DCT-Shield 是直接競爭者，同場景同主張且參數量更少，尚未比較。
  3. 「幅度保留」目前是一個沒有被證明有用的性質。 add 是全圖無限制的加性（位置沒對齊）、phase_rand 也保留幅度， 兩者都不隔離這個變因。加上 amp_dev 與效果的 r = +0.449，這個缺口更尖銳。
  4. 逐圖預算漂移。固定 θ 讓 PSNR 漂 16.4 dB（§7.5）。 已有兩條解法：fit_to_budget 逐圖對齊，或 arXiv:2602.06577 的 幅度相依相位上限 2·arcsin(ε/(2|X|))。

9.6 下一個關鍵實驗

Griffin-Lim 迭代消融（尚未執行）

由 §3.5：amp_dev 就是 STFT 一致性投影誤差， 而 Griffin & Lim 論文裡的迭代投影可以把它壓下去。

做法：在算子輸出之後多跑幾輪「重新 STFT → 把幅度換回原來的 → 逆 STFT」， 量 amp_dev 下降多少、效果掉多少。

這直接回答第 9.5 節第 3 點：若壓掉投影誤差之後效果幾乎不變， 效果來自相位重排；若效果同步塌掉，效果來自新造的能量， 非加性的主張就要重寫。成本只有幾行程式加一次像素臂批次。
