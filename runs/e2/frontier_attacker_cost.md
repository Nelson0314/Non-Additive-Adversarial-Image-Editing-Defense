# 攻擊者代價前緣

`ctrl_lpips` 為未防禦影像走同一淨化後，編輯結果相對未淨化編輯的
偏移，即攻擊者為淨化付出的自身代價。

攻擊者可自由選擇淨化算子，故在給定的自身代價預算 B 下，其最佳
應對是**挑選代價不超過 B 且把防禦壓得最低的那一個設定**：

    best(B) = min { net_lpips(p) : ctrl_lpips(p) <= B }

下表即為此值。取「首個超過門檻的設定」會高估防禦，因為那等於
假設攻擊者隨機選算子。

| arm | 預算 0.00 | 預算 0.02 | 預算 0.05 | 預算 0.10 | 預算 0.20 |
|---|---|---|---|---|---|
| L r=1 | 0.0679 (blur 0) | 0.0625 (quantize 64) | 0.0433 (jpeg 95) | 0.0276 (blur 0.5) | 0.0232 (quantize 16) |
| L r=4 | 0.0671 (blur 0) | 0.0647 (quantize 64) | 0.0383 (jpeg 95) | 0.0294 (blur 0.5) | 0.0253 (quantize 16) |
| L r=16 | 0.0664 (blur 0) | 0.0649 (quantize 64) | 0.0396 (jpeg 95) | 0.0299 (blur 0.5) | 0.0194 (quantize 16) |
| P r=1 | 0.0272 (blur 0) | 0.0198 (quantize 64) | 0.0132 (jpeg 95) | 0.0058 (quantize 32) | -0.0051 (quantize 16) |
| P r=4 | 0.0602 (blur 0) | 0.0495 (quantize 64) | 0.0338 (jpeg 95) | 0.0243 (blur 0.5) | 0.0037 (quantize 16) |
| P r=16 | 0.1133 (blur 0) | 0.0946 (quantize 64) | 0.0686 (jpeg 95) | 0.0621 (noise 0.01) | 0.0126 (quantize 16) |
