# 標記的美化：三個旋鈕，代價幾乎與好看成正比

`scripts/patch_pretty_round.sh`。基底是 `runs/ip2p_patch_direct/ig_comp_subj`
（補集支撐 ＋ `image_guidance` ＋ 主體加權），四格各與它只差一個變因。
六千步，四格皆 `max_steps@6000`。

## 為什麼要美化

學出來的補丁是彩色雜訊，讀起來是「**這塊壞掉了**」而不是「這裡有一個標記」。
差別不在多好看，而在**看起來是不是刻意的**——隨機噪點像檔案損毀，規則圖樣
像浮水印，即使兩者一樣顯眼。

把「像設計品」拆成三個正交的構造，各給一個旋鈕，就能量出美化的代價：

| 旗標 | 構造 | 為什麼看起來像設計 |
|---|---|---|
| `--patch-tile 64` | 只學一塊 64×64 的磚並整片重複 | 規則重複是浮水印的第一視覺特徵；參數量同時降 64 倍 |
| `--patch-alpha 0.5` | `(1−α)·原圖 + α·標記` | 原圖透出來 → 讀成疊上去的東西而不是破洞 |
| `--patch-tv 0.3` | 內容的總變差懲罰 | 柔和色塊取代逐像素噪點 |

## 結果

主體區位移（`regional.csv`）：

| 格 | 盆栽人 | 瑪利歐 | 佔基準 | DISTS | 看起來 |
|---|---|---|---|---|---|
| 基準（自由學） | 0.597 | 0.570 | 100% | 0.225／0.175 | 彩色雜訊，像檔案壞掉 |
| `a050` 半透明 0.5 | 0.475 | 0.488 | **83%** | 0.183／0.133 | 仍是雜訊，只是變淡 |
| `tile64` 平舖 | 0.327 | 0.367 | 60% | 0.226／0.184 | **規則圖樣，像刻意放的** |
| `tv03` 平滑 0.3 | 0.350 | 0.342 | 59% | 0.197／0.151 | 柔和塊狀 |
| `pretty` 三個全開 | 0.118 | 0.195 | **27%** | 0.147／0.133 | **真的像浮水印** |

參照：未最佳化白噪聲補集是 0.149／0.111。

## 三件這張表說了的事

**一、三個旋鈕買到的「好看」，跟付出的效果幾乎成正比。** 沒有免費的美化。

**二、半透明看起來最便宜（83%），但它其實沒怎麼美化**——只是讓雜訊變淡，
產物仍然像雜訊。便宜是因為改動小，不是因為它找到了更好的取捨。

**三、`pretty` 那一格達成了外觀目標但失去效果。** 產物是柔和的粉彩重複色塊、
半透明疊在背景上、被遮住的角色從底下清楚透出來——四格裡唯一看起來像設計品的。
但**看圖：編輯後工具箱仍然變紅、角色完好，攻擊基本上成功**。0.118–0.195 已經
掉回未最佳化白噪聲的水準。

**目前外觀與效果同時可接受的只有 `tile64`。**

## 限制

1. 四格皆未早停，讀數是下界。
2. 只有兩張影像。
3. 「像設計品」是人眼判定，本檔用影像佐證，沒有量化的外觀指標。
4. 三個旋鈕各只掃了一個值，沒有掃強度曲線。`tile128` ＋ `alpha 0.7` 這種
   中間點還沒試過。
