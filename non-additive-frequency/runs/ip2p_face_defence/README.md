# 臉是受保護主體：三類指令 × 兩種覆蓋率 × 十張影像

**成功的定義換了。** 先前的主讀數是主體區位移（LPIPS），量的是像素變了多少；
這一批換成**編輯之後還認不認得出那個人**。約束不變：防禦圖交出去時臉逐位元
不動，發布的照片看起來正常。

## 設定

| | |
|---|---|
| 受保護主體 | ATR 人體解析的 Face(11) ＋ Hair(2)，膨脹 16、往外羽化 24 |
| 載體 | ATR 衣物類 → 導引濾波吸附 → 挖掉偵測到的臉框 → 內縮 3 → 往內羽化 8 |
| `plain` | 支撐＝整個載體，全圖 23% |
| `pretty` | ＋ 分散六個斑塊（總面積 5%）＋ `--patch-tint 3.0`（局部色調拉向衣服） |
| 損失 | `image_guidance`（`--ig-zt diffuse_src`），6000 步、步長 0.01 |
| 指令 | `data/attack_prompts.yaml` 的三類，兩類完全固定 |

影像清單與挑選依據見 `runs/carrier_survey/README.md`。

## 主結果：覆蓋率決定成敗

「成功」＝ `id_def` 低於 0.55 參照門檻，或編輯輸出裡偵測不到臉。
「可解讀」＝該列 `id_orig ≥ 0.55`（攻擊自己沒把身分毀掉，扣得出防禦的貢獻）。

| 組 | 可解讀 | 成功 | `id_def` 逐圖分佈 |
|---|---|---|---|
| clothing / plain | 10 | **7** | −0.00 −0.16 0.17 0.41 0.60 0.80 0.82 無臉 ×3 |
| clothing / pretty | 10 | **0** | 0.63 0.66 0.85 0.85 0.87 0.88 0.88 0.94 0.94 0.95 |
| accessory / plain | 5 | **4** | −0.10 0.01 0.02 0.13 0.63 |
| accessory / pretty | 5 | **0** | 0.62 0.63 0.77 0.90 0.92 |
| background / plain | 10 | **3** | −0.10 0.28 0.66 0.75 0.81 0.88 0.89 0.90 0.91 無臉 |
| background / pretty | 10 | **3** | 0.05 0.07 0.85 0.88 0.91 0.91 0.93 0.93 0.97 無臉 |

覆蓋率由 23% 降到 5% 之後，改變衣著與加上配件**全數失效**。失真同時由
DISTS 0.187 降到 0.060。

**變換背景是例外**：兩種覆蓋率都是 3/10，與花紋大小無關，而且分佈**雙峰**
——0.05、0.07 之後直接跳到 0.85 以上。**中位數（0.91）描述不了這件事**，
跨組比較一律要看逐圖分佈。

## 一個反例

`task_attr_mod_color_202962` 在 background/pretty（5%）下輸出幾乎全白、
偵測不到臉、`iou_person` 0.040；同一張影像在 background/plain（23%）反而
失敗（0.661，人還在）。**覆蓋率大不一定比較好。**

## 三個已知的問題

1. **`add a scarf to the person` 這個指令選壞了。** 選圍巾本是為了不遮臉、
   讓 `id_orig` 維持高，實測 20 列裡有 10 列 `id_orig < 0.55`、中位數 0.359
   ——攻擊自己就把人換掉了。那一半資料不可解讀。
2. **`--ig-weight subject` 這個變因漏著。** 舊的主體加權對的是 CLIPSeg 物件
   遮罩；主體換成臉之後沒有跟著換，**這六十格全部沒開**。未受控。
3. **覆蓋率只有兩個點**（23% 與 5%），中間沒有量，「效果從哪裡開始塌」未知。

## 讀數

`identity.csv` 由 `scripts/identity_probe.py` 事後算，只讀已存影像：

- `id_orig` / `id_def` / `id_drop` —— MTCNN ＋ InceptionResnetV1 (vggface2) 餘弦
- `face_found_edit_def` —— 輸出裡偵測不到臉是最強的成功形式，**不可記成 0**
- `iou_person` / `iou_classes` / `n_classes` —— 編輯前後 ATR 分割的 IoU，
  參照是**攻擊在原圖上的結果**不是原圖

0.55 只作參照（VGGFace2 上「同一人」的常見取值），**不進任何算式**。
