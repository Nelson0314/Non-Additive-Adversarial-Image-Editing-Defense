# 可辨性判定

判準由使用者裁定：**攻擊方拿到的輸出，原圖還認得出來嗎。**

| 判定 | 意思 |
|---|---|
| `blocked` | 原圖不可辨。模型重畫成無關的場景，或整張變成噪紋。兩者都算擋下 |
| `borderline` | 主體被摧毀但場景仍推得出來 |
| `failed` | 原圖仍認得出來。只是變糊、變髒、色偏——攻擊方仍拿得到可用的輸出 |

**大幅改動不等於不可辨。** 兩筆 `user_corrected` 記的就是這條界線：
雕花畫框碳化成粉紅絨毛之後仍看得出是「框裡的人像」，冰山那張的山與雲被換掉
之後仍看得出是「水上的冰山」，兩者都判 `failed`。

`judge` 欄：`user_confirmed` 表示助手先判、使用者確認；`user_corrected`
表示使用者推翻了助手的判定。這一欄要保留，因為助手的校準比使用者寬鬆，
之後若由助手預判必須先對這兩筆重新校準。
