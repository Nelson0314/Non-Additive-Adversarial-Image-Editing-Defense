# 影像自然度使用者研究：設計

本文件定義補充材料中「ImmuLUT 防禦圖是否看起來像套用一般濾鏡的照片」的使用者研究。研究只量測 ImmuLUT 防禦圖的外觀，參照對象為常見相片濾鏡，不比較其他防禦方法，也不涉及編輯結果；inpainting 編輯的使用者研究另立設計。架構沿用 AdvCF（Zhao et al., arXiv 2011.06690，Sec. V，CC BY-NC-SA 4.0）的成對選擇形式。

## 1. 研究問題

在分享照片的情境下，受試者於「ImmuLUT 防禦圖」與「同一張照片套用常見濾鏡」之間選擇較願意分享者的比例。比例接近 50% 表示兩者的偏好無法區分。

## 2. 刺激

| 項目 | 設定 |
|---|---|
| 影像池 | crosseditor100（Pexels 人像，主表協定）之 ImmuLUT（`color3d_scale2p5_pexels`）防禦圖 |
| 挑選規則 | 對防禦圖 LPIPS、LAION 美學分數、MUSIQ-AVA 三個指標，各取最接近 100 張中位數的 10 張，取聯集（允許重疊） |
| 影像數 | 28 張（中位數：防禦圖 LPIPS 0.3015、LAION 5.2145、MUSIQ-AVA 5.3259；挑選範圍分別為 [0.2822, 0.3189]、[5.1647, 5.2319]、[5.3025, 5.3397]） |
| 常見濾鏡 | 6 種公開、可重現的全域調色（暖色、冷色、褪色、高飽和、低飽和、復古），每張影像以主種子 20260812 固定指派一種；參數與實作入庫 |
| 顯示 | 原圖 260 px 置於上方，兩個候選版本並排於下方（AdvCF 的三圖金字塔形式），灰色背景 |
| 控制題 | 3 題：一側為常見濾鏡，另一側為色彩通道錯亂的版本，期望選擇濾鏡 |

28 張影像的清單（挑選依據）：man_17、man_20、man_30、man_32、man_46、woman_15、woman_58、woman_75、woman_91（防禦圖 LPIPS）；woman_24、woman_37、woman_39、woman_54、woman_64、woman_70、woman_76、woman_83、woman_97（LAION）；man_37、woman_06、woman_18、woman_28、woman_31、woman_49、woman_56、woman_88（MUSIQ-AVA）；woman_84（LAION 與 MUSIQ-AVA）；woman_90（防禦圖 LPIPS 與 MUSIQ-AVA）。

## 3. 作答形式

- 指導語：想像要把照片分享到社群平台，從下方兩個版本中選出較願意分享的一張（強迫選擇）。
- 每位受試者作答全部 28 題＋3 題控制題，題序與左右位置隨機，預估 8 分鐘。
- 不提及「防禦」「對抗」「擾動」「AI」。
- 基本資料：年齡區間、是否從事攝影或影像處理相關工作、是否有已知的色覺異常；不收集可識別個人的資料。

## 4. 受試者人數

| 文獻 | 人數與形式 |
|---|---|
| Universal Image Immunization via Semantic Injection（arXiv 2602.14679，附錄 B.8） | 20 人（MTurk），20 張影像 |
| AdvCF（arXiv 2011.06690） | 346 名 MTurk 工作者，222 張影像，每張影像保留 10 名最可靠者的判斷 |

本研究目標 20 人，每個影像對約 20 個判斷，共約 560 個判斷。

## 5. 排除規則

事前固定：3 題控制題中選錯 2 題以上者，整份排除。排除人數連同原因回報。色覺異常者不排除，另報排除後的結果。

## 6. 分析

- 主要讀數：ImmuLUT 被選中的比例與 95% 信賴區間（受試者與影像雙層 bootstrap，10,000 次）。
- 依濾鏡種類、依挑選指標（LPIPS／LAION／MUSIQ-AVA）分列比例。
- 依研究規則，報告完整數字，不預設門檻。

- 問卷頁面以 Claude Artifact 加共享資料庫實作，受試者以匿名代碼進入，作答寫入資料庫。模擬版：https://claude.ai/artifact/Mqm71z19C5c8jD3okxYJnD （6 題＋1 控制題，作答不送出）。
