成立的三件事

  • • A 段把 φ=0 的重建下限壓低 38–50%，270 個配對格全部改善保真
  • • 投影式約束把 |1−銳利度比| 由 0.2235 降到 0.0623（−72%）， woman_03 由 0.646 救到 0.960
  • • 非加性的抗淨化保留率 100–115%，加性在 blur 0.75 掉到 43–52%
  • • 階段一（UNet LoRA）每格 910 s → 0 s，且 stage1 的 1,594,368 個參數確認為死參數

被推翻的三個假設

  • • 「L1 可以靠攤平降低」→ 比例式損失確實把質量移出 M，編輯照樣成功
  • • 「抑制只存在於被取樣的 timestep」→ 施力點與其餘 t 差距僅 1–3 個百分點
  • • 「c_a 抑制是防禦的機制」→ PhotoGuard 未針對它最佳化卻達到 −11.1%， 而其 edit_lpips 高 3.3 倍
  • • 評測期抑制只剩 3–16%（訓練 log 是 77–87%），差距來自 scale_k 0.19–0.44

適用範圍與限制

  • • 移除七個淨化設定（未防禦編輯自身 ΔNIQE ≥ +1.0），已跑的格保留但不進曲線
  • • 評測期 attention 擷取的是攻擊 prompt 的 span，與訓練施力的 c_a 是兩件事
  • • 投影成本為罰項的 4 倍；apa_tj 的段 0 探測縮短為 3 候選 × 20 步
  • • 絕對水準仍是加性領先：blur 0.75 上 PhotoGuard 0.1646 對非加性 0.1109
