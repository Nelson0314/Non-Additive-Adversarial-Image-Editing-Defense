> **基準論文**：Lo, Yeo, Shuai, Cheng, *Distraction is All You Need:
> Memory-Efficient Image Immunization against Diffusion-Based Image Editing*,
> CVPR 2024。其約束（L∞ ≤ 0.06）、判準（Table 1 五指標）與 baseline
> （PhotoGuard 兩變體）已定為本專案的**必要對齊項**；本專案既有的語意判準、
> 感知劣化判準、LPIPS 綁定約束等一律保留為**改良項**。協定見
> `docs/specs/2026-08-03-lo-aligned-protocol.md`。

本檔是**主張**的索引，`docs/INDEX.md` 是**檔案**的索引，兩者互補：想知道
「某個結論現在還算不算數、出處在哪」查本檔；想知道「哪份文件現行、哪個 run
目錄屬於哪個實驗」查 INDEX。
