# 影像引導消除損失的擾動，過了淨化算子之後還剩什麼

同一份量測（`scripts/phase_drift_diagnosis.py`）套到
`runs/ip2p_ig_converge` 的四個工作點上。**不跑 GPU。** 定義、權重取法、
三種失效型態的區分方式與 crop 的座標問題，全部見
`runs/phase_drift_diagnosis/README.md`，此處不重複。

**八張，不是十張。** 取四個工作點都已訓練完的交集；主線那四個條件在
`runs/phase_drift_ig_ref/` 上用**同一組八張**重跑過，故兩份可以逐欄對照，
不可拿去和 `runs/phase_drift_diagnosis/`（十張）混讀。

## 一個必須先講的對照限制

四個 ig 工作點裝上去的相位偏移比主線大：`inst_mag` 是 0.536–0.609，
`ours_ph_q` 是 0.384、`ours_pg_q20` 是 0.529。像素域的殘差也更大
（L∞ 0.79–0.93 對 0.42）。**下面的存活率是各自對自己裝上去的量的比值，
不是等失真下的比較。**

點是 1.00–1.04（各級品質都是），也就是壓縮既沒有削掉也沒有額外疊上去。

| `ig_n30` | 0.959 | 0.287 | 0.768 | 0.114 | 0.547 |
| `ig_n35` | 0.958 | 0.272 | 0.756 | 0.109 | 0.530 |

| `dct_aj85` | 0.961 | 0.034 | 0.372 | 0.018 | 0.170 |

`rho` 全部 0.96 上下——高斯模糊是零相位濾波器，乘的是實正數 `H(ω) ≥ 0`，
原理上動不了相位。差別全在**載體剩多少**：σ1 下四個 ig 點留 0.27–0.34，
`ours_ph_q` 留 0.087，DCT-Shield 留 0.034。

## 裁切

`cos_vs_warped` 是 0.999，對原格點的 cos 是 0.000–0.005——與其餘所有條件
同一格。裁切對這四個點一樣是**把整份搬走**，不是消滅。這一格不隨損失改變。

## 這一頁不改變什麼

量的是擾動的存活，不是編輯位移，**沒有跑任何 GPU 上的編輯**。
`runs/ip2p_ig_converge/tables/net_gain.csv` 上模糊與裁切的淨增益仍然低於
地板。兩份數字並列即可，不在此處下任何「有沒有效」的結論。

## 重跑

```bash
python scripts/phase_drift_diagnosis.py --defended runs/ip2p_ig_converge \
    --images <八張的清單> --tags ig_d21 ig_d25 ig_n30 ig_n35 \
    --conds phase_gain phase_gain phase_gain phase_gain \
    --out runs/phase_drift_ig
python scripts/phase_drift_diagnosis.py --defended runs/ip2p_mainline \
    --images <同一份清單> --out runs/phase_drift_ig_ref
```
