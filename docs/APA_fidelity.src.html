1. 先講清楚 APA 是哪一種方法

APA 屬於 unrestricted adversarial example（UAE，不受限對抗樣本）這一類。它的問題設定在論文式 (1) 寫得很直接：

max fϕ′(x_adv) ≠ y,　s.t. x_adv is naturally similar to x

限制條件是「看起來自然地相似」，不是 Lp 球。論文緊接著說明理由：自然相似性沒辦法用 Lp 強制。也就是說——擾動幅度不受限，是這一類方法的定義本身，不是實作上的疏失。

做法是兩階段：先用規則式相似度回饋微調 LoRA 提升視覺一致性，再依替代分類器的回饋去更新 image latent 或 prompt embedding。防禦圖是由 diffusion 重新生成出來的，不是在原圖上加一層東西。

從這張表直接讀出來的三件事

一、差距很大。APA-SG／GC 的 LPIPS 是 0.23–0.25、SSIM 只有 0.67–0.69（原圖為 0 與 1.00）。作為對照，本專案量過 L∞ = 0.06 這個文獻標準幅度對應 LPIPS 0.582，而那一級人眼判讀是「一眼看出背景扭曲」；本專案早期的運作點是 LPIPS 0.05。APA 自報的失真是後者的 5 倍。

二、同一張表裡就有更保真的非加性方法。cAdv 在 LPIPS 0.15 時 SSIM 高達 0.98，代價是成功率只有 32.04%。所以「非加性 = 一定要動很大」並不成立，那是 APA 這個特定設計的取捨。

三、取捨曲線就在表裡。APA-GC-P 改成優化 prompt 而非 latent，LPIPS 由 0.23 降到 0.09、SSIM 由 0.69 升到 0.82，而成功率由 88.02 掉到 62.08。少三分之二的失真，換掉四分之一的效果——這一列對我們最有參考價值。

apa 與 pg_enc 的 LPIPS 幾乎相同（0.4391 對 0.4640，比值 0.95×），但 PSNR 相差 12.70 dB、L∞ 相差 28 倍。

L∞ 0.847 的意思是：有些像素從幾乎 0 被推到幾乎 1（car_00 那張是 1.000，即滿量程）。加性方法是 0.030。

這正是本專案後來把「同時綁 LPIPS 與其他量」寫進限制條件的原因——只綁 LPIPS 的話，最佳化會鑽進 LPIPS 的量測盲區。

逐張明細（LPIPS / PSNR / L∞）：apa 為 dog_00 0.4544 / 21.23 / 0.773、dog_01 0.4299 / 21.18 / 0.769、car_00 0.4331 / 16.81 / 1.000。出處 docs/archive/2026-07-26-v2-evidence/experiments/stage0/20260726_032310/fairness.csv。

5. 回答

差距大不大

非常大，而且是設計使然。APA 屬於不受限對抗樣本這一類，其問題設定明文放棄 Lp 限制，改用「看起來自然地相似」這個沒有量化定義的條件。論文自報 LPIPS 0.23–0.25、SSIM 0.67–0.69；本專案在匹配 LPIPS 的條件下實測 PSNR 19.74 dB、L∞ 0.847，逐圖看是物體被重畫、背景被抹除的程度。

對本專案有三個直接後果：

  1. APA 這一類不能當成「非加性可以做到低失真」的證據。它證明的是「放棄失真限制之後，非加性可以取得很高的攻擊成功率」。這兩件事不一樣。
  2. 但同一篇論文提供了反例。cAdv 在 SSIM 0.98 下仍有 32% 成功率；APA 自己的 prompt 版本在 LPIPS 0.09 下有 62% 成功率。非加性方法的失真量是可以壓的，只是要付效果。這條取捨曲線正是本專案該量而還沒量的東西。
  3. 「同一個 LPIPS、PSNR 差 12.7 dB、L∞ 差 28 倍」這個實測，是本專案量測方法那條線最早的證據之一，而且它來自非加性與加性的直接對照。目前這個現象已在四個不同的場合重現。

注意事項：論文的 LPIPS 與本專案的 LPIPS 可能使用不同的骨幹網路（AlexNet／VGG）與解析度，兩組數字不宜逐位比較，只宜看量級。另外本專案的 apa 是把原方法移植到抗編輯任務並重新校準過強度，其運作點與論文原設定不同。
