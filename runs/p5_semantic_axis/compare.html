編輯有沒有被擋下來

量測互相矛盾：net_lpips 說防禦有效（0.08–0.12）， SigLIP 說編輯對 prompt 的服從程度沒有下降（726 格中語意失敗 0 格）。 請按數字鍵（或點按鈕）在滑鼠所在的面板上原地切換。三種切換各問一件事： 1↔2 防禦本身看不看得出來；3↔4 編輯有沒有被擋下來（本頁的主要 問題）；4↔5 JPEG 把防禦洗掉多少。判斷第二項時請看編輯的內容有沒有 照 prompt 發生，而不是兩張圖長不長得一樣——兩次擴散輸出即使都達成了 prompt 也本來就會不同，那個差異會被 net_lpips 全部記成防禦效果。 右側為 4× 最近鄰放大，位置取原圖梯度能量最高處，各版本同一座標。
