# 索引

本目錄的每一筆資料都有一個編碼、可以單獨讀完、不依賴閱讀順序。
編碼只用來互相指認，**不代表先後或依賴**。

| 前綴 | 意思 | 檔案 |
|---|---|---|
| `EXP-` | 一個實驗批次：設定、規模、狀態、產物路徑 | `EXPERIMENTS.md` |
| `FND-` | 一個測得的事實：量、值、來源批次、證據路徑 | `FINDINGS.md` |
| `DEC-` | 一個裁決：決定了什麼、依據、影響範圍 | `DECISIONS.md` |
| `DEF-` | 一個缺陷：症狀、根因、處置、釘住它的測試 | `DEFECTS.md` |
| `MTH-` | 一個條件／方法：參數化、損失、隨機對照 | `METHODS.md` |
| `MET-` | 一個判準或指標：定義、方向、陷阱 | `METRICS.md` |

常設文件（不編碼，因為它們是操作與契約，不是資料）：

| 檔案 | 用途 |
|---|---|
| `SYNTHESIS.md` | **三組配置橫過來看一次**：哪些變因固定、哪些改動、各自確立或否定了什麼 |
| `RUNBOOK.md` | 上機執行：環境、五段流程、監察、失敗處理 |
| `ARCHITECTURE.md` | 程式結構與模組介面契約 |
| `DESIGN.md` | 實驗設計：軸、條件、主張階層 |
| `reference/` | 外部論文的原始碼逐字查證，逐篇自足 |
| `archive/` | 逐次執行的原始紀錄。**不是判準來源**，見下 |

## `archive/` 的地位

裡面是 2026-08-05 到 08-08 的逐日紀錄（`RESULTS_*`、`HANDOVER_*`、
`LOGIC_CHECK`、`PRIOR_FINDINGS`）。它們按時間寫、彼此交互引用、後面的節次
會推翻前面的——正是本次整理要消除的形態。

**判準與結論一律以 `FINDINGS.md`／`DECISIONS.md` 為準。** archive 保留原文
只為兩件事：追溯某個數字當初怎麼量的，以及查那些尚未被歸納的細節。
若某個結論在 archive 裡而不在 `FINDINGS.md`，表示它**還沒有被複核歸納**，
引用前要自行查證。

## `runs/` 的地位

`runs/` 是唯一的證據來源，容器會被刪除、實驗無法重跑。每個 `EXP-` 條目
都寫明它的產物路徑。改動 `.gitignore` 的 `runs/` 區塊時必須用
`git status --porcelain --ignored` 確認沒有結果檔被排除。
