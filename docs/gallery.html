WACV — 人眼比對頁總覽

最後整理 2026-08-03。本頁把散在 runs/ 各處的比對頁集中起來， 並記下每一頁當初決定了什麼。

本專案的規則是：指標之間出現矛盾時，把影像做成比對頁交人眼判斷。 τ_acut、τ_chroma 兩個門檻與 E29 的否定結果都是這樣定或確認的。 每一頁都對應一個當時無法只靠數字解決的判斷，故保留全部原圖不刪。 相關索引：結論總帳、檔案索引。

約束與門檻的定錨

頁面實驗決定了什麼
等 LPIPS 的模糊 vs 雜訊 E20 / P1 四臂校準到同一 LPIPS。使用者判讀為「0.4–0.6 px 的位移不明顯，模糊明顯較糟」， 據此淘汰 GMSD／NLPD／HaarPSI／VIF／SSIM／DISTS／PSNR（它們量的是位移）， 選出 local_acutance_dev 並定出 τ_acut = 0.04。
色度偏壓的階梯 E28 / P10 0.3 與 0.6 看不出來、1.0 要很仔細看才看得出來。 τ_chroma 取 0.8 而非 1.0，因為 1.0 屬於已確認看得見的一級。
把失真預算用滿之後長什麼樣 E27 同一個 LPIPS 下 site C 買到人眼可見的色調偏移，而 site P 沒有。 這是「匹配失真是假的」第三次成立，直接促成 E28 的第三道約束。
預算探針 E31 / P13 把既有解沿射線放大到各個 LPIPS 預算。連 i.i.d. 白高斯雜訊都在 LPIPS 0.20 超過 τ_acut、0.28 同時超過兩道，據此把兩道次要門檻改為逐預算。
劣化階梯 E31 / P11 待判讀。四個算子各四級施加在七個未防禦的編輯輸出上 （六張由本機補產生，見 runs/e31_sources/）， 要決定哪一級開始「這張圖已經不能用」，用以定出 ISR 感知劣化那一半的門檻。
κ 可見度階梯 Lo 對齊 / P17 把 PGD 擾動沿射線放大到 0.2×–1.0× 的 κ = 0.06。 κ 對應 LPIPS 0.58、PSNR 27.1 dB，是本專案跑過最大預算 （τ_lpips = 0.10）的 5.8 倍。使用者 2026-08-03 判讀：「最右邊那張算是 一眼看出背景扭曲 但不會到令人很不舒服，倒數第二張比較可以接受」 ——即 κ 是可見的，可接受的邊界落在 0.75κ（L∞ 0.045、LPIPS 0.53）。 對抗擾動文獻普遍把 L∞ 球描述為 imperceptible，該描述在此不成立。

攻擊設定

頁面實驗決定了什麼
攻擊強度掃描 E31 既有防禦圖在 SDEdit strength 0.2–0.5 下被編輯，三臂共用同一個 ε。 這是遷移不是匹配設定——防禦圖在 0.5 下訓練——故為下界。 用來量出「E29 的否定結果有多少是 strength 造成的」。

攻擊端與判準

頁面實驗決定了什麼
guidance scale 決定編輯有沒有發生 E26 / P7 w=1 與 w=7.5 的未防禦編輯對照。w=1 下 SD v1.4 幾乎不服從 prompt—— 本專案 E2–E23 全部跑在 w=1，即在防禦一個不存在的攻擊。這是那批數字失效的根因。
編輯有沒有被擋下來 E25 / P5 使用者判讀後指出比「防禦無效」更根本的事：連未防禦的原圖被編輯都沒有成功。 這條線索直接導向 E26 的根因。
