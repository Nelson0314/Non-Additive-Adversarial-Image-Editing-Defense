# 設計：影像引導消除損失，與色散變形探針

**這是設計文件，不是結果。** 判準寫在各節的「事前判準」，在看到數字之前定案。
數值產出一律落在 `runs/` 底下，結論先進 `docs/PENDING.md`，不直接改
`RESULTS.md` 或 `DECISIONS.md`。

## 零、為什麼是這兩件事

專案自己的量測給出三個不變量：

| 編號 | 事實 | 證據 |
|---|---|---|
| I1 | 擋下率幾乎完全由**位移**決定，與參數化無關 | `RESULTS.md` 一節 |
| I2 | 「每單位 LPIPS 換到多少位移」跨四個方法的變異係數 0.108（1.27 倍） | `distortion_axis_analysis` |
| I3 | 位移在 0.70 飽和，52 個工作點的前十名擠在 1.2% 區間內 | `PENDING.md` 〇節 |

I1 與 I2 合起來說的是：**在「損失只讀 VAE 編碼器」這個威脅面上，換參數化不是
槓桿。** 這已由四組互相獨立的實驗量到——AdvDrop 移植打平、DCT 學習平面 0.93、
純加性下限打平、只有隨機相位輸。

因此本設計動的不是參數化，是**損失讀哪裡**（第一節），並用一支不需最佳化的
探針判定「位移場家族還有沒有東西」（第二節）。

## 一、影像引導消除損失

### 1.1 機制

InstructPix2Pix 的取樣式（`diffusers` 的
`pipeline_stable_diffusion_instruct_pix2pix.py:444–447`，已逐行核對）：

```
eps_tilde = eps(z_t, 0, null)
          + s_T * [ eps(z_t, c_I, c_T) - eps(z_t, c_I, null) ]
          + s_I * [ eps(z_t, c_I, null) - eps(z_t, 0,   null) ]
```

三份批次的順序是 `[text, image, uncond]`（同檔 `:443`），文字嵌入是
`[prompt, negative, negative]`，影像 latent 是 `[img, img, zeros]`（同檔 `:898`
的 `uncond_image_latents = torch.zeros_like(image_latents)`）。

**兩件由此確定的事：**

1. 影像無條件分支用的就是**零影像 latent**。
2. 影像分支與無條件分支**共用同一組文字嵌入**（空字串），故兩者的差只來自
   影像條件。

現行的 `latent_norm`（把 `‖E(x')‖₂` 壓向零）於是可以精確地描述：**它把影像
條件逐元素推向 UNet 的無條件分支**，影像引導項因此消失，IP2P 退化成純文生圖
——這就是 `RESULTS.md` 記的「輸出即 prompt 被畫出來」。它一直是這個機制的
**逐點版本**。

本節提出**函數版本**：不要求 `E(x') = 0`，只要求 UNet 對兩者的反應相同。

```
L_ig(x') = E_{t, eps} || eps(z_t, E_img(x'), null) - eps(z_t, 0, null) ||^2      （最小化）
```

`{x' : eps(z_t, E_img(x'), null) = eps(z_t, 0, null)}` 是 UNet 的一個等位集，
**比單點大得多**，故在同一個失真預算下更容易落進去。這是可預先登記的效率主張。

### 1.2 三個附帶性質

- **起點梯度不為零。** 乾淨影像的影像引導很強，`L_ig(x) >> 0`，避開 FND-053
  記的「untargeted 損失在起點處梯度為零」那種無症狀失效。
- **它不是語意 reward。** 已否決的三個 reward（分類器／latent／CLIP）都在
  SDEdit 線上、量的是語意對齊；**SDEdit 沒有影像引導分支**，那三次否決不涵蓋
  本項。本項量的是條件通道的代數性質，不涉及語意。
- **與參數化正交。** 只換損失，不動 `texture_rephase.py`，主線兩個設定都能掛。

### 1.3 兩個必須明寫、不得猜預設的參數

**`z_t` 怎麼抽。** IP2P 由純噪聲起步，中間步的 `z_t` 分布依賴條件，無法解析。
兩個候選都要能跑，由旗鈕指定，**不給不跑**（`--loss image_guidance` 時必填）：

| 值 | 構造 | 依據 |
|---|---|---|
| `diffuse_src` | `z_t = sqrt(abar_t)·E(x_clean) + sqrt(1-abar_t)·eps` | Anti-DreamBooth 一系的慣例；`fixedpoint_loss` 已用同式 |
| `noise` | `z_t = eps`（純噪聲），對應 IP2P 實際的起點 | IP2P 由純噪聲起步 |

`x_clean` 是**原圖**不是防禦圖：`z_t` 是取樣軌跡上的點，用防禦圖會讓軌跡隨
最佳化漂移，量到的不是同一件事。

**時間步範圍** `--ig-t-min` / `--ig-t-max`：預設涵蓋整個排程（1–1000），因為
影像條件在整條軌跡上都作用。兩者逐列寫進 CSV。

## 二、色散變形探針

### 2.1 位移場為什麼死，以及「單值」才是病灶

`ip2p_warp/DIAGNOSIS.md` 已證預算夠、最佳化沒走；`ip2p_warp_hard` 補上兩個
端點（grid 16 到不了失真帶、grid 64 到得了但付 1.92 倍失真只換 65% 位移）。

本設計補的是歸因：**單值位移場是微分同胚，它把一張自然影像映成另一張自然
影像。** 編碼器與 UNet 面對的仍是一張合理的照片，編輯照樣成功。真正動得到
編碼器的只有場的**粗糙度**（重取樣走樣），而那與加性高頻雜訊同族。

這不是推論，`matched_geometry.csv` 已直接量到：`warp_roundtrip`（先 f 再 −f，
幾何完全抵銷、只留內插 artifact）與 `warp_rand` 在等失真上差 **8.6%**。
**幾何本身不值錢，走樣才值錢。**

推論：問題出在「單值」，不在「位移」。單值場強迫**所有空間頻率一起搬**，這
正是它留在自然影像流形上的原因。

### 2.2 色散變形

讓每個八度頻帶各自有自己的位移場。在加窗區塊的複數頻譜上，「把第 k 帶平移
`u_k` 像素」就是「該帶的相位加 `2π·<f, u_k>`」——這是 Wadhwa 等人的相位式
運動處理所用的同一條恆等式（相位式運動處理，SIGGRAPH 2013）。

```
theta_b[omega] = 2*pi * < f_omega , u_{k(omega)}(b) >
```

| K（獨立位移的頻帶數） | 是什麼 | 已知結果 |
|---|---|---|
| K = 1 | 古典位移場 | 已測，失敗（**內建對照組**） |
| K = 2–8 | 色散變形 | 未測 |
| K = 每個頻格獨立 | 現行紋理重相位 | 現行工作點 |

K 是一個「色散度」旋鈕，把三個方法串成一條線；參數量由 59 萬降到 K × 視窗數 × 2。

### 2.3 探針：不做最佳化，只做前向

量的是**每單位失真換到多少 latent 位移**，即 `‖E(x') − E(x)‖ / DISTS`，沿用
`encoder_frequency_response` 的量測骨架。條件：

| 條件 | 構造 |
|---|---|
| `disp_k1` … `disp_k8` | K 個八度帶各一個隨機平滑位移場 |
| `disp_kfull` | 每個頻格獨立的隨機相位（＝現行家族的隨機對照） |
| `warp_smooth` | 像素域的單值平滑位移場（古典位移場） |
| `warp_fold` | 像素域的單值位移場，**允許折疊**（Jacobian 行列式可為負） |

`warp_fold` 那一格同時回答「非微分同胚」：折疊比例逐列記下。

**成本**：只有 VAE 前向，不做 PGD、不跑編輯。十張 × 四個強度 × 十個條件，
量級是幾分鐘到十幾分鐘，不需要佔用整張卡。

### 2.4 事前判準

| 編號 | 內容 | 結論 |
|---|---|---|
| D1 | `disp_k4` 的效率 ≥ `disp_kfull` 的 **90%** | 值得做成完整參數化：參數量少兩個數量級而效率不掉 |
| D2 | `disp_k4` ≤ `disp_kfull` 的 **50%** | 色散假說成立且**位移場族確定沒救**，寫成診斷結論 |
| D3 | `warp_fold` 的效率 ≥ `warp_smooth` 的 **1.5 倍** | 「非微分同胚」是一個獨立的軸，值得再看 |
| D4 | 效率隨 K 單調 | 不單調則「色散度」不是一個好的描述量，歸因要重寫 |

D1 與 D2 之間（50%–90%）是灰帶，記為「不決定」，不強行解讀。
