一、一句話現況
--------------------------------------------------------------------
正式方向是「紋理重相位」：把影像切成重疊區塊做加窗 FFT，只轉相位、
幅度譜逐位保留，再重疊相加回去。三個主張的現況：

  並列  防禦效果不輸加性        成立。人眼門檻上勝加性 1.55x、逐圖 22/24。
                                 換第二個編輯 prompt 後是 1.74x、17/18。
                                 但與原生預算的 photoguard_c 打平（0.99x）。

  主    非加性更抗淨化          2026-08-16 起可判定。補上空白地板控制組後，
                                 扣掉地板的淨增益上勝加性 9/9、勝 photoguard_c
                                 8/9、勝 dia_r 9/9、勝隨機相位 9/9；
                                 輸 mist 0/9，而 mist 的失真是 3.3 倍。

  三    保真受控                 全部指標照報不挑選。

已知最大的方法學弱點：固定的相位半徑 theta=1.30 讓失真逐圖漂 16.4 dB，
而該漂移與「相位在哪張圖上贏」的相關是 r=+0.776（FND-038）。

三、研究目標與主張
--------------------------------------------------------------------
白盒（攻擊方用 stock SD）、外掛模組形態下，找出非加性方法，在匹配人眼可辨
失真下勝過加性基準。威脅模型只有 img2img（SDEdit strength 0.55）一種。

不再追求語意抵抗。CLIP-T 掉幅照報但不作為成敗判準（FND-024/029/030，
且 arXiv:2506.04394 獨立測到同一現象）。

判準以人眼為主、數值指標為輔。報告的每一格都必須有影像可看；
指標與人眼矛盾時以人眼為準並記錄。


四、三個條件，沒有第四個
--------------------------------------------------------------------
弱 baseline    完全原生 APA，只把 reward 換成 targeted output（DEC-023）
強 baseline    photoguard_c / mist / dia_r 三個已發表的加性方法
紋理重相位     本專案的方法

add（加性 delta 走同一個 encoder-targeted 損失）與 phase_rand（同失真隨機
相位，即 RPN）是紋理重相位消融的內部對照，不是獨立條件。

待加入：DCT-Shield（ICCV 2025, arXiv:2504.17894）。它是 DCT 係數上的加性
方法，主張與本方法逐條重疊，且同時是「保不保留幅度」的對照組。


五、方法是什麼（一段）
--------------------------------------------------------------------
    x_def = OLA( irfft2( rfft2(w*P_b) * exp(i*g_b*m_w*theta_b) )*w ) / OLA(w^2)

把影像切成 32x32 重疊區塊、加 Hann 窗做 FFT，只把相位轉一個角度，幅度譜
逐位保留，再重疊相加回去。theta 是唯一的參數；紋理度閘 g_b（結構張量
coherence）與徑向頻率閘 m_w 由原圖算一次即固定。theta=0 時輸出等於原圖
（float64 誤差 5.6e-16）。

定案參數：block=32、r_min=0.12、紋理閘分位數 0.5。
註：r_min 的定案值不是效率上的操作點，見 FND-042。

文獻依據是 Random Phase Noise（Galerne et al., IEEE TIP 2011）。
但相位擾動加上幅度保留這個構造有前例（arXiv:2602.06577、JEI 2025），
新穎性主張已收窄，見 FND-041 與 docs/reference/SURVEY_2026-08-16.md。


六、已經被否證的方向（不要重試）
--------------------------------------------------------------------
「把編輯推遠」做得到，「讓編輯不服從 prompt」做不到。

  * 提高失真預算、放大既有方向、換 reward（注意力抑制/分類器 CE/latent/CLIP）、
    換約束、換更新規則、換階段一 —— 全部測過（FND-023..030）
  * cross-attention 目標注入、分階段注入、amortized generator（GAN）、
    對淨化的 min-max、顏色通道 —— 2026-08-13 全部否決
  * 位移場（flow）—— 與同失真隨機無法區分（FND-004）
  * 相位參數化搬進 APA 的 latent —— 無收益（FND-032）。機制：要利用的落差是
    「人眼與 DISTS 對紋理重取樣寬容、VAE encoder 對相位敏感」，而 latent
    擾動已在 encoder 之後。優勢是像素空間特有的
  * block=16 與 r_min=0.05 —— 兩者都在造能量而非重排相位（FND-042）


七、動手前必須知道的坑
--------------------------------------------------------------------
量測與方法
  * 沒有任何單一指標可以當兩個家族的共用預算軸。兩條人眼門檻（相位 1.30 /
    加性 1.2/255）在十六項指標上沒有一項落在同一個值。FND-035
  * 但那是跨家族的結論。它不能延伸成「同一家族內部也可以讓預算漂 16 dB」。
    FND-038
  * 比值一律報「平均比平均」與逐圖勝場，不報逐圖比值的平均——後者會被
    分母支配。retention 的 r=-0.83（FND-037）與主結果的 r=-0.900（FND-039）
    是同一個缺陷
  * 抗淨化必須扣掉空白地板。地板佔淨化後位移量的 47%-92%；crop_resize（92%）
    與 noise 0.05（90%）兩列實質上不具鑑別力。FND-043
  * 未防禦的編輯必須真的成功，否則抗編輯那一欄的分母不成立。DEC-022
  * latent 半徑不是保真約束。FND-028
  * 階段二的 CFG 必須是 1.0、反演必須走淺噪聲帶（50 格排程只執行前 11 格）

工程（完整版見 docs/RUNBOOK.md）
  * 本 repo 用 sparse-checkout（cone mode）。新增頂層目錄或新的 runs/
    子目錄前要先 git sparse-checkout add <路徑>
  * 同一個批次目錄只允許一個寫入者——不是鎖，是覆寫語意
  * pkill -f 會殺到自己：ssh 送過去的命令列本身含有那個字串
  * 遠端 repo 是 worktree，rebase 中斷會留下 detached HEAD
  * dia_r 與 mist 必須開 use_ckpt 與 vae_ckpt，否則 OOM
  * photoguard_c 約 33 秒/步 x 200 步 = 1.9 小時/圖，佔一批實驗 94% 的機時
  * runs/ 是唯一的證據來源，全部入版控
