## §1 目標與完成判準

### 1.1 研究問題

在**單一 Stable Diffusion 模型**上外掛一個可開關的殘差模塊，使得：

1. 模塊**開啟**時，由原圖 `x` 生成防禦圖 `x_def`，且 `x_def` 與 `x` 在人眼尺度上接近；
2. 攻擊者以**同一個** SD 模型（模塊**關閉**）對 `x_def` 進行編輯時，編輯結果明顯偏離對原圖編輯的結果；
3. 上述效果在防禦圖經過淨化後仍然存在。

### 1.2 本規格的核心設計主張

殘差 `Δ = x_def − x` 應被**架構層級地**約束在秩為 `r` 的子空間內。此主張的依據見 §5.1（LRDM 的低秩殘差假設）與 §5.2（v2 的淨化耐受性實證）。

### 1.3 完成判準

- **E1 三項正確性測試全數通過**（§7.2），否則後續任何數字都不可信。
- **E2 產出 site × rank 的防禦—保真前緣**，且能明確回答：低秩約束是否改善此前緣。
- **E3 產出淨化強度掃描曲線**，且能明確回答：耐淨化性來自「低秩」還是「非加性」（此問題由 P 與 L 兩個 site 的對比切割，見 §6.2）。

## §4 架構

### 4.1 外積參數化的低秩殘差

殘差不以「先產生再投影」（truncated SVD）的方式取得，而是**直接參數化為秩恰為 `r` 的形式**：

```
Δ[c] = Σ_{i=1}^{r}  U[c,i,:] ⊗ V[c,i,:]ᵀ
```

`c` 為通道索引，`U[c,i,:] ∈ R^H`，`V[c,i,:] ∈ R^W`，`⊗` 為外積。以 einsum 表示：

```python
delta = torch.einsum('cri,crj->cij', U, V)     # (C, H, W)
```

**採用此參數化而非 truncated SVD 的四項理由**：

1. 秩在代數上精確等於 `r`（至多為 `r`），不需事後驗證，也不依賴懲罰項的權重調參。
2. 訓練迴圈內不需執行 SVD。SVD 在奇異值簡併時反向傳播數值不穩定，且成本高。
3. 參數量小。site L、`k_inv=10`、`R_m=32` 時為 `2 × 10 × 4 × 32 × 64 = 163,840`；`r=8` 時為 `40,960`。單圖優化下不致過擬合。
4. rank 掃描退化為更改一個整數，ablation 設計乾淨。

**初始化**：`U ~ N(0, 0.02)`，`V = 0`。使得初始 `Δ = 0`（即 `x_def = x`），同時 `∂L/∂V ≠ 0`，梯度可正常流動。此慣例沿用 LoRA 的 A 高斯／B 零初始化（v2 程式碼中 `init_lora_weights="gaussian"`，出自 APA 官方 `visual_alignment.py`）。

### 4.2 秩排程（Adaptive Rank Selection）

參數 `U`、`V` 一律配置至 `R_m`，第 `j` 步僅使用前 `r(t_j)` 個分量（其餘遮罩為零）。此配置方式對應 LRDM Fig.4 的「scaled to maximum rank `R_m`」。

排程函數直接採用 LRDM 式 (15)–(19)：

| 代號 | 名稱 | 式子 |
|---|---|---|
| `const` | 固定 | `r(t) = r` |
| `LI` | 線性遞增 | `r(t) = ⌈(t/T) · R_m⌉` |
| `LD` | 線性遞減 | `r(t) = ⌈(1 − t/T) · R_m⌉` |
| `PI` | 多項式遞增 | `r(t) = ⌈(1 − envelope(t/T; p)) · R_m⌉` |
| `PD` | 多項式遞減 | `r(t) = ⌈envelope(t/T; p) · R_m⌉` |

其中
```
envelope(d; p) = 1 + a·d^p + b·d^(p+1) + c·d^(p+2)
a = −(p+1)(p+2)/2,   b = p(p+2),   c = −p(p+1)/2
```

`const` 為本規格新增（LRDM 未列此項），作為排程 ablation 的基準線。

### 4.3 三個注入位置（injection site）

#### site P — 像素空間

```
x_def = clamp(x + Δ, 0, 1)
Δ = einsum('cri,crj->cij', U, V)      U,V: (3, R_m, 512)
```

參數量：`2 × 3 × R_m × 512`。**此 site 為加性方法**，且像素空間殘差的秩**精確等於** `r`。

#### site L — latent 空間，去噪逐步注入

防禦生成流程：

```
x → (2x−1) → VAE.encode                          → z_0
  → DDIM inversion，k_inv 步，模塊關閉，prompt p_def → z_{k_inv}    【無梯度，每圖快取】
  → 去噪 k_inv → 0，模塊開啟                        → z_0'          【梯度流向 φ】
  → VAE.decode → (·+1)/2 → clamp                  → x_def
```

第 `j` 步的注入方式為修改預測噪聲：

```
ε̂'_j = ε̂_j + Δ_j
Δ_j = einsum('cri,crj->cij', U[j], V[j])      U,V: (k_inv, 4, R_m, 64)
```

選擇修改 `ε̂` 而非直接修改 `z` 的理由：`ε̂` 同時進入 `pred_x0` 與下一步的 `z`，其影響會沿軌跡傳播；此與 APA 的 step-level 注入形式一致（v2 程式碼中 `eps − √(1−ᾱ_t)·sign(m_st)`）。

**重要且必須在報告中明說的性質**：site L 的秩約束**精確作用於注入的 latent 殘差**，但最終像素空間殘差 `Δ = x_def − x` 的秩是**湧現的**，因為它還經過 DDIM 更新與 VAE 解碼兩道非線性變換。實際秩必須實測（§8.2 的奇異值譜診斷圖），不得假設。

site P 與 site L 在此性質上的差異，本身即為一項可報告的發現。

**效率設計**：inversion 段模塊關閉，故 `z_{k_inv}` 不依賴 `φ`，可於優化開始前計算一次並快取，省去每個 iteration 一條 `k_inv` 步的 UNet 前向。

#### site W — 權重空間

UNet attention 投影（`to_q`／`to_k`／`to_v`／`to_out.0`）之 LoRA，秩為 `r_lora`。UNet 基底權重凍結。

此 site **不受 §4.1 的低秩殘差約束**，其低秩性在權重空間而非訊號空間。列入實驗的目的是回答「權重空間殘差與訊號空間殘差孰優」，而非參與秩軸的比較。**結果呈現時必須與 P、L 分開列表**，不得將 `r_lora` 與 `r` 畫在同一條座標軸上。

### 4.4 模組邊界

| 檔案 | 職責 | 不得依賴 |
|---|---|---|
| `src/residual/base.py` | `ResidualModule` 介面：`enable()`／`disable()`／`parameters()`／`reset()`／`rank_at(t)` | 具體 site |
| `src/residual/lowrank.py` | 外積參數化張量與秩排程（P、L 共用） | SD 模型 |
| `src/residual/site_pixel.py` | site P | — |
| `src/residual/site_latent.py` | site L | sd_wrapper |
| `src/residual/site_weight.py` | site W | peft |

## §5 損失函數

```
L(φ) = λ_def · L_def + λ_fid · L_fid
```

無低秩懲罰項。秩為架構硬約束（§4.1），不以懲罰項近似。

### 5.1 防禦項

```
L_def = E_{P∼𝒫, ε∼N(0,I)} [ max(0, m − d( E(P(x_def), ε), E(x, ε) )) ]
```

- **hinge 形式**：偏移超過 margin `m` 後不再施力。無界最大化會發散，此為必要設計。
- **`𝒫` 包含恆等算子**（即「不淨化」）與各淨化方法。將耐淨化性寫入訓練目標，而非事後量測。
- **兩分支噪聲 `ε` 必須相同**。否則量到的偏移主要來自噪聲差異而非防禦效果。
- `E(x, ε)` 對 `φ` 為常數，每 `(圖, prompt, seed)` 僅計算一次並快取。
- `d(·,·)` 之選擇見 §8.1。

不可微的淨化（JPEG 量化、GrIDPure）於訓練時以可微代理替代，**評測時一律使用真實實作**。此差距須在報告中明列，不得省略。

### 5.2 保真項

```
L_fid = LPIPS(x_def, x)
      + α · (1 − SSIM(x_def, x))
      + β · max(0, ‖Δ‖_∞ − τ)
      + γ · max(0, PSNR_floor − PSNR(x_def, x))
```

後兩項為 hinge 形式的硬地板。其存在理由為 v2 的直接實測結果：apa 方法的 LPIPS 與 pg_enc 幾乎相同，但 PSNR 相差 12.7 dB、L∞ 相差 28 倍。若保真項僅使用 LPIPS，優化過程會利用 LPIPS 的量測盲區，產生 LPIPS 數值良好但人眼可見的失真。`τ` 與 `PSNR_floor` 兩道地板封閉此路徑。

### 5.3 梯度路徑

`φ` 為唯一可訓練參數，SD 全部凍結。反向路徑：

```
L_def → d(y_def, y_orig) → E 的 n_edit 步去噪鏈 → VAE.decode
      → 淨化 P → x_def → VAE.decode → G 的 k_inv 步去噪鏈 → φ
```

凍結參數不阻斷梯度。`requires_grad=False` 僅表示不累積該參數的 `.grad`，鏈式法則對輸入的偏導照常計算，梯度可穿過兩條 UNet 鏈抵達 `φ`。

兩條 UNet 鏈串接為本設計的主要記憶體風險，由 E0（§7.1）實測決定可行參數範圍。

### 6.2 未取自 LRDM

以下為 LRDM 的內容，本規格**不採用**，避免誤植引用：

- 式 (1)–(5) 的 RDDM 前向／反向過程與雙損失項。本規格不訓練擴散模型本身。
- 式 (7)–(12) 的 VLB 緊化證明。該證明成立於「訓練擴散模型以最大化 VLB」的框架；本規格的目標函數為對抗性 loss，非 VLB，故該定理不可直接引用為本方法的理論保證。**此點在論文中須明確聲明，不得暗示本方法繼承了該理論保證。**
- truncated SVD 取得 `Q_k` 的作法（LRDM Fig.2）。本規格改用外積參數化，理由見 §4.1。
- 全部復原任務基準與資料集（Raindrop、Rain1400、GoPro、RealBlur、ISTD、CelebA-HQ）。

| 設計 | 出處 |

### 6.4 本專案原創

- 外積參數化使秩成為架構硬約束而非懲罰項（§4.1）。
- 三注入位置（P／L／W）× 秩的兩軸因子設計，以 P 與 L 的對比切割「秩」與「非加性」兩個混淆因素（§6 下方、§7 E2–E3）。
- 多項硬地板保真項，其設計動機來自 v2 對單一 LPIPS 量測盲區的實測（§5.2）。
- 將淨化期望值寫入訓練目標，使耐淨化性成為優化目標而非事後觀察（§5.1）。

## §7 實驗

### 7.1 E0 — 成本實測

**目的**：取得真實記憶體與時間數字，作為後續所有參數選擇的依據。**此為動手的第一件事，先於任何功能實作。**

- 環境：TWCC V100-SXM2-32GB，CompVis/stable-diffusion-v1-4，512×512 單圖。
- 掃描：`(k_inv, n_edit) ∈ {5, 10, 20}²`，site L（最深的計算圖）。
- 記錄：peak GPU memory、單次 iteration 秒數、是否 OOM。
- 開／關 `torch.utils.checkpoint` 各測一次。

**產出**：`e0_cost.csv` + 熱圖。**判準**：至少一組 `(k_inv, n_edit)` 可在 32 GB 內完成反向傳播。若全數 OOM，降低 latent 解析度或改用 site P 先行驗證流程。

EOT 取樣數（§5.1 的 `𝒫` 與 `ε` 期望值）由此結果決定，不預先設定。

### 7.2 E1 — 正確性測試

以 pytest 實作，設計為模型無關（本機 tiny-SD 可跑），以便在 TWCC 上出現異常時能區分邏輯錯誤與規模問題。

| 測試 | 內容 | 判準 |
|---|---|---|
| T1-P | site P：`φ = 0` 時 `x_def` 與 `x` | 逐元素相等，且 `y_def` 與 `y_orig` 逐元素相等 |
| T1-L | site L：模塊停用時的去噪結果 | 與「無模塊」逐元素相等；反向檢查 `V` 非零時結果必須改變 |
| T2 | 對產生的 `Δ` 做 SVD，計算數值秩 | site P：等於設定的 `r`。site L：latent 注入殘差等於 `r`，像素殘差**記錄實測值、不下數值斷言** |
| T3 | 兩分支的 `ε` 張量 | 逐元素相等；反向檢查不同 `ε` 必須給出不同編輯結果 |

**全數通過才進入 E2。**

#### 修訂紀錄：T1 敘述更正（2026-07-28，實作階段）

**原文（v1 §7.2 T1）**：「`φ = 0` 時 `d(y_def, y_orig)` ≈ 0（數值容差內）」

**問題**：該敘述僅對 site P 成立。site P 的 `Δ = 0` 使 `x_def = x` 恆等，故 `y_def = y_orig`。但 site L 即使殘差為零，`x_def` 仍是「VAE 編碼 → DDIM inversion → 去噪 → VAE 解碼」來回一趟的重建，本身即帶重建誤差，`y_def` 不可能等於 `y_orig`。依原文撰寫的測試會恆為失敗，或被迫放寬容差至失去鑑別力。

**更正後**：site L 的正確不變量是「模塊停用時，其存在不得改變任何計算結果」，即 `denoise(eps_hook=module.eps_hook())` 必須與 `denoise(eps_hook=None)` 逐元素相等。site P 的恆等檢查保留為 T1-P。

**對應實作**：`tests/test_pipeline.py` 之 `test_T1_P_殘差為零時防禦圖與原圖恆等`、`test_T1_L_停用模塊不改變去噪結果`、`test_T1_L_初始參數下殘差為零且不改變結果`、`test_T1_L_參數非零時結果必須改變`。

#### 實作階段發現的兩項數值行為

以下兩點在 v1 規格中未載明，實測後補記，供後續分析與報告引用：

1. **秩的數值判準必須是相對的。** `einsum` 於 float32 計算，被截斷分量的殘留奇異值正比於 `σ₁` 的量級（`σ₁ ≈ 1e-3` 時殘留約 `1e-10`）。以絕對閾值判定秩會隨 `init_std` 改變而誤判。實作一律使用 `σ_{r+1} / σ₁ < 1e-6` 與 `matrix_rank(..., rtol=1e-6)`。

2. **site P 的像素殘差秩不精確等於 `r`，`clamp` 會破壞它。** 詳見下方獨立條目。

3. **排程方向在 `t` 與去噪步序上相反，且 `t = 0` 永遠不被評估。** 排程名稱的遞增／遞減是對 LRDM 的 timestep `t` 而言（`t=0` 為乾淨端）；去噪走訪 `t` 遞減，故 LD 沿去噪步序為**遞增**、LI 為**遞減**。此外去噪走訪的是 `ts[steps..1]`，最後一步以 `ts[1]` 的 ε 更新至 `ts[0]`，因此 `t = 0` 端點的排程值永遠不會被使用。比較排程行為時必須指明座標是 `t` 還是 step index。

#### 修訂紀錄：site P 像素秩敘述更正（2026-07-29，實作階段）

**原文（v1 §4.3 site P、§6 因果切割）**：「site P 為加性方法，且像素空間殘差的秩**精確等於** `r`（無任何後續非線性變換）」。

**問題**：`x_def = clamp(x + Δ, 0, 1)` 中的 `clamp` **就是**非線性變換。原文「無任何後續非線性變換」的前提不成立。原圖中已飽和（值為 0 或 1）的像素，加上 `Δ` 之後會被截斷，在該處產生一個不屬於 `Δ` 列空間的稀疏擾動。

**實測**（`data/dayn_testset/car/car_00.png`、128×128、`r = 2`、`init_std = 0.02`、原圖飽和像素佔 0.97%）：

| 量測對象 | `effective_rank`（`σ_i/σ₁ ≥ 1e-6`） | `energy_rank` 99% |
|---|---|---|
| `Δ`（clamp 前） | `[2, 2, 2]` | `[2, 2, 2]` |
| `x_def − x`（clamp 後） | `[84, 87, 83]` | `[3, 2, 2]` |

被 `clamp` 改動者為 225 / 49 152 個元素（0.46%）。

**更正後**：`Δ` 的秩精確等於 `r` 由外積參數化保證，此點不變；但**像素殘差 `x_def − x` 的秩不等於 `r`**。低秩結構在**能量意義**下成立（99% 能量仍落在秩 2~3），在**精確秩**意義下不成立。

**對報告的要求**：`energy_rank` 為主要量度，`effective_rank` 併列，兩者都須報出。不得宣稱 site P 的像素殘差秩精確等於 `r`。

**對 §7.4 因果切割的影響**：不影響。該切割依賴的是「P 為低秩**加性**、L 為低秩**非加性**」的對比，P 在能量意義下仍為低秩，加性性質也未改變。但論文敘述須改用能量意義的低秩，否則可被審稿人以此處的數字直接反駁。

**對應實作**：`ResidualModule.raw_residual()`（`src/residual/base.py`）提供 clamp 前的殘差，`PixelResidual.clamped_fraction()` 提供被截斷的元素比例；`scripts/run_defense.py` 對兩者分別做譜分析並各自入表。

#### 修訂紀錄：L∞ hinge 的對象與 `psnr_floor` 改由實測決定（2026-07-29，實作階段）

**原文（v1 §5.2）**：

```
L_fid = LPIPS(x_def, x) + α·(1 − SSIM(x_def, x))
      + β·max(0, ‖Δ‖_∞ − τ) + γ·max(0, PSNR_floor − PSNR(x_def, x))
```
其中 `Δ = x_def − x`，`τ = 0.06`、`PSNR_floor = 30 dB`。

**問題**：兩道地板都設在 site L **不可能達到**的位置。site L 的 `x_def` 在 `φ = 0` 時已是「VAE 編碼 → DDIM inversion → 去噪 → VAE 解碼」的重建，該重建誤差與防禦強度無關且 `φ` 無法消除。

E0c 實測（n = 6，`t_max = 500`、`k_inv = 20`）：

| 量 | VAE 單獨來回 | 完整來回 | 原設定門檻 |
|---|---|---|---|
| PSNR | 27.51 dB | 26.56 dB | `PSNR_floor = 30` ← 不可達 |
| L∞ | 0.707 | — | `τ = 0.06` ← 不可達 |

pilot 實測 `φ = 0` 時 site L 的 `L∞ = 1.0000`，代入原式得 `β·(1.0 − 0.06) = 94`。防禦項的上限僅 `margin = 0.5`，故 `L_fid` 完全主導總損失，且該主導項是一個 `φ` 改善不了的常數，防禦無法發展。

**更正後**：

1. **L∞ hinge 的對象改為 `x_def − x_base`**，其中 `x_base = G(x; φ=0)`。site P 的 `x_base = x`（故此改動對 site P 無影響）；site L 的 `x_base` 為其重建。兩個 site 量到的都是「防禦本身加了多少」，彼此可比。
2. **`PSNR_floor` 由 30 dB 改為 26 dB**，略低於實測地板 26.56 dB，使 hinge 可以釋放。

**未更動**：LPIPS、SSIM、PSNR 三項的對象仍為 `(x_def, x)`，總體保真度仍受把關。`L∞` 對原圖的總值以 `fid_linf_total` 逐步記錄並在報告中列出，不因改了優化對象就不報。

**限制（須在論文中載明）**：site L 的保真上限受其重建誤差限制，與 site P 的起點（逐元素相等）本質不同。E2 前緣圖的橫軸為實測保真度，兩個 site 的起點差異在圖上直接可見，不以損失函數的設計掩蓋。

**對應實作**：`DefenseObjective.fidelity_term(x_def, x, x_base)`、`optimize()` 中停用模塊取得 `x_base` 並快取（對 `φ` 為常數，只算一次）。

### 7.4 E3 — 淨化耐受

取 E2 中位於前緣上的格點，加上 site W 最佳格點，掃描淨化強度。

**此階段回答的核心因果問題**：P 為低秩**加性**殘差，L 為低秩**非加性**殘差。v2 已實證一般加性擾動（高頻像素訊號）會被淨化剝離。

- 若 P 亦耐淨化 → 耐淨化性的機制是**秩結構**。
- 若 P 不耐而 L 耐 → 機制是**非加性**。
- 若兩者皆耐且程度相近 → 兩機制不可分辨，須設計進一步實驗。

三種結果都是可發表的發現，此設計不存在「實驗失敗」的分支。

**檢驗對象**：LRDM Fig.6「中等秩優於全秩」之主張在防禦任務上是否成立。

### 7.6 E5 — prompt ablation

`p_def ∈ {攻擊者編輯 prompt、通用 caption（類別名稱）、空字串}`。

回答：防禦生成是否需要預知攻擊 prompt。若空字串效果接近，則防禦具備 prompt 無關性，實用價值顯著提高。

## §8 指標與診斷

### 8.1 指標清單

所有 `edit(orig)` vs `edit(defend)` 與 `x_def` vs `x` 的比較一律**同時報告下列全部指標**，不得只報單一指標。

| 指標 | 類型 | 出處 | 納入理由 |
|---|---|---|---|
| PSNR | 像素 | 標準 | v2 顯示其能捕捉 LPIPS 漏掉的重建失真 |
| L∞ | 像素 | 對抗擾動文獻標準約束（PhotoGuard） | v2 顯示非加性方法此值差達 28 倍 |
| SSIM | 結構 | Wang et al., IEEE TIP 2004 | 結構相似性 |
| LPIPS | 感知 | Zhang et al., CVPR 2018 | 感知距離標準指標；v2 已證其單獨使用會低估非加性失真 |
| DISTS | 感知 | Ding et al., IEEE TPAMI 2020 | 分離結構與紋理，補 LPIPS 之不足 |
| NIQE | 無參考 | Mittal et al., IEEE SPL 2013 | 不需參考圖的品質評估 |
| CLIP score | 語意 | Radford et al., ICML 2021 | 編輯結果與 prompt 的語意對齊程度 |
| SigLIP | 語意 | Zhai et al., ICCV 2023 | 第二個語意指標，避免單一視覺語言模型偏誤 |

引用之出處於論文撰寫階段須再次逐項核對版本與頁碼。
