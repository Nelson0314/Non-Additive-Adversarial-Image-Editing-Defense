二、主張是什麼（2026-08-13 定案）

  並列  防禦效果本身不輸：未淨化時的位移量不低於加性 baseline

三、內部弱 baseline（DEC-023）
--------------------------------------------------------------------
「完全原生 APA，只把 reward 換成 targeted output」。五個位置裡四個原生：

    階段一   APA 官方 LoRA（denoising MSE、AdamW 1e-4、200 步、rank=8）
    階段二   dual-path attack guidance（trajectory + step-level）
    約束     latent L∞ 球 ε_a = 0.4
    更新     L1 正規化動量 + sign，µ=0.04、N=10
    reward   −‖D(z̄_0) − y_target‖²        ← 唯一的替換

叫「弱」是因為它的語意抵抗接近零。它是位置基準，不是有效的防禦。

跑它：
    python scripts/apa_baseline.py --out runs/<批次名> \
        --data data/lo_aligned --images horse_00 man_00 bird_03

不給 --data 時讀 data/apa_native（APA 官方那三張圖）。
--conditions 可只挑其中幾個（apa_weak / photoguard_c / mist / dia_r）。

五、已經被否證的方向（不要重試）
--------------------------------------------------------------------
四個軸都試過了：「把編輯推遠」做得到，「讓編輯不服從 prompt」做不到。

  * 提高失真預算 —— τ=0.50 下注意力抑制達 89–94%，而編輯成功率 100%，
    比不防禦（67%）還高。防禦圖被破壞到 img2img 直接當噪聲重畫。FND-024
  * 放大既有方向 —— k 掃到 64 倍，抑制率非單調且達不到高抑制區。FND-025
  * 換 reward —— 注意力抑制、分類器 CE、latent、CLIP 四種都測過，
    語意掉幅全部在 ±0.03 內。連與評測同族的 CLIP loss 也無效。FND-029/030
  * 換約束 —— latent 球、DISTS 進 loss、影像空間投影都測過。FND-029
  * 換更新規則 —— sign 與 Adam 都測過。FND-029
  * 換階段一 —— 原生 LoRA 與 z*+decoder 都測過。FND-023/027

**外部獨立確證**：arXiv:2506.04394（ICIP 2025）測到多數情況下受保護影像
的編輯仍符合 prompt，加噪聲甚至可能提高輸出與 prompt 的關聯。這些負面
結果是可引用的，不是「我們沒做出來」。


六、現在在做什麼
--------------------------------------------------------------------
見 PLAN.md。兩條路線：

  A  對淨化的 min-max：max_φ min_{P∈𝒫} effect(P(G(x;φ)))
     維持弱 baseline 的四個原生位置，只在 reward 外包一層 min over 𝒫。
     內層用確定性最壞情況，不用隨機輪替（算子噪聲會蓋過方法訊號）。

  B  cross-attention target injection reward（程式已完成，待跑四格消融）
     R = −‖A(z̄₀,c) − A(y_tgt,c)‖² + β·‖A(z̄₀,c) − A(x,c)‖²
     與已否證的注意力抑制不同：對象是 attn2 的「輸出」不是「分佈」，
     動作是「讓另一個語意接管」不是「把質量拿走」。
     注入目標 data/targets/obama.png（公有領域）。

淨化算子要新增三個（ROBUSTNESS_TESTS.md §4）：C&R 串接、NAPPure-flow、
PDM-Pure。第二個最關鍵——它是針對非加性設計的淨化，不納入的話主張
可被一句「沒測針對性淨化」推翻。


七、動手前必須知道的坑
--------------------------------------------------------------------
量測與方法
  * 未防禦的編輯必須真的成功，否則抗編輯那一欄的分母不成立。換資料集或
    換 prompt 後一定要先看 edit_orig 的圖。DEC-022
  * DISTS 在 512² 上會先降採樣到 256²，加性與非加性的失真比較會因此
    翻轉。要比絕對值時先確認量在哪個解析度。FND-026
  * latent 半徑不是保真約束：同一個 ε_a 在不同影像上是完全不同的可見
    失真，而 LPIPS/DISTS/SSIM 三者的排序都可能與人眼相反。FND-028
  * retention 的分母在 effect_siglip 讀數下不可用（65 組只過 1 組），
    但在位移讀數下 1425 列有 1350 列可用。PLAN.md §2.1
  * 加性 baseline 不經 VAE 來回，其 39–41 dB 有相當部分來自結構差異，
    不宜與走生成路徑的格直接比保真度絕對值。
  * APA 階段二的 CFG 必須是 1.0、反演必須走淺噪聲帶（50 格排程只執行
    前 11 格）。這兩處弄錯不會報錯，只會讓失真量級整個不同。
  * injection reward 可正可負，第 0 次迭代若落在零附近，DEC-021 的正規化
    常數會極小而讓 reward 爆掉。每格第一行 log 要看 reward_raw。PLAN.md §4.2a

工程
  * **本 repo 用 sparse-checkout（cone mode）。** 新增頂層目錄前要先
    `git sparse-checkout add <目錄>`，否則 git mv 會拒絕且不留半途狀態。
  * **測試跑的期間不要改原始碼。** pytest 逐檔 import，中途改檔會讀到
    不一致的狀態，症狀是隨機幾個測試失敗而重跑就好——極容易誤判成缺陷。
  * 遠端跑 legacy/scripts/run_stage.py 時預設模型是 SDXL/1024²，本專案
    主線是 SD v1.4/512²，必須明給 --model 與 --resolution。
  * dia_r 與 mist 必須開 use_ckpt 與 vae_ckpt，否則 OOM。
  * 同一個批次目錄只允許一個寫入者（.writer.lock）。要平行就用不同的
    批次目錄。殺掉行程後鎖會殘留，先用 ps -p 確認 pid 已死再刪。
  * runs/ 是唯一的證據來源，全部入版控。改 .gitignore 的 runs/ 區塊後
    必須用 git status --porcelain --ignored 確認沒有結果檔被靜默排除。
