## 方法現在長什麼樣

四步，每一步可微，用 sign PGD 學 8000 步、固定步長 0.01：

1. 512×512 切成 `32×32` 方塊，hop `8`（大量重疊，每像素被 16 塊蓋到）。
2. 每塊加窗傅立葉轉換得複數係數 `S = A·e^(iφ)`。
3. 每個係數乘 `exp(iθ)`（轉相位）再乘 `exp(g)`（改幅度）；`θ, g` 是參數，
   乘上去前過兩個閘：逐區塊紋理閘、逐頻格知覺定價（`jpeg_luma^0.25`）。
4. 重疊相加回像素、夾值域，那就是交出去的防禦圖。

主線設定：`--conditions phase_gain --quantile 0 --freq-weight jpeg_luma
--freq-weight-power 0.25 --hop 8 --gain-ratio 1.0 --radius 2.5`。

**關鍵恆等式**：一個係數實際造成的改變是 `|ΔS| = 2A·sin(θ/2)`。`A` 是原圖
自己的幅度，我們控制不了——後面所有的失效都由這一條解釋。

## 三個目標

### 一、模糊與裁切造成的失效主因

兩者的機制**完全不同**，不可用同一個方案處理。

**模糊：相位完整活著，載體被抽掉。** 高斯模糊是零相位濾波器，頻域上乘實正數
`H_σ(ω) = exp(−σ²ω²/2)`，乘實正數不改變輻角——實測相位保留率 0.96。它拿走的
是 `|ΔS| = 2A·sin(θ/2)` 裡的 `A`：實測 `H(σ=1, r=0.95) = 1.17%`（理論 1.17%），
整張殘差能量 σ1 剩 30.9%、σ2 剩 12.0%，而存活的能量 **99.4% 集中在 r < 0.35**。

**裁切：擾動完整通過，只是被搬到別的座標。** 殘差對「單獨送進同一幾何變換」
的餘弦 0.9997，對原格點 0.005，能量存活 0.66–1.20。這一輪查證了 1.2488× 的
放大把它搬到 VAE 敏感度**高 1.8 倍**的頻帶——**所以病因是座標對位，不是頻帶
錯位**，尺度共變參數化那條路的前提已被否證。

**要注意的量測事實**：主讀數有天花板。LPIPS 在兩張不相干的自然影像之間飽和，
實測十張兩兩配對（45 對）的中位數 **0.772**，所以每一欄的可達範圍是
`0.772 − 地板`。用這個讀法，最糟的欄是**模糊 σ2（佔可達範圍 21%）**而不是
裁切 15%（33%）——舊讀法「地板的 0.12 倍」高估了裁切有多糟。
證據：`runs/readout_ceiling/README.md`。

**還沒做、最該做的一格**：把預算拆成兩份。UNet 的（頻帶, 噪聲步）敏感度圖
（`runs/unet_band_sensitivity/`）顯示每單位人眼代價換到的反應在 r 0.88–1.06
是 51,812、在 r 0.18–0.35 是 1,163（44 倍）；但乘上模糊 σ2 的存活率之後前者
歸零、後者還有 291。**先前記下的「模糊可贏上界 1.54 倍」是在 σ1 上算的，
從未涵蓋 σ2。** 旋鈕都已存在（`--freq-weight-power` 調定價陡度、`--r-max`
設上界）。**注意這與已否證的「放行低頻（`r_min` 調低）」不同**——那條調的是
下界，這裡調的是上界與定價陡度。

### 二、當前方法的整合、架構簡化、抗淨化

**架構要簡化的理由是實測的**：這一輪關掉了六條路，它們都可以從方法描述裡
刪掉——L∞ 交付投影、逐像素紋理遮罩、加大 hop、`--theta-budget`、STFT 一致性
懲罰（含退火）、幾何 EOT。六條合起來說的是**讓它有效的東西和讓它醜的東西是
同一個**：擾動必須鋪在平坦區、必須夠大，才打得動 VAE 編碼器。

還開著的旗標裡，**真正有證據支撐的只有三個**：損失的選擇、`--purify-aware
eot_broad`、半徑。其餘（`--quantile`、`--gate-edge-power`、`--floor-gate`、
`--coarsen`、`--gl-iters`、`--pixel-gate-sigma`、`--linf-deliver`、
`--consistency-weight`）都是已否證或打平的，寫論文時應該從方法一節移除。

**抗淨化目前的機制是寬 EOT**：每步先均勻抽算子類別（identity／JPEG／模糊／
裁切各 1/4），再在該類族內抽參數，損失算在處理過的圖上。兩層抽樣是刻意的——
攤平會讓 identity 從 1/4 掉到 1/13。

### 三、位移場的可能性探討

**先讀既有證據再提方案**，這一族已經被打過三次：

- `runs/ip2p_warp/DIAGNOSIS.md`：預算夠、最佳化沒走。
- `runs/ip2p_warp_hard/`：grid 16 到不了失真帶；grid 64 到得了但付 1.92 倍
  失真只換到 65% 的位移。
- **歸因**：單值位移場是**微分同胚**，把一張自然影像映成另一張自然影像，
  VAE 與 UNet 面對的仍是一張合理的照片。真正動得到編碼器的只有**場的粗糙度**
  （重取樣走樣），而那與加性高頻雜訊同族。`matched_geometry.csv` 直接量到：
  `warp_roundtrip`（先 f 再 −f，幾何完全抵銷、只留內插 artifact）與
  `warp_rand` 只差 **8.6%**——**幾何本身不值錢，值錢的是走樣。**

**這個論證同時指出出路**：問題出在「單值」不是「位移」。單值場強迫所有空間
頻率一起搬，那正是它留在流形上的原因。若讓不同頻帶各自有自己的位移場，這個
變形**沒有任何座標映射可以實現**，構造上就離開流形：

```
x_def = Σ_k  shift_{u_k(x)} ( band_k(x) )        第 k 個八度帶各自平移 u_k
```

在複數子帶上「平移 u」就是「相位加 2π f·u」——這是 Wadhwa 相位式運動處理的
恆等式。於是 `K`（獨立位移的頻帶數）把三個方法串成一條線：`K=1` 是古典位移
場（已測、失敗）、`K=∞` 是現行紋理重相位、`K=3–5` 是沒測過的中間物。

**色散那一臂上一輪被使用者裁定打掉**（隨機且不接閘的版本殘差是滿幅度尖峰、
L∞ 0.98、防禦圖很醜；接上閘與可學之後 L∞ 修到 0.57–0.66、PSNR 18.1→28.0，
但擋下 0/10）。程式仍在 `src/defense/dispersion.py`，派工腳本已刪。

## 五個會踩到的坑

1. **等失真比較不可省，而且不可外插。** 落在掃描範圍外一律拒絕。
2. **擋下數不可用 SigLIP 代理。** 實測它把「人還在、只是被蓋上紋理」也標成
   blocked。要用眼睛判**重畫**（原圖不可辨）對**劣化**。
3. **`pkill -f` 的樣式會匹配到自己的 ssh 連線**並截斷輸出。用 `ps` 取 PID 再
   逐一 kill（這一輪踩了三次）。
4. **兩個 process 不可寫同一個輸出目錄。** 每張影像寫檔是整份重寫
   `results.csv`，並行會互相截掉；`--skip-existing` 早期版本也踩過同一個坑。
5. **殘差不可夾取值域。** `crop_resize` 最後一行的 `.clamp(0,1)` 是給影像用
   的；殘差是有號小量，夾取會把負值推成 0（曾把 `cos_vs_warped` 架高成 0.71，
   真值 0.9997）。
